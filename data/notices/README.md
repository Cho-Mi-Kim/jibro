`official-20261101.json`은 2026-11-01 LH청약플러스 상세 페이지를 직접 대조한 초기 공개 자료다. 자동 수집 전체 결과나 실시간 데이터가 아니다. 각 항목의 `content.evidence.url`이 원문이며 `panId`가 공식 식별자다.

| 공고 | 게시일 | 신청 접수기간 | 확인 당시 상태 |
| --- | --- | --- | --- |
| 전국 청년 전세임대 1순위 수시모집 | 2026-02-24 | 2026-02-24 10:00 ~ 2026-12-31 18:00 | 접수 중, 조기 종료 가능 |

서울: 서류제출대상자 발표 10-02, 서류접수 10-06~10-08, 예비입주자 순번 발표 12-11. 경기남부: 서류제출대상자 발표 09-11, 서류접수 09-14~09-16, 예비입주자 순번 발표 11-27. 예비순번 발표와 서류제출대상자 발표는 다른 일정이며 입주 확정도 아니다.

## 초기 자료의 확인 범위와 공개 판단

아래는 최초 `official-20261101.json`의 범위다. 이후 준비 안내 검수는 별도 자료로 적용한다.

- 공식 상세 페이지의 제목, 지역, 유형, 게시일, 신청 접수기간, 공급일정을 Codex가 대조했다. 경기남부는 정정본을 선택했다. 별도 사람 검토자는 아직 확인되지 않았다.
- 기본 정보는 PASS, 개인별 준비 안내는 HOLD로 함께 기록한다. 질문·제출서류·신청 가능 여부를 추론하지 않으며 준비 시작은 비활성화한다.
- 첨부 PDF 전체와 개별 주택 목록은 검수하지 않았다. 첨부 및 개인별 질문·서류는 빈 배열이다. 날짜만 확인된 일정에 마감 시각을 임의로 붙이지 않는다.
- 현재 API의 접수 상태는 날짜 단위다. 당일 마감 시각·조기 종료를 자동 판정하지 못한다. 전세임대의 확인된 시각은 요약에 보존하며 실제 신청 전 원문을 다시 확인한다.
- LH HTML에는 숨겨진 공통 팝업과 정정 안내 템플릿도 들어 있다. 숨겨진 문구를 해당 공고의 실제 상태로 해석하지 않는다.

## 로컬 적용

프로젝트 루트에서 Node 24와 Docker를 사용한다.

```powershell
node scripts/import-official-notices.mjs
node scripts/import-official-notices.mjs --apply
```

첫 명령은 파일 검증만 한다. `--apply`는 Compose 프로젝트·서비스를 확인한 뒤 `jibro-housing-dev-postgres-1`의 `jibro` DB에 없는 공고만 추가한다. 동일 URL의 source key 또는 동일 panId가 있으면 덮어쓰지 않는다. 기존 항목의 검수 상태가 HOLD인 경우에도 자동 승격하지 않으므로 관리자 검수가 필요하다.

해당 공개 공고 행의 적용 전 상태와 결과는 Git에서 제외된 `.tools/notice-imports/`에 남긴다. 계정·인증·준비 기록을 백업하거나 변경하지 않는다. 기존 예시 공고는 삭제하지 않고 기본 검색·필터에서 제외하여 기존 준비 기록을 보존한다.

## 후속 작업

현재 자동 수집의 임대주택 분류(06)와 최근 3개월 범위로는 이 자료의 매입·전세임대 분류(13) 및 장기 수시모집을 모두 포괄하지 못한다. 분류별 수집과 장기 접수 공고 갱신, 조기 종료·정정 감지, 관리자 원문 검수는 별도 보완한다. 이 자료의 재실행만으로 최신 내용이 갱신되지는 않는다.

## 준비 안내 원문 검수 추가

`guidance-review-20261101.json`은 첨부 공고문·Q&A를 대조한 후속 자료다. 전세임대 안내는 PASS, 서울·경기 매입임대는 복합 서류 조건 검증이 남아 HOLD다. [공고별 검수 보고서](../../docs/planning/official-guidance-review-20261101.md)에 근거·예외·보류 이유를 기록했다.

```powershell
node scripts/apply-guidance-review.mjs
node scripts/apply-guidance-review.mjs --apply
```

최초 자료와 버전이 일치할 때만 로컬 DB에 반영하며 재실행은 같은 결과를 유지한다. 계정·기존 준비 기록은 변경하지 않는다. 팀의 사람 검토 완료를 뜻하지 않는다.
