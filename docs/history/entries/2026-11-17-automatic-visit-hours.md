# 신규 공고의 방문 접수 일정 자동 반영

접수 중·예정 공고의 일정 검수에서 공식 모집공고의 날짜별 방문 시간, 점심시간, 사전 연락 안내를 읽어 전체 일정과 회차별 시간에 제공한다. 방문과 인터넷의 시작·마감은 각 접수 방식에 연결하고, 사전 연락 기한과 전화번호는 별도의 일정 안내로 저장한다. 신청 장소와 접수 시간이 같은 행에 있는 한글 표와 줄이 나뉜 방문 전용 PDF 표를 처리한다. 상충하는 사전 연락 안내는 자동 확정하지 않는다.

익산부송1·익산동산, 서귀포동홍3, 나주시 국민임대, 아산·천안 국민임대, 인천산곡 A1의 저장된 공식 자료를 자동 검수에 다시 입력했다. 390px 브라우저에서 재현 결과를 연결해 공고별 일정과 회차별 시간 창의 표시를 확인했다. 기존 공고의 저장값은 일괄 변경하지 않았다.
