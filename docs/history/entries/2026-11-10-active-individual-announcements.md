# 미종료 공고의 개별 결과 안내 대조·반영

- 기록일: 2026-11-10 (Asia/Seoul)
- 기록 상태: 근거 정리·담당자 검토 전
- 작업 상태: 해결
- 유형: 문제 해결 / 개발
- 담당·검토: 사용자 요청, Codex 원문 대조·구현·검증 보조. 팀 검토 미확인
- 관련 이슈·PR·커밋: 미등록, 로컬 작업

## 배경·문제

사용자가 다른 공고도 공식 원문에서 결과를 개별 안내하는 경우 반영하고, 설명을 공고별로 작성하며 접수종료 공고를 제외하도록 요청했다. 현재 공개 API의 OPEN/UPCOMING 21건을 범위로 고정했다.

## 고려한 선택지와 결정

단순히 날짜가 없는 공고에 공통 문구를 넣는 방식은 사용하지 않았다. 결과 선정, 서류 대상자 발표, 소명 요청, 계약·입주 개별 안내를 구분했다. 기존 고정 일정과 최종 개별 통보가 함께 있는 경우 날짜를 없애지 않고 설명 버튼을 함께 표시한다. source별 날짜가 다르면 설명에서 차이와 기관 확인 필요를 명시한다.

## 변경·해결 과정

다자녀·신혼Ⅰ·남원노암은 source review의 현재 원문/전체 첨부/revision 검증 후 amend했다. 청년은 기존 구형 안내의 일정 한 항목만 추가하는 명시적 수정 경로로 처리했다. 평택·안성 2건은 기존 팜플렛 ZIP이 FAILED 발췌여서 전체 안내 재승인 경로를 중단했다. 과거 명시적 검토의 SHA와 현재 전체 첨부를 대조한 뒤 해당 결과 일정만 수정하고, 기존 발췌 상태·질문·서류·검토 이슈를 유지했다. 이 작업을 팜플렛 전체 해석 성공으로 기록하지 않는다. 모두 잠금과 현재 상태/원고/revision 확인 및 수정 감사 이력을 남겼다.

## 검증·결과

- 실제 공개 API: 21개 확인, 6개에 일정 1개씩 추가, 15개 기존 일정/버전 유지. 기존 질문·서류·요약·검토 이슈·접수기간 모두 동일.
- 접수종료 날짜 공고와 개인 준비 전체 행의 작업 전후 해시 동일. 변경한 6개 모두 적용 시 OPEN/UPCOMING과 공식 페이지 상태를 재확인.
- 관련 프런트 5파일 36테스트, 타입 검사, 변경 TS ESLint, 빌드 통과. 기존 번들 크기 경고 잔존.
- 393×852 브라우저에서 평택·안성 날짜+개별 안내 공존, 팝업 본문·근거·닫기 확인. 실제 기기 미검증.
- 근거/실행 결과: `.tools/qa/individual-announcements-active-20261110/official-check.json`, `apply-results.json`, `validation.json` 및 일정 한정 수정 로그. 비밀값 미포함.

## 기여·한계

각 원문의 서로 다른 기간과 발표 단계를 공통 모델로 표현했다. 남원노암 날짜 차이는 해소됐다고 주장하지 않고 설명에 기관 확인 필요로 남겼다. 삼척·정선, 동해·태백, 태백궁전의 계약 개별 통보를 결과 발표로 바꾸지 않았다. 충주연수2는 PDF에 고정 발표일이 있어 개별 안내 대상에서 제외했다. 미래 자동 기간 추출·운영 배포·push는 이번 범위가 아니다.

## 발표·포트폴리오 메모

날짜 유무만으로 분류하지 않고 발표 단계와 출처 문맥을 대조해, 확정 날짜와 개별 통보 설명을 보존했다.

## 후속 작업

남원노암의 실제 발표일은 기관 확인 또는 후속 공식 자료가 필요하다. 사용자 화면 확인.
