# 공고 선택 자동 스크롤 속도 조정

2026-11-12 사용자 요청으로 공고 목록의 공고 선택 시 즉시 이동을 650ms 완만한 가감속 스크롤로 변경했다. 원래 스크롤 여유 공간 확보 로직과 고정 상단 영역 계산은 보존했다. 다른 공고 선택/화면 이탈 시 이전 애니메이션을 취소하고 휠·터치 입력으로 중단한다. 동작 줄이기 환경은 기존 즉시 정렬을 유지한다.

변경: frontend/src/features/housing/useNoticeCardScroll.ts 및 기존 테스트의 reduced-motion 환경 명시. 기존 헤더·검색영역 접기와 여유공간 회귀 테스트3건 통과, TypeScript 검사 통과. 650ms 애니메이션 실제 브라우저 시각 QA는 미실행. AI 보조 구현, 커밋·push 없음.

후속 사용자 조정: 자동 스크롤 시간을650ms에서900ms로 늘려 더 천천히 이동하도록 변경했다. 가감속 방식과 취소 처리는 유지한다.
최종 사용자 조정: 자동 스크롤 시간700ms(0.7초) 적용.
최종 사용자 조정: 자동 스크롤 시간750ms(0.75초) 적용.

## 후속: 사이트 공통 시간 기준
사용자 요청으로 CSS --motion-duration:750ms 및 shared/ui/animateScroll을 도입했다. 기존 공고 자동 정렬, 가이드 질문 자동 정렬, 준비서류 패널 자동 정렬이 공통 시간을 사용한다. 상태 표시 펼침·접힘, 목록 검색영역 접힘, 집 진행 이미지 전환도 공통 토큰 적용. 동일 대상 새 스크롤은 이전 실행을 취소하고 수동 휠/터치 입력을 존중한다. 향후 기준을 AGENTS.md에 기록했다. 화면 전환 초기 위치 복원·검색 debounce·네트워크 지연은 애니메이션 시간 변경 대상에서 제외. TypeScript 검사 실행, 브라우저 시각 QA는 미실행.

## 후속: 남은 펼치기/접기 적용
홈 설명·가이드 질문·준비 조건/서류/일정 근거·공고 근거·정정/비교/보관 이력 등 native details에 공통 ::details-content block-size/opacity/content-visibility 전환750ms 적용. interpolate-size 지원 브라우저에서 열기와 닫기를 모두 전환하며 미지원 브라우저는 기존 기본 동작 유지. 준비 문서 hidden 패널도 display allow-discrete/height 전환 적용. 공고 카드와 계정 탈퇴 안내의 조건부 렌더링은 shared/ui/Collapse로 닫기 완료까지 유지. 닫히는 동안 inert/aria-hidden으로 입력 방지. 기존 reduced-motion 전역 정책 유지.

검증: TypeScript 검사 및 변경 TSX ESLint 통과, 공통 Collapse의750ms 지연 제거/닫는 중 다시 열기 및 기존 스크롤 회귀 총5건 통과. 테스트1건은 내용 내부 요소 대신 wrapper를 찾아야 해서 단언 수정 후 통과. 브라우저 시각·실기기 검증은 미실행. 팝업/페이지 전환을 아코디언으로 바꾸지는 않았다.

## 후속: 공고 상단 필터와 카드 전환 충돌
상단 검색영역과 이전 카드가 0.75초 동안 접히는 중 선택한 카드의 절대 위치가 움직이는데, 기존 자동 스크롤은 최초 위치만 목표로 하여 정렬이 어긋났다. animateScroll에 매 프레임 위치 계산을 추가하고 공고 목록에서 현재 상단 높이와 카드 위치를 다시 계산한다. 사용자 휠·터치 중단과 동작 줄이기 동작을 유지한다. TypeScript 및 기존 스크롤 테스트3건 통과. 실제 브라우저 시각 검증은 미실행.
