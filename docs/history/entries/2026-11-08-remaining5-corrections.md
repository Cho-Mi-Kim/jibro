# 남은 보류 5건 최신 원문 재확인과 정정본 연결

- 기록일: 2026-11-08 (Asia/Seoul)
- 기록 상태: 근거 정리·담당자 검토 전
- 작업 상태: 정정 연결 1건 적용, 기관 원문 충돌 4건 보류
- 유형: 개발 / 문제 해결 / 원문 검토
- 담당·검토: Codex AI 보조 구현·공식 자료 대조·실행 검증, 사람 담당·검토자 미확인
- 기준: `feature/launch-integrations-20261107` / `e288a99`, 기존 작업 보존, 커밋·push·배포 없음

## 배경·문제

사용자는 앞선 18건 처리 뒤 남은 보류 5건을 최신 정정 공고와 공식 원문으로 다시 확인해 해결하도록 요청했다. 이전 결과는 안내 PASS 11 / UNSUPPORTED 2 / HOLD 5였다. 원문 충돌을 임의로 해소하지 않는 기존 결정과 개인 준비 기록 보존을 유지했다.

## 고려한 선택지

- 공고 제목이 비슷하다는 이유로 원본·정정본을 합치거나 원본을 취소/PASS 처리하는 방법: 공식 식별과 개인 기록을 훼손하므로 사용하지 않았다.
- 공식 양방향 정정 관계를 검증하고 기존 안내가 검수된 별도 정정본으로 연결하는 방법: 인천논현에 적용했다.
- 다수 자료의 일치나 오타 추정으로 나머지 충돌을 승인하는 방법: 공식 원문이 여전히 서로 달라 사용하지 않았다.

## 결정·이유

인천논현2는 LH 원본·정정 페이지의 `panId`, `currPanId`, `GoCrc`에 명시된 양방향 관계와 최신 정정 종류를 검증했다. 장소 변경은 원문 10쪽의 관리사무소 → 210동 회의실(구 탁구장)이다. 원본 HOLD는 보존하고 검수 완료된 정정본으로 이동할 수 있게 했다. 나머지 4건은 현재 공식 첨부에서 충돌이 재확인되어 HOLD를 유지했다.

## 변경·해결 과정

- LH 현재 목록·상세·알려드려요 공지 및 주택관리공단 공식 게시글·첨부를 재조회했다. 기존 비교 대상 LH 첨부 16개는 재다운로드 SHA가 같았다. 남동 현장대행 PDF 1개와 관리공단 자료도 추가 확인했다. 검색 기간·키워드·결과·해시·차수 구분은 `docs/reviews/2026-11-08-remaining5-*.json`에 보존했다.
- `OfficialCorrectionLink`는 원격 JavaScript를 실행하지 않고 제한된 정형 선언·주 게시글 폼의 ID와 정정사유를 읽는다. 팝업용 빈 panId는 제외한다. 양방향 확인·공식 호스트·경로·동일 시스템·최신 정정 종류를 모두 요구한다.
- `NoticeCorrectionService/Repository/Controller`, V28 정정 연결 테이블을 추가했다. 공개 조회는 200/204/404이며 유효 revision과 대상 공개/안내 PASS/NORMAL 상태를 재검사한다. 쓰기 HTTP 경로·예약 작업은 추가하지 않았다.
- 실제 적용 첫 시도는 정정본 대표 근거가 PDF라 출처 검증에서 거절됐다. 안내 대표 근거와 수집 출처를 분리하여, 발췌 이력의 공식 상세 후보 중 수집 `source_key`와 정확히 일치하는 주소만 찾도록 수정했다. `LhNoticeClient`의 기존 키 생성식을 `sourceKey`로 재사용하고 PDF 대표 근거·타 공고 출처 거절 회귀를 추가했다.
- 네트워크 확인 후 두 공고를 순서대로 잠그고 revision/공개 상태/검증 120초 유효기간을 검사한다. 원본·정정본 콘텐츠 및 개인 스냅샷은 변경하지 않는다. 중복·자기 연결·체인을 거절한다.
- `NoticeCorrectionBanner`와 API 모듈을 분리했다. 안내 상태와 무관하게 확인된 정정 링크를 조회하고, 조회 실패는 재시도한다. 자동 이동·답변 이전 없이 사용자가 이동하며 홈/검색 복귀 상태를 보존한다.
- 15:57 KST 원본 `4d2e2916-60d2-4ffc-a63a-40d1843fd590` → 정정 `3fe0dbde-d45b-42ff-bc6a-14bc2bd2c6e7` 연결을 실제 적용했다. 공식 상세를 적용 시 다시 검증했다.

## 기여·한계

공식 파일 수집·원문 대조·코드·회귀 검사에 AI 보조를 사용했다. 기관 전화·메일 문의 또는 기관 확인 답변을 받지는 않았다. 익산은 현재 모집과 과거 확약서/증빙 적용 범위, 충주는 LH 접수처 안내의 2026 연도, 남동은 김포시 배점·초본 대상, 경주는 16/17시와 공고일/접수일 충돌이 남는다. 정정 미발견은 기록한 검색 범위·시각에 한정한다. 범용 자동해석을 완성한 결과가 아니다.

## 발표·포트폴리오 메모

공식 원본의 정정 관계를 추정하지 않고 식별자·현재 자료·revision에 결합해 검증했다. 실제 적용에서 발견된 대표 PDF/원문 HTML 혼동을 수정하고 개인 준비 보존을 검사했다. 개인 기여 표기는 담당자 확인 후 사용한다.

## 후속 작업

- 나머지 4건은 정정자료 또는 적용 범위가 명시된 공식 답변 확보 후 재검토한다. 질문/서류 초안을 임의 승인하지 않는다.
- 새로운 정정 차수가 생겨 revision이 달라지면 연결을 숨긴다. 체인 또는 반복 정정 교체 정책은 별도 검토가 필요하다.
