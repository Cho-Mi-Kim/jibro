# 모바일·PC 시안 기반 프론트엔드 재디자인

- 기록일: 2026-11-01 (Asia/Seoul)
- 기록 상태: 작성 중
- 작업 상태: 진행 중
- 유형: 개발 / 의사결정
- 담당·검토: 사용자 요청, Codex 구현·검증 보조. 팀 담당자 검토 전.

## 배경·문제
사용자가 모바일 brick-20261031-clean 및 PC desktop-20261031-compact의 10개씩 화면과 최대한 동일한 반응형 구현을 요청했다. 기존 PC 화면은 좁은 모바일 본문과 소개 영역으로 구성되어 시안과 구조가 달랐다.

## 고려한 선택지
전체 화면을 이미지로 표시하는 방식은 실제 데이터·상호작용을 보존할 수 없다. 기존 API와 상태 관리 위에 공통 UI와 페이지 레이아웃을 재구성하는 방식을 선택했다.

## 결정·이유
- 별도 feature/frontend-responsive-redesign-20261101 브랜치. 기존 미커밋 동기화 기록은 보존하고 이번 변경에 포함하지 않는다.
- 1024px 이상은 PC 상단 메뉴 및 2단 구성, 그 미만은 하단 메뉴와 세로 흐름. 중간 너비에서도 내용을 숨기지 않는다.
- 샘플 이름·65%·D-5는 하드코딩하지 않는다. 실제 API 값과 한국 날짜 기준으로 표시한다.
- 현재 조건 응답 API는 YES/NO/UNKNOWN이다. 시안의 지역 선택지를 이 값으로 임의 매핑하지 않는다. 기존 질문·응답 계약을 보존하면서 레이아웃을 맞춘다.
- 확인되지 않은 공고 날짜·발급 대상·공식 링크를 만들어 넣지 않는다. 미제공 정보는 확인 필요로 표시한다.
- SEED ActionButton을 유지한다. 공식 React 문서 https://seed-design.io/llms/react/components/action-button.txt 확인. 디자인 시안에 맞는 제품 CSS 및 SVG 아이콘·단계별 벽돌 집을 작성한다.

## 변경·해결 과정
1. PC 상단 메뉴/모바일 하단 메뉴, 공통 색상·타이포·카드·버튼과 벽돌 집 SVG 구성.

## 검증·결과
검증 진행 중. 완료한 검사와 화면 확인 결과를 후속 갱신한다.

## 기여·한계
AI 보조 구현이다. 사용성 개선 수치나 사용자 테스트 결과는 아직 없다. SVG 장식은 시안을 참고한 벡터 재현이며 원본 일러스트와 픽셀 단위 동일하지 않다.

## 발표·포트폴리오 메모
모바일/PC의 서로 다른 정보 배치를 기존 API·저장 흐름과 결합하는 반응형 재구성 작업. 검증 완료 후 결과를 추가한다.

## 후속 작업
- 10개 화면의 데이터 연동 및 반응형 검증, 자동 검사, 단계별 커밋·푸시.

### 2차 구현
- 홈 대시보드, 공고 검색/복수 필터/목록 및 상세, 가이드 카테고리와 아코디언 구현.
- API 없는 발표·서류 마감은 확인 필요로 표시. 제공된 일정만 사용.
- 1·2차 구현 후 TypeScript 빌드 검사 통과. 전체 동작 검증은 계속 진행.


### 3차 구현과 회귀 검증
- 내 준비 개요·조건 질문/결과·서류 목록/상세·일정·마이를 재구성했다.
- PC 서류 목록/상세 분리와 모바일 펼침 UI에서도 편집 컴포넌트를 유지해 다른 서류의 미저장 입력을 보존한다.
- 기존 테스트의 화면 탐색을 새 UI에 맞춰 변경했다. 저장 실패→재시도 및 다른 서류 메모 보존 시나리오는 유지했다.
- ESLint 통과, TypeScript 통과, Vitest 4개 파일 15개 테스트 통과.
- 별도 5174 시연 서버에서 PC 조건 응답→결과→서류 완료 기록 및 모바일 서류 화면을 확인했다. 실제 계정/DB에 테스트 기록을 추가하지 않았다.
