# 관심 공고에서 저장한 두 공고 비교

- 기록일: 2026-11-16 (Asia/Seoul)
- 상태: 구현·로컬 검증 완료, 팀 검토 전

## 배경·문제

관심 목록에서 두 공고를 비교하려면 전체 목록으로 이동해 다시 찾아야 했다.

## 고려한 선택지와 결정

관심 목록에 별도 선택 화면을 만들거나 기존 비교 화면에 저장 목록을 전달하는 방식을 검토했다. 두 목록에서 같은 비교 결과와 선택 방식을 유지하기 위해 기존 화면을 사용했다.

## 변경·해결 과정

SavedPage의 공고 비교 링크가 회원 전용 /saved/compare 화면을 연다. 미리보기가 열려 있으면 해당 공고를 첫 번째로 선택한다. 후보는 해당 회원의 저장 목록에서 검색한다. 비교 결과는 기존 공고 비교 자료를 사용한다.

## 검증·결과

프론트엔드 빌드와 테스트 436개 통과. 별도 체험 계정으로 로컬 5173의 Chrome 360·390·768px에서 두 공고 선택, 결과 표시, 선택 해제와 뒤로 가기를 확인했다.

## 기여·한계 및 후속 작업

Codex가 구현·브라우저 검증을 수행했다. 실기기 검증과 팀 검토는 별도다.

## 발표·포트폴리오 메모

같은 비교 화면에서 진입한 목록에 따라 후보를 제공한다. 관심 목록의 저장 공고를 검색할 때는 전체 공고 목록을 다시 요청하지 않는다.

## 비교 후 목록 위치 복원

비교 화면의 돌아가기 링크가 목록 주소에서 펼친 카드 정보를 잃고, 화면 전환과 카드 정렬이 각각 스크롤을 이동시켰다. 관심 목록과 비교 화면이 같은 방문 기록을 공유하도록 해 원래 목록 주소·스크롤 좌표·끝 여백을 복원한다. 비교할 공고를 바꿔도 목록에서 열었던 카드가 유지된다. 이 위치는 해당 화면 방문 중에 보관한다.

별도 체험 계정으로 Chrome에서 360px 화면의 돌아가기 링크, 390·768px 화면의 브라우저 뒤로 가기, 390px에서 카드를 모두 닫은 경우를 확인했다. 복귀 후 스크롤 좌표와 마지막 카드의 화면상 위치를 비교했다. 프론트엔드 빌드와 테스트 436개 통과.
