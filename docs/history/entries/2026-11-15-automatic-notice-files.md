# 접수 중·예정 LH 공고의 공식 첨부 자동 연결

수집 시 LH 상세 주소를 보관하고 접수 기간이 확인된 공고의 공개 첨부를 별도로 갱신한다. 기존 공고는 정정 확인에 쓰던 공식 주소를 이어받는다. 공식 페이지의 공고 ID와 수집 출처를 대조한 뒤 첨부와 ZIP 내부 경로를 저장한다. 일반 재확인은 1시간, 실패 재시도는 10분이다. 접수 종료와 최신 정정본으로 대체된 공고는 작업 대상에서 제외한다.

- 본문 추출 성공 여부와 무관하게 공식 첨부 목록을 반영한다. 큰 ZIP은 임시 파일로 내려받아 압축 해제 없이 내부 목록을 읽는다. 파일 크기 상한 150MiB, ZIP 항목 상한 4,096개를 적용한다.
- 공식 발급처를 우선하고, 서류명과 일치하는 단독 파일이나 ZIP 내부 파일이 하나일 때 자동 연결한다. ZIP 링크에는 실제 내부 경로를 표시한다. 준비 안내의 검수 상태와 사용자 답변은 보존한다.
- 5173에서 공개 37건을 LH 상세와 다시 비교해 첨부 158건 일치, ZIP 7개 내부 항목 46개 확인. 모바일 크기 Chrome에서 앞서 보완한 11개 공고의 첨부와 서류 링크, 비교 응답과 비회원 준비 응답도 검증했다.
- 신규 공고의 접수 예정 전환, 신규 서류 ID의 양식 연결, 오래된 결과의 접수 종료 후 반영 차단을 별도 테스트 DB로 검증했다. 전체 단위 테스트에서 기존 ApplicationPeriodReviewService의 DB 계층 검사 한 건 실패. 이 변경의 관련 테스트는 통과했다.

AI 보조 구현. 주요 파일은 OfficialFileCollector, OfficialFileRepository, OfficialFileManifest, ZipFormDirectory 및 V39 마이그레이션이다.
