## 배경·문제

사용자가 문서상 남은 기능 중 1~5번 보완을 요청한 뒤 다국어 지원(4번)을 제외했다. 이전 준비 스냅샷 조회, 기존 계정의 소셜 연결, 접근성 옵션, 공고별 조건·서류·일정 비교를 구현 대상으로 확정했다.

## 고려한 선택지

- 과거 준비를 현재 공고로 재계산할지 저장된 스냅샷을 표시할지: 당시 기록을 보존하는 읽기 전용 조회를 선택했다.
- 기존 이메일과 소셜 계정을 자동 합칠지 명시적으로 연결할지: 기존 계정 재인증과 제공자 확인을 연결하는 별도 흐름을 선택했다.
- 표시 설정을 계정에 저장할지 기기에 저장할지: 비회원도 사용할 수 있는 브라우저 설정을 선택했다.
- 공고의 서류 이름만 비교할지 상세 기준을 제공할지: 공개/검수 조건을 서버에서 검사하는 비교 전용 응답을 추가했다.

## 결정·이유

원본/개인 준비 기록/표시 설정/인증 수단의 책임을 분리한다. 새 기능은 별도 모듈로 추가하고 기존 화면은 진입점을 연결한다. 다국어 기반이나 번역 데이터는 추가하지 않는다. 원격 업로드나 병합은 이번 구현에 포함하지 않는다.

## 변경·해결 과정

- `preparation/PreparationHistory*`, `features/preparation/history`: 소유자만 과거 안내 버전·답변·서류·메모·신청 기록 조회. 보관된 준비에서도 진입 가능.
- `auth/AccountConnections*`, `ConnectionOAuthFlow`, `OAuthCompletionHandler`, V10: 현재 계정 확인, 단일 사용 연결 요청, OAuth 상태·세션 결합, 연결 충돌과 마지막 로그인 수단 보호.
- `features/accessibility`: 브라우저별 글자 크기·대비·동작 설정. 기본 UI는 보존하고 글자 확대 때 모바일 배치 보완.
- `notice/NoticeComparison*`, `features/comparison`: 조건 질문·선택지·공통/조건부 서류·발급 기준·공식 일정 비교. 안내 미공개 자료는 표시하지 않음.

## 검증·결과

- 프런트 `npm run ci`: 포맷·lint·타입·27개 파일 161개 테스트·실빌드 통과. `npm run build:pages`도 통과했다.
- 서버 `gradlew -p backend build integrationTest`: 단위 21개 + 별도 PostgreSQL 통합 44개 = 65개 통과. 실패/오류/건너뜀 없음. 이전 스냅샷 보존·타인 조회 차단·보관 후 조회, 공개 조건·서류 차단, 계정 재인증/단일 사용/해제 경합을 포함한다.
- 독립 검토에서 미설정 제공자만 남기는 해제 및 OAuth 로그인/해제 경합을 찾아 사용 가능한 수단 검사와 사용자 잠금 후 연결 재검증으로 수정했다. 별도 트랜잭션 회귀 테스트를 추가했다.
- 5173과 새 backend 실행 확인. 기존 서버 PID/경로/시작시각/명령을 대조한 뒤 backend만 재시작했고 V10 적용 후 health/database가 UP이다. 5174·5184는 변경하지 않았다.
- 실제 공개 비교 API에서 검수 중 2건은 질문/서류 0개와 공개 일정 3개씩, 안내 공개 1건은 질문 7개·서류 9개·일정 1개를 반환했다. 브라우저 공고 변경·공개 구분·이전 기록 빈 상태 조회를 확인했다. 실제 개인 준비 데이터는 갱신하지 않았다. 값이 있는 과거 기록은 React 및 DB 통합 fixture로 검증했다.
- 브라우저 360·393·768px, 기본/125% 글자 크기, 대비 강화, 동작 줄이기, 마이 진입·초기화, 확대 일정 행과 가로 넘침을 확인했다. 확대 시 확장 제목의 고정 줄 높이와 일정 날짜 열을 보완했다. 설정은 기본값으로 복원했다. 200% 브라우저 글자 확대·실제 기기·스크린리더 검증은 미수행이다.
- 빌드에 500KB 초과 주 번들 경고(약505KB)와 기존 Gradle 향후 버전 경고가 남는다. 경고 한도를 올리거나 검사를 우회하지 않았다.
