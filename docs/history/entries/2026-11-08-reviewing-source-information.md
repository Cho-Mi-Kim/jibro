# 검수 중 공고의 공식 원문 열람

## 배경·문제

사용자가 아직 검수 중인 공고에서도 표시 가능한 부분을 보고 싶다고 요청했다. 기존 공고 상세는 기본 정보만 공개하고 조건·서류 영역을 통째로 안내 문구로 대체했다. 자동 검수의 미통과 후보는 저장되지 않으며, 후보를 그대로 공개하면 미검수 해석을 개인별 준비 안내로 오인할 수 있다.

## 고려한 선택지

1. 미통과 안내 후보를 기존 `Notice.content`에 저장·노출: 공개 일정과 개인 준비 계약에 섞이고, 유형별 후보가 전체 예외를 검증했다는 보장이 없어 채택하지 않았다.
2. 현재 공식 원문의 발췌만 별도 읽기 전용 조회로 제공: 검수 상태와 개인 준비 규칙을 보존하면서 실제 읽을 수 있는 내용을 제공하므로 채택했다.

## 결정·이유

이번 요청에 따라 공식 원문 열람 범위를 출처별 발췌 카드로 확장한다. 화면 설계서의 미검수 개인별 해석·질문·서류 생성 제한은 유지한다. 원문 발췌를 검수 통과로 간주하지 않고, `원문 발췌 · 검수 중`을 함께 표시한다. 기존 자동 부분 제공와 구분하여 안내 상태, `canStart`, 준비도, 일정·알림·캘린더용 확정 값은 변경하지 않는다.

## 변경·해결 과정

- 공고 상세 전용 `/api/v1/notices/{id}/source-information`에서 현재 공개 공고의 최신 발췌만 조회한다.
- 조건·서류·일정별 원문 구간과 페이지·출처·자료 확인 시점을 제공한다. 읽지 못한 자료나 추정 문장은 만들지 않는다.
- 공고 revision·원문 지문·최신 작업과 발췌 내용을 전후 대조한다. 새 수집/재시도/자료 변경이 있으면 이전 발췌를 대신 노출하지 않는다.
- 조회 중 외부 모델·수집·재검수·데이터 저장을 실행하지 않는다. HTTP 캐시도 사용하지 않는다.

## 검증·결과

- 백엔드 전체 단위 389개·관련 통합 18개 통과. 마지막 제목 축약·독립 절 우선 선택 보완 후 단위 10개와 원문 통합 8개 재검증 통과, `bootJar` 성공. 추가된 절 제목 선택 테스트가 발견한 `입주자격/자격기준` 분류 누락을 수정했다.
- 프런트 전체 297개 중 기존 문구 기대값 1개를 새 영역별 안내에 맞춰 보완했다. 나머지 296개 통과 후 해당 App 테스트 38개·원문 조회 6개를 재검증했고 모두 통과했다. lint·계층/순환/선택자 계약·타입·최종 build 통과. 기존 500kB 번들 경고는 유지된다.
- 실제 5173 API에서 인천논현2·구미 다세대 두 검수 중 공고를 확인했다. 각각 조건/서류/일정 3개씩의 발췌가 저장된 원문 파트 전체와 동일하며, 구미의 EMPTY 첨부는 포함하지 않았다. `guideState=REVIEWING`, `canStart=false`, 질문·개인별 서류 빈 배열, GET 전후 공고 값 동일, `no-store` 확인. 진행 중 발췌의 장항성주 공고는 `PENDING`, 구간 0개다.
- 393×852 조건 원문, 360×800 서류 원문·일정 탭을 브라우저로 확인했다. 가로 넘침·콘솔 오류 없음, 원문 펼침·출처·자료 확인일·공식 원문 경로 표시 확인. 긴 파일명은 근거 링크에 두고 카드 제목은 원본 위치만 표시한다. 읽는 동안 접힘 상태가 초기화되지 않도록 주기적 자동 재조회를 제거했다. 실제 기기 검증은 하지 않았다.
- 최종 재시작 backend PID63160/frontend PID52132, health 확인. 기존 승인 공고 5개 원고·버전·revision 및 개인 준비 0행 digest 전후 동일. 5174/5184 및 원격 저장소는 변경하지 않았다.
- 근거: `docs/reviews/2026-11-08-source-information-runtime.json`, `.tools/qa/source-information/`의 검사·재시작 로그와 보존 비교. 작업 종료 branch/HEAD는 시작과 동일하다. 커밋·push·배포 없음.

## 기여·한계

원문 발췌의 열람과 개인별 준비 안내 승인을 분리했다. 읽을 수 없는 원문은 계속 대기 상태이며, 발췌를 보았다는 이유로 준비 완료·자격 충족이 되지 않는다. 실제 기기 및 운영 배포는 이번 범위가 아니다.

## 발표·포트폴리오 메모

공고 전체 검수 상태 때문에 확인 가능한 원문까지 숨겨지던 문제를, 현재 자료에 연결된 읽기 전용 원문 표시로 보완한다. 담당자 확인 전 개인 기여로 사용하지 않는다.

## 후속 작업

- 새 수집 자료도 현재 발췌가 준비되면 같은 조회 경로에서 표시한다. 개인별 안내 승인과 확정 일정 공개는 별도 자동 검수 계약을 계속 따른다.
