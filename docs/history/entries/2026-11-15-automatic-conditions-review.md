# 신규 모집의 정정 대조와 조건 요약

- 기록일: 2026-11-15 (Asia/Seoul)
- 작업 상태: 로컬 반영
- 기여: 사용자 요청에 따른 AI 보조 구현과 검증. 기관의 유권해석은 별도다.

## 배경·문제

접수 중·예정 공고를 검수할 때 실제 정정 공고와 연결된 후속 자료도 찾아야 한다. 원문의 PDF 쪽수나 한글 문단을 가리키는 근거에 대해 기존 비교가 파일 주소만 검사하면서, 특정 서류의 문제를 전체 안내 보류로 처리할 수 있었다.

## 결정·변경

- 원공고와 정정 페이지의 직접 연결, 또는 공식 정정 이력과 양쪽 상세가 일치할 때 같은 모집으로 연결한다. 후속 공지의 링크가 다른 모집을 가리키면 제목만으로 적용하지 않는다. 최종 게시 시 동일한 발견·검증 절차를 다시 수행한다.
- 파일 지문과 물리 쪽·문단 위치가 맞으면 확인 표시를 해당 항목으로 한정한다. 소득 심사 생략·접수 순서 선정이 명시된 모집은 해당 목적의 증빙과 일반 세대관계 서류를 나눠 설명한다. PDF의 제출 대상 문구에 발급처 열이 섞인 경우에는 공식 한글 양식의 같은 목적 문구도 필요하다.
- 확정된 정정값으로 나이·무주택·금액 기준을 쉬운 문장으로 만들고 예외와 숫자는 보존한다. 발췌 위치 안내는 세부 설명에 남긴다. 읽기 실패, 자료 변경, 비교 불완전은 재검수 사유로 처리한다.
- 수집된 필드에 실제 충돌이 남으면 기존 검수 절차로 해당 조건을 표시한다. 기존 자동 검수의 접수종료 제외 및 관리자 원고 보호를 따른다.

## 검증과 한계

익산한스빌 공식 PDF 파일의 지문을 실시간으로 확인하고 저장된 공식 PDF·HWPX 발췌를 사용해 소득 계산용 임신·입양 증빙, 가점용 가족관계 증빙 두 건의 목적 판정을 재현했다. 이 재현은 이미 검수된 공고 데이터를 갱신하지 않는다. 백엔드 단위 검사 및 검수·후속 게시 통합 검사, 프런트 조건 요약 검사와 빌드를 수행했다. 다음 신규 공고의 실제 예약 수집·게시 결과는 추후 확인 항목이다.

## 발표·후속 작업

같은 이름의 증명서도 제출 목적이 다를 수 있다. 목적이 명시된 경우에만 안내를 좁히며, 아직 읽지 못한 조항과 기관이 해석해야 하는 실제 충돌을 구분한다.
