# 일정 요약의 공통 표시

접수 기간·결과 발표·서류 마감을 홈, 상세, 내 준비, 이전 기록, 비교에서 같은 구성 요소로 표시한다. 접수 기간 한쪽만 있는 공고와 날짜 없는 개별 통지를 처리하고, 시간은 한국 시각으로 표시한다. 개인 이력은 당시 일정과 설명만 읽는다. 비교 화면은 대표 일정을 먼저 보여주고 세부 일정과 출처를 펼칠 수 있다.

AI 보조로 공고별·버전별 시각을 선정하는 경로를 정리했다. 전체 프런트 테스트 429건과 빌드가 통과했다. 5173 Chrome 360px와 390px에서 실제 개별 안내 공고 및 격리된 테스트 준비·이력을 사용해 다섯 화면의 일정과 설명을 확인했다.
관심 공고에는 공고 목록 미리보기의 신청 마감일과 D-day를 카드 하단에 표시한다. 마감일은 NoticeCardClosingDate, 남은 기한은 NoticeCardDeadline을 두 목록에서 공유한다. 마감 시각 전후 회귀 테스트를 포함한 전체 프런트 테스트 434건과 빌드가 통과했다. 5173 Chrome 360·390·768px에서 실제 공고 두 건을 체험 계정에 저장해 접수 중과 종료 공고의 날짜·기한 표시를 목록과 대조한 뒤 체험을 종료했다.
접수 기간의 시작·마감 시각을 각 날짜 바로 아래에 배치했다. 완주삼례A-1 공고에서 11월 9일 10:00부터 11월 20일 22:00까지의 짧은 날짜·전체 날짜 표시를 Chrome 360·390·768px에서 확인했다. 프런트엔드 테스트 464개와 빌드 통과.

2026-11-18 홈·공고 상세·비교·내 준비·이전 준비 기록의 일정 카드와 요약 배치를 `ScheduleCard.tsx`와 같은 이름의 CSS 모듈로 모았다. 대표 일정, 다음 일정, 상세 회차, 타임라인에 해당 화면의 날짜·상태·공식 근거를 전달한다. 개인 준비에서만 저장을 처리하고, 이력은 선택한 버전의 일정과 당시 완료 여부를 표시한다. 전체 프런트 테스트 502개와 빌드·린트·계층 검사를 통과했다. Chrome 360·390·768px 시연 자료로 홈과 상세에서 시작·마감 시각이 각각 해당 날짜 아래에 놓이는지, 내 준비에서 일정 카드를 열고 접을 수 있는지 확인했다.
