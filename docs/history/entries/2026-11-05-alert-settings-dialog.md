# 알림 화면의 설정 팝업

알림 화면에서는 상단 제목을 ‘알림’으로 표시하고 톱니바퀴 버튼으로 설정을 연다. 본문에는 공고 소식과 읽음 처리를 두고, 기존 설정 폼과 알림 수신 방법은 같은 팝업으로 옮겼다. 설정 조회·저장은 기존 회원 알림 API를 사용한다.

알림 팝업 회귀 테스트와 lint·빌드가 통과했다. 393×852 시연 환경에서 열기, 저장한 값 다시 열기, Esc로 닫힌 뒤 톱니바퀴로 초점 복귀를 확인했다. 360px에서도 팝업이 화면 폭 안에 들어왔다. 화면 기록은 `.tools/feature-qa/alerts-settings-modal.png`에 있다.
알림 이전 버튼은 앱의 직전 방문 기록으로 복귀하며, 직접 진입한 첫 화면이면 마이로 이동한다. 알림에서 이전 화면으로 복귀할 때 페이지 상단 이동을 생략한다. 공고 검색어·준비 건 조건 탭 복귀와 직접 진입을 포함한 관련 테스트 4개가 통과했다.
