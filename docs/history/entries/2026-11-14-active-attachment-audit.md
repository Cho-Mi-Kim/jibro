# 접수 중·예정 공고 첨부 재점검

- 2026-11-14 공개 상태 OPEN 11건, UPCOMING 26건의 LH 상세페이지 다운로드 목록과 5173 공고 상세 데이터를 읽기 전용으로 비교했다. 종료 공고는 조회 대상에서 제외했다.
- 158개 파일 모두 공식 사이트에서 다시 내려받고 실제 형식과 이전 추출 기록의 파일 해시를 확인했다. ZIP 내부 46개 파일도 확인했다.
- 5건에 첨부 목록 누락 15개가 있었다. 파일명 대조로 발급처 주소가 빈 서류 중 최소 17개 항목의 양식을 확인했다. AI 보조 조사이며 제품 데이터·검수 상태는 수정하지 않았다.
- 공고별 대조표와 공식 양식 링크는 [첨부 점검표](../../reviews/2026-11-14-active-attachment-audit.md)에 기록했다.
