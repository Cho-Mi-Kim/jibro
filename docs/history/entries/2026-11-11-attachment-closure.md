# 첨부 신청기간 자동 반영과 오래된 미종료 공고 보완

- 기록일: 2026-11-11 (Asia/Seoul)
- 기록 상태: 근거 정리·담당자 검토 전
- 작업 상태: 해결 (불확정 자료는 보류)
- 유형: 자동 수집 보완 / 자료 검수
- 담당·검토: AI 구현·공식 자료 대조·로컬 검증, 팀 검토 미확인
- 기준: feature/launch-integrations-20261107, e288a99. 기존 작업 트리 보존, 커밋·push 없음.

## 배경·문제

LH가 공고중으로 제공하지만 실제 첨부 접수기간이 지난 공고가 기본 목록에 남았다. 전체 준비 안내 검수가 끝나야만 기간을 게시하는 기존 경로에서는 조건·서류의 보류가 확정된 접수기간까지 가렸다. 사용자는 현재 자료 보완과 향후 자동 반영을 요청했다.

## 고려한 선택지

- 공고 연도나 LH 게시 종료일로 임의 종료: 실제 신청기간과 달라 제외.
- 전체 준비 안내 검수를 완화: 기간 확인과 자격 해석은 별개여서 제외.
- 공식 원문에서 확인한 신청 경계만 독립적으로 반영: 채택.

## 결정·이유

`ApplicationPeriodCompiler`가 기존 범위 검증·일정 해석을 재사용한다. PDF/HWP 변형본은 모두 대조하며 명시적인 신청일시/방법/장소 표만 추가 지원한다. 순위별 합쳐진 셀, 불명확한 열, 날짜 충돌, 읽기 실패, 종료일 없는 후속 선착순 계약은 자동 확정하지 않는다. 분양권 소유 판정의 법령 문구와 분양사무소 운영기간은 신청 연장으로 오인하지 않는다.

## 변경·해결 과정

- `ApplicationPeriodReviewService`와 worker: 최신 revision·출처 지문·행 잠금·수동 검수 보호 후 신청 시작/마감만 저장. 조건·서류·준비 안내 상태·개인 기록 보존. V36 `application_period_review`에 APPLIED/HOLD/UNCHANGED와 근거 지문·정책 기록.
- `ApplicationTableReader`와 `ScheduleSourceReader`: 명시 연도, 날짜 범위, 일별 시각 지원. 다른 날짜 열을 임의 결합하지 않는다.
- 수집이 다시 LH 공고중을 받아도 확인된 기간은 보존한다. 기존 `ApplicationPeriod`가 실제 접수 종료를 계산한다. 이미 종료된 공고는 일반 첨부 큐 등록/선점에서 제외하며 명시적 단건 검토는 유지한다.
- 현재 미종료 범위 82건의 공식 본문·첨부를 재조회했다. 모든 첨부가 읽힌 것은 아니며 실패를 성공으로 대체하지 않았다. PDF 화면과 HWP를 대조해 12개 데이터(목록 공고 11개 + 이미 숨겨진 원공고 1개)를 종료 반영했다. 5개는 새 자동 경로, 복잡한 표 등 7개는 최신 바이트 SHA를 대조한 명시적 검토로 처리했다.
- 상세 근거·파일 SHA·날짜·처리 방식은 [반영 감사](../../reviews/2026-11-11-attachment-closure.json)에 보관한다. 서로 다른 추가모집/잔여세대 모집을 합치지 않았다.

## 검증·결과

- `test --tests '*ApplicationPeriod*' --tests '*AutomaticScheduleCompilerTest' --tests '*ScheduleSource*'`: 단위 74개 통과.
- `integrationTest --tests '*ApplicationPeriodReviewIntegrationTest' --tests '*AutomaticPublicationIntegrationTest' --tests '*Extraction*IntegrationTest'`: DB 통합 61개 통과. `bootJar` 성공.
- 기간만 게시, 미래 기한, 중복 실행, 오래된 발췌/변경 지문, 수동 원고, 기존 시각 충돌, 재수집 보존, 종료 공고 일반 큐 제외와 명시 선점 검증.
- 실제 5173 API에서 12개 CLOSED·날짜·마감 시각·준비 안내 상태 보존 확인. 기본 목록 80→69. 28일 이상 지난 공고는 기존 목록 정책에 따라 제외되고 상세는 보존된다.
- 새 jar로 백엔드 재시작, 5173의 health/database UP. 프론트엔드 코드는 변경하지 않았다.

## 기여·한계

기한만 확인된 공고를 전체 안내 승인 없이 정리했다. 82건 모두 준비 안내 검수를 완료했다는 뜻은 아니다. 다음 오래된 4건은 종료로 추정하지 않았다.

| 공고 | 남긴 이유 |
| --- | --- |
| 강원혁신 B2 | 최신 공식 PDF/HWP가 정상 문서로 내려오지 않음. 재조회도 실패 |
| 평택소사벌 B5 2014년 10월 잔여세대 | 초기 접수 후 10월 30일부터 도착순 계약, 종료일 없음 |
| 충북혁신 B7 | 12월 15일부터 공급 종료 시까지 선착순 계약 |
| 논산내동2 A1 | 11월 4일부터 선착순 동호 지정 즉시 계약, 종료일 없음 |

자동 처리의 지원 문법 밖인 표나 미검증 OCR을 임의 승인하지 않는다. 실제 신규 공고가 들어왔을 때의 장기 운영과 원격 배포는 이번 로컬 검증에 포함되지 않는다.

## 발표·포트폴리오 메모

공고 게시 상태와 신청기간을 분리하고 첨부 근거·현재성·감사를 유지하면서 기간만 독립적으로 반영했다.

## 후속 작업

최신 공고문 오류가 복구되거나 선착순 종료 공식 자료가 게시되면 해당 근거로 다시 확인한다. 현재 미확정 공고를 공고일만으로 종료하지 않는다.
