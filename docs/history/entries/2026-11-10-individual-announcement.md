# 확정 날짜 없는 결과 발표를 개별 안내로 표시

- 기록일: 2026-11-10 (Asia/Seoul)
- 기록 상태: 근거 정리·담당자 검토 전
- 작업 상태: 해결
- 유형: 개발 / 문제 해결
- 담당·검토: 사용자 요구, Codex 구현·검증 보조. 팀 검토 미확인
- 관련 이슈·PR·커밋: 미등록, 로컬 변경

## 배경·문제

사용자는 2026년 신혼·신생아 전세임대Ⅱ 수시모집의 결과 발표가 비어 있어 `개별 안내`로 표시하고 클릭 시 최소 10주 소요 설명을 요청했다. 공식 공고문 4쪽은 소득·자산 확인이 필요한 경우 신청일부터 최소 10주, 증빙 대상별 단축 가능성, 서류·검증에 따른 지연 및 SMS·이메일 개별 안내를 명시한다.

## 고려한 선택지와 결정

화면에 특정 공고 ID와 설명을 직접 넣는 대신 공식 근거가 있는 날짜 미정 일정으로 모델링했다. 임의의 발표일을 만들지 않고 날짜가 확정된 결과 일정과 구별한다. 최소 10주를 모든 신청자에게 무조건 적용하는 표현은 피하고 원문의 조건을 함께 표시한다.

## 변경·해결 과정

ScheduleTemplate/Schedule의 선택 필드 timingDescription, 기존 생성자 호환, 검증과 준비 스냅샷 복사를 추가했다. IndividualAnnouncement 공통 팝업을 공고 상세·공통 날짜 요약·준비 일정에서 사용한다. 날짜 없는 일정은 캘린더 및 기한 알림의 유효 날짜 선택에서 제외된다.

로컬 대상 공고 11f5a8d1-3100-4d80-8f4b-b0ef6dc8af3c의 공식 상세 전체 문맥과 첨부 11개 SHA를 재대조했다. 최신 발췌 및 source review 검증·수정 게시 경로로 결과 발표 안내 1개만 추가했다. 질문 17개·서류 29개·검토 이슈 0개는 유지했다. 다른 공고를 일괄 처리하지 않았다.

## 검증·결과

- 프런트 관련 5파일 34테스트 통과: 팝업 열기/닫기, 고정 날짜 우선, 날짜 없는 일정의 캘린더 제외 및 기존 일정 회귀.
- 백엔드 NoticeSchedulesTest, ApplicationPeriodTest, ReviewedApplicationPeriodTest, IndividualAnnouncementIntegrationTest, SourceReviewPublicationIntegrationTest: 63테스트 실패 0.
- 타입 검사, 변경 TS 파일 ESLint, 프런트 빌드, 백엔드 bootJar 통과. 프런트 번들 크기 경고는 기존과 같이 남는다.
- 5173 재연결 후 실제 공개 API에 설명 반영 확인. 브라우저 393×852, 360×852에서 버튼 → 팝업 → 닫기, 본문·근거 표시와 화면 내 수용을 확인. 실제 휴대폰 검증은 미실행.

## 기여·한계

공식 원문 근거의 개별 결과 안내를 데이터와 공통 UI로 연결했다. 이 작업은 해당 공고의 검증된 안내를 반영했으며 모든 향후 공고에서 소요 기간을 자동 추출한다고 보장하지 않는다. 원격 게시·운영 배포·push는 하지 않았다.

## 발표·포트폴리오 메모

고정 날짜가 없는 결과를 누락으로 오인하는 문제를 근거가 있는 개별 안내 상태로 표현하고, 날짜가 필요한 알림과 분리했다.

## 후속 작업

사용자 후속 요청에 따라 `개별 안내`로 명시된 결과 일정에만 버튼을 표시하도록 선택 조건을 제한했다. 날짜가 없거나 일반 설명만 있는 결과를 개별 안내로 변환하지 않는다. 최소 10주 설명은 해당 공고의 검증된 데이터이며 다른 공고의 기본 문구가 아니다.

사용자 화면 확인. 공식 발표 방식 변경 시 동일한 출처·revision 검증 경로로 갱신한다.
