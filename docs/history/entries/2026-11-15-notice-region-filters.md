# 지역 필터의 ‘외’ 중복 선택지 통합

공개 검색 조건 24개에 대구·대전·부산·서울·세종·인천·전남광주 7개 지역의 ‘외’ 표기가 별도 항목으로 포함돼 있었다. 기본 범위에서 대구광역시 단독 검색은 0건이었고 대구광역시 외 검색은 2건이었다.

NoticeQueryRepository는 지역명과 ‘지역명 외’를 같은 필터로 조회하고 선택지에서 중복을 제거한다. 공고의 원본 지역과 모집 범위를 보존하며 명시되지 않은 추가 지역은 추정하지 않는다. NoticePages의 선택 상태는 기존 주소에 담긴 ‘외’ 필터도 같은 대표 지역으로 해석한다.

5173 재시동 후 7개 지역의 기본 목록을 변경 전 두 선택지의 공고 ID 합집합과 대조했다. 지역 선택지는 17개, 대구광역시 검색은 2건으로 확인했다. Chrome 브라우저에서 예전 검색 주소로 진입해 대표 선택지가 체크되는 것을 확인했다. AI 보조 구현·검증.
