# 공고 모집 지역과 주택 유형의 공통 표시

홈·목록·상세·내 준비·비교에서 지역과 유형을 직접 조합하던 경로를 `housing/noticeHousingFacts.ts`로 연결했다. 내 준비의 개요와 조건·서류·일정에도 주택 유형을 표시한다. 한 줄 요약과 항목별 표시, 비교의 차이 표시는 같은 공고 데이터를 사용한다. 이미 공급 지역이 확인된 값을 사용하며 비어 있는 항목은 ‘확인 필요’로 표시한다.

AI 보조로 표시 경로를 정리하고 여러 지역·전국 모집 및 비어 있는 주택 유형의 비교 테스트를 추가했다. 프런트엔드 테스트 431건, 변경 파일 ESLint와 빌드 통과. 5173 Chrome의 360·390·768px에서 실제 대구·경북 매입임대와 전국 전세임대를 비교했다. 대구·경북 공고의 홈, 목록·미리보기, 상세, 내 준비 개요·서류도 확인했다. 개인 준비 응답은 격리된 테스트 자료를 사용했으며 실제 기기 검증은 수행하지 않았다.
관심 공고에도 기관·지역·유형 공통 요약을 적용했다. 관심 목록 응답에 주택 유형을 추가하고 공고 목록과 같은 원문 버전 기준으로 모집 지역을 일괄 조회한다. 회원 기능 및 공급지역 통합 테스트와 프런트 빌드 통과. 5173 재시작 후 격리된 임시 체험 계정으로 실제 대구·경북 매입임대 및 전국 전세임대를 저장해 두 목록의 값 일치와 360·390·768px에서의 표시를 확인하고 체험을 종료했다.
