# 현재 공고의 날짜별 방문 접수 일정 재검수

2026-11-17 공개 목록의 접수 중 18건과 접수 예정 60건을 다시 조회했다. 모집별 현행 LH 첨부 목록과 PDF·한글 자료 249개의 지문이 앞선 공식 원문 대조 시점과 일치했다. 새 방문 접수 검수 결과와 기존 공개 회차를 비교하고 기간만 표시된 공고는 원문의 날짜·휴무일·접수처를 확인했다.

원주시지역, 경주·영천, 수원우만3, 익산한스빌, 충주연수2, 밀양가곡1, 원주명륜2, 증평송산5의 일정에 방문 접수 36일을 표시했다. 원주시지역과 원주명륜2는 LH 첨부의 10:00~17:00와 원주시 게시문의 09:00~18:00를 출처별로 보여준다. 수원우만3은 LH 공고문의 점심 12:00~13:00와 우만2동의 13:00~14:00 안내를 구분했다. 사전 연락이 확인된 인천산곡 A1은 기존 회차에 대상·연락처·기한이 표시되어 있었다.

변경 직전 버전과 접수 상태를 확인하고 8건의 일정과 근거를 함께 저장했다. 저장 뒤 공개 상세 78건과 390px 브라우저에서 변경된 8건의 공식 접수 일정 및 회차별 시간 표시를 확인했다.
