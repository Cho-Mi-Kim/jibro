# 모바일 홈 조정과 참고 이미지 기반 벽돌 진행도

- 기록일: 2026-11-04 (Asia/Seoul)
- 기록 상태: 근거 정리·담당자 검토 전
- 작업 상태: 해결
- 유형: 개발 / 사용자 피드백
- 담당·검토: 사용자 요구 확정, Codex 구현·검증 보조, 별도 담당자 검토 미확인
- 관련 이슈·PR·커밋: 미등록. 로컬 feature/local-mobile-screens-20261103, 기준 ebccaa7

## 배경·문제

사용자는 5173 모바일 홈을 393×852에서 확인하며 상단 안내·공고 선택칸·체험 상태 문구 제거, 준비도 설명 접기, 여백 축소, 짧은 공고 제목, 구분선 제거를 순서대로 요청했다. 이어 나무 지붕과 적갈색 벽돌이 있는 이미지를 첨부하고 준비도에 따라 벽돌이 늘고 줄도록 요청했다. 기존 SVG는 집 단계별로 큰 덩어리만 바뀌고 0%에서도 벽돌이 보였다.

## 고려한 선택지

PNG 전체를 그대로 표시하면 벽돌 단위 변화가 어렵다. 기존 SVG 컴포넌트를 참고 이미지 형태로 다시 작성하면 독립된 벽돌과 반응형 크기·대체 설명을 유지할 수 있다.

## 결정·이유

문서의 벡터·미완료 윤곽·서버 결과 원칙에 맞춰 SVG를 사용한다. 서버 준비도 산정과 집 단계 계약은 유지하고 27개 벽돌 표시 수만 진행률에 대응시킨다. 문·창문을 새로 붙이던 종전 그림 대신 첨부 이미지의 목재 지붕·잔디·여분 벽돌 형태를 따른다. 감소는 사용자 기록 변경 반영이며 실패 벌점이나 시간 경과에 의한 퇴화가 아니다.

## 변경·해결 과정

- `BrickHouse`, `brickHouseLayout`, `BrickHouse.module.css`로 그림·좌표·전환 스타일 책임을 구분했다. `House`가 progress와 stage를 함께 전달한다.
- 0% 빈 벽, 100% 전체 벽, 중간값은 아래부터 순서대로 쌓인다. 모션 줄이기 설정에서는 전환하지 않는다. 여러 집을 함께 표시해도 SVG 색상 참조가 겹치지 않는다.
- 앞선 사용자 요청으로 제거된 홈 선택칸을 찾던 테스트 3개를 현재 공고 목록의 홈 보기 경로와 기존 선택 기록 유지 검증으로 갱신했다. 모바일 짧은 제목과 원래 제목의 중복 낭독도 수정했다.
- 앞선 홈 문구·간격 수정은 사용자 요청으로 이미 반영된 변경이며 이번 작업에서 새로 구현했다고 구분하지 않는다. 준비도 설명은 접힌 상태로 유지하고 로그아웃 기록 삭제 안내는 유지한다.

## 검증·결과

- `npm run ci`: 포맷·린트·타입 검사·38개 테스트(8개 파일)·production 빌드 통과. 신규 3개 테스트는 진행률 증감/100% 경계, 미확인 값, SVG 참조 독립성을 검증한다.
- 별도 임시 QA 화면에서 실제 컴포넌트로 0→25→65→99→100→25% 선택 시 벽돌 0→6→17→26→27→6개 확인. 360px 및 393×852에서 가로 넘침 없음. 임시 QA 화면은 검증 후 제거한다.
- 실제 5173 홈의 서버 준비도 0%와 빈 벽 그림을 확인했다. 사용자 기록은 검증 목적으로 변경하지 않았다.
- 모바일 확인은 브라우저 크기 검증이며 iPhone 실기기 검증은 아니다. 모션 줄이기는 CSS 분기로 구현했으며 OS 설정 전환 검증은 별도로 수행하지 않았다.

## 기여·한계

참고 이미지의 형태·색감을 재현한 벡터이며 원본 PNG의 질감과 픽셀 단위로 동일하지 않다. 준비도·자격 계산 및 백엔드 변경은 없다. 커밋·push·배포 없이 로컬에 적용했다.

## 발표·포트폴리오 메모

서버 준비 결과를 재계산하지 않고 모듈화된 벽돌 SVG로 시각화했다. 사용자 효과나 개인 기여 수치는 측정하지 않았다.

## 후속 작업

- 실제 iPhone에서 시각적 크기와 모션 줄이기 설정을 확인할 수 있다.
