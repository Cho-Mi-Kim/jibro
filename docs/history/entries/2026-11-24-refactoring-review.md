## 유지·기각 판단

- PDF HTTP 용량 필터와 문서 워커 감독: 다운로드/응답 전송과 파서 프로세스라는 서로 다른 실제 경계다. 단순 이중 guard로 삭제하지 않는다. 주 서버 직접 PDF 렌더 경로는 이미 제거됐고 공유 프로세스 감독을 사용한다.
- 원문 SHA·게시 직전 재확인·DB revision: 변하는 외부 원문과 긴 수집 중 동시 변경을 구별하는 실제 소비자가 있다. 일괄 삭제하지 않는다.
- 서버/브라우저 개인화 두 구현: 서로 다른 실행 환경과 공유 어휘·계약 사례가 있으므로 같은 프로세스 안의 평행 구현으로 단정하지 않는다.
- 정적 시연 어댑터: 실제 서버 없는 실행 환경의 소비자다. 오래된 이름만으로 삭제하지 않는다.
- 공고별 다른 문구·표·숫자·예외: 유지할 데이터다. R3의 대상은 반복된 적용 판정 책임이다.
- 테스트의 호출 횟수: 중복 저장 방지·비저장·재시도 한도를 관찰하는 경우 유효하다. 문법만 보고 삭제하지 않는다.
- 비밀번호 재설정의 외부 응답 동일화: 계정 존재 여부를 숨기는 의도된 계약이므로 오류 메시지를 차등 노출하는 수정은 제안하지 않는다.
- questionAnswerInput의 표시용 옵션 참조: 값 검증을 원래 options로 분리하면 좋으나 현행 치환은 label만 바꾸므로 현재 유효성 오류로 확정하지 않았다. 후속 책임 정리 관찰로 남긴다.

## 검증·검토 처분

- 현재 ESLint 통과. 개발 환경 초기화 전 npm PATH 누락은 코드 실패와 구분했다.
- check:boundaries: 검사10개 통과, TS368개·CSS91개 계층·실행 순환·선택자 계약 통과. 구조 지도 --check는 fresh. 이 검사는 위 의미·실패 처리 문제를 모두 검출하지 않는다.
- 독립 frontend/backend 검토 지적은 R1/R2/R3/R5/R6으로 채택했고 주 검토자가 실제 코드를 재대조했다. 독립 검토의 낮은 우선순위 표시 의존 후보는 위 관찰로 분리했다. 나머지 보호 경계 기각 사유는 위에 기록했다.
- Iron Laws 전용 분석 도구와 외부 GPT Pro 기존 대화 연결은 확인되지 않아 미실행이다. ESLint·독립 에이전트 검토를 그 도구의 완료로 표시하지 않는다.
- 앱 코드/새 시험을 변경하지 않아 이번에는 mutation 검사, 전체 빌드/전체 회귀, 브라우저·실기기·외부 서비스 검증을 수행하지 않았다. 앞선 보안 작업의 백엔드1451개 통과를 이번 변경의 검증이라고 재사용하지 않는다.
- 정적 코드 근거로 확정한 구조/실패 처리 부채와 실제 사용자 화면에서 재현한 장애를 구분한다. 이번에는 후자를 주장하지 않는다.

## 권고 구조·추진 순서

검수는 수집·재확인·저장을 작업 서비스가 맡고, 하나의 순수 판정이 게시와 관리자 미리보기에 후보를 제공한다. 화면은 하나의 출처/답변 계약 판정을 통과한 공고별 표시 데이터를 소비하며, 실패는 데이터 적용 상태로 드러낸다. 비밀번호 실패 정책은 auth의 공통 책임으로 모으되 목적별 증명 바인딩은 보존한다.

먼저 R1/R2/R6의 실패·판정 불일치를 해결한다. 이어 R3/R4의 책임과 정책 범위를 정하고 실제 소비자를 함께 바꾼다. 마지막으로 R5/R8/R9의 대체된 경로·시험을 삭제하고 R7의 현행 문서를 맞춘다. 파일 크기만 줄이는 분할이나 새 wrapper 추가는 해결로 세지 않는다.

## 추가·삭제·한계·후속 작업

추가한 것은 이 검토 기록과 메타데이터 작업 기록뿐이다. 삭제한 제품 코드 없음, 새 제품 임시 코드 없음. 이번 검토의 모든 채택 항목은 수정 미적용 상태이며 실제 구현 시 각 항목을 수정 또는 근거 있는 기각으로 처분한다. 독립 검토는 AI 보조 검토이며 사람의 승인·운영 성능 개선·외부 Pro 검토를 뜻하지 않는다. 커밋·push·운영 배포·설정 변경 없음.

## 후속 도구 실행

이 점검을 마친 뒤 사용자가 Iron Laws 저장소를 지정해 실행을 요청했다. 이후 실제1회 실행과 상위 지적 대조를 [별도 이력](2026-11-24-iron-laws-audit.md)에 기록했다. 위 ‘미실행’은 최초 수동 점검 시점의 사실이며 현재 도구 실행은 완료됐다. R1~R9의 수정 미적용 상태와 외부 GPT Pro 미검토 상태는 유지한다.
