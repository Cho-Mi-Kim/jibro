# 기존·신규 공고의 서류 발급처 자동 연결

- 요청과 결정 — 거창 공고 ID에 묶였던 안내를 공고 상세, 비교, 내 준비의 공통 규칙으로 옮겼다. 공식 첨부 경로가 있으면 우선하고, 링크가 비어 있으면 검수된 서류명을 확인한다. 등록증 사본, 방문 발급, 은행별·공고별 양식을 구분한다.
- 구현 — `frontend/src/features/housing/onlineIssuance.ts`와 `DocumentIssuanceLinks.tsx`에서 처리한다. 수집 결과를 표시할 때 계산하므로 기존 준비 기록과 앞으로 공개되는 서류 모두 재수집 없이 적용된다. 사용자 답변·증빙·서류 상태를 외부로 전송하지 않는다.
- 확인 — 5173 기본 목록 54건 중 서류 공개 47건. 969개 중 기존 주소 68개, 빈 주소 901개에서 351개에 공식 링크를 새로 연결했다. 550개는 현 규칙으로 연결할 발급처를 특정하지 않았다. 주소 수와 공고별 서류 항목 수는 별도로 집계했다.
- 검증 — 기관 서비스 25개 HTTP 200. 5173 완주삼례A-1 공고 제출서류 화면에서 정부24·법원 링크를 Chrome 모바일 크기로 확인했다. 관련 테스트 50개, 경계 검사, ESLint와 빌드 통과. 실제 인증 발급은 미실시.
- 기여·후속 — AI 보조 구현. 새로운 증명서는 공식 서비스명·제출 목적·실제 공개 주소를 확인한 뒤 공통 규칙에 추가할 수 있다. 실제 공통 발급처가 없는 계약서 사본 등은 공고 안내를 이용한다.
