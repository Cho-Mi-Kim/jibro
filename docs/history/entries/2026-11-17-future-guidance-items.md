# 신규 LH 공고의 세부 자격·서류 항목 대조

2026-11-17 · 개발 · 로컬 실행 검증 · 팀 검토 전

## 배경과 결정

현재 공개된 43건의 검토 결과를 다른 모집에 복사하면 적용 대상이나 예외가 달라질 수 있다. 예약 수집에서 이번 모집의 공식 자료를 다시 읽고, 명시된 항목과 정정 관계를 근거로 판단한다.

## 구현

공식 HTML의 열 이름, PDF의 분리된 열, HWPX 표의 셀 주소와 병합 범위로 자격·배점·제출 대상·발급처를 연결한다. 해석할 수 없는 인접 행도 검수 대상에 남긴다. 동일한 구간 안에서 명시된 고유 항목의 순서만 바뀐 경우를 구분한다. 필수 서류와 원문에 명시된 제출 면제를 구분한다.

정정 전후 표 외에 전체 정정본도 대조한다. 한 항목이 한 번만 등장하고 앞뒤의 다른 조항과 예외까지 일치할 때 변경을 적용한다. 같은 날 두 번 정정한 경우 공식 원공고 연결이 확인되면 그 순서를 따른다. 새 자료 대조·원문 지문 재확인·공개 직전 종료 확인은 기존 예약 검수와 게시 트랜잭션을 사용한다.

공식 자료의 명시적인 기관 문의 또는 같은 항목의 미해결 충돌은 해당 항목과 종속 서류에 연결한다. 원문 미수신, 읽기 실패, 정정 관계나 예외의 적용 범위를 확정하지 못한 경우에는 재검수한다.

## 검증과 한계

백엔드 테스트 714개 통과. 공식 HTML 정정표, PDF 열과 근거 쪽, HWPX 서류 표, 동시 충돌, 연속 정정, 기관 문의, 제출 면제, 부분 공개 후 준비 시작을 검증했다. 수정한 Java 파일 18개에 프로젝트 IntelliJ 서식을 적용했다.

기존 공식 원문 43건을 읽기 전용으로 재생한 결과 38건에서 이 방식으로 서류 행 698개, 자격·배점 행 340개를 읽었다. 여러 자료의 같은 항목도 각각 집계한 판독 수치다. 전체 자동 승인 건수와 구분한다. 배포 파일 지문과 5173 서버·DB 정상 응답을 확인했다. 기존 공개 상세 43건에서 준비 안내, 질문 549개, 서류 1,673개, 일정 192개가 조회됐다.

미래의 실제 신규 공고가 들어와 게시되는 경우는 아직 관찰하지 않았다. 새로운 표나 해석되지 않은 조항이 다른 항목에도 영향을 줄 수 있으면 공고 전체의 자동 게시가 보류될 수 있다.

## 기여와 후속 확인

AI 보조로 서버 구현과 검증을 수행했다. 실제 후속 모집에서 원문 대조 결과와 재검수 사유를 확인할 수 있다. 이번 작업의 범위는 자동 검수와 로컬 서비스 반영이다.

## 기존 형식 5건 재현과 항목 공개

2026-11-17 후속 검증. 파주운정 A4·A20의 자격 본문·병합 서류 표, 서귀포동홍3의 OWPML, 대전문화1의 병합 구비서류·비고 표, 대전·충남 든든전세의 배점·발급처 표를 반영했다. 원문 43건 재생에서 43건에 명시적인 항목이 나왔다. 여러 자료에서 반복되는 행을 포함해 서류 888행, 자격·배점 368행이다.

접수 날짜를 미리 입력하지 않은 별도 테스트 DB에서 기존 원문 5건으로 신규 수집 과정을 재현했다. 공식 정정 탐색과 LH 첨부 재요청, 파일 지문 확인, 날짜 판정, 저장, 공개용 조회를 거쳤다. 다섯 공고 모두 접수 예정으로 판정됐고, 파주운정 A4 8개, 서귀포동홍3 3개, 대전문화1 4개, 대전·충남 든든전세 5개, 파주운정 A20 8개 항목이 각 PDF 근거 쪽과 함께 조회됐다. 검수 중에도 확정된 내용은 공고 상세 조건·제출서류 탭에서 볼 수 있다. 신청 서류와 계약·분양전환 단계의 부속서류를 구분한다. 새로운 정정자료나 바뀐 자료를 검증하지 못하면 기존 자동 대조 결과를 공개하지 않는다. 접수가 끝나면 이 항목 공개 경로에서도 제외한다.

기존 공개본 5건에는 이미 검토된 준비 안내가 있어 재작성하지 않았다. 5173 재시작 후 서버와 DB, 기존 공개 자격·서류를 확인했다. 이후 실제로 처음 게시될 공고에 대한 관찰은 별도다.
최종 검사에서 백엔드 단위 테스트 718개, PostgreSQL 통합 테스트 370개, 프런트엔드 테스트 473개가 모두 통과했다.
