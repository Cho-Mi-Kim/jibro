# 공고 운영기관의 이름·로고 표시 통합

목록과 상세에서 사용하던 공식 LH 워드마크를 홈, 내 준비, 공고 비교에도 적용했다. 약칭·정식 명칭·로고 자산은 `housing/noticeAgency.ts`에서 관리한다. 등록된 LH의 표기 차이는 비교에서 같은 기관으로 처리하며 공동모집 이름은 원래 이름으로 구분한다. 기관 로고가 있으면 대체 텍스트에 기관 이름을 제공한다.

AI 보조로 요약·선택·비교 표시 경로를 점검했다. 전체 프런트엔드 테스트 432건, 변경 파일 ESLint와 빌드 통과. Chrome 360·390·768px로 5173의 실제 LH 공고를 열어 다섯 화면에 같은 로고 파일이 표시되는지 확인했다. 내 준비는 격리한 개인 준비 응답을 사용했고 실제 기기 검증은 수행하지 않았다.
관심 공고 목록에도 같은 운영기관 표시를 적용했다. 로컬 Chrome 360·390·768px에서 테스트용 관심 공고의 LH 로고 파일이 목록의 CI와 일치하고 다른 기관명과 지역도 읽히는지 확인했다. 변경 파일 ESLint와 빌드 통과.
