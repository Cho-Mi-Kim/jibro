# 공고 상세 조건 카드의 기본 요약 축소

- 기록일: 2026-11-15
- 배경: 조건 카드마다 모든 설명과 예외를 연달아 표시해 핵심을 훑기 어려웠다.
- 결정: 공고 상세 조건 탭에만 짧은 미리보기를 적용했다. 성년 조건은 기본 연령과 미성년 예외 여부를 함께 표시한다. 자동차 기준은 확인된 한도부터 보여준다. 전체 원문과 근거는 기존 펼침 동작으로 읽을 수 있다.
- 검증: 조건 상세·요약 검사 21건과 프런트 빌드 통과. Chrome 360px와 390px에서 익산한스빌의 긴 조건 미리보기 15개가 최대 두 줄로 표시되고, 성년 항목을 펼치면 미성년 대리 신청 설명까지 보이는 것을 확인했다.
- 기여·한계: AI 보조 구현과 브라우저 검증. 실제 기기 검증은 수행하지 않았다.

## 쉬운 표현으로 다듬기

기본 카드의 제목과 문장을 신청자 관점에서 다시 작성했다. 예를 들어 자격검증 대상 세대원은 ‘누구까지 함께 심사하나요?’로 표시한다. 펼친 설명에서도 미성년 세대주의 예외를 경우별로 나눴고, 증빙·무주택·차량 가격과 관련된 표현을 풀어 썼다. 연령 기준일, 제한·예외, 금액과 단위는 공고 문구를 따른다. 360px·390px Chrome에서 익산한스빌의 연령·가족 조건과 펼친 예외를 확인했고, 관련 프런트 검사 22건이 통과했다.
## 내 준비의 조건 카드

내 준비에서 추가 확인할 조건과 답변 완료 조건을 볼 때도 공고 상세의 쉬운 제목·미리보기·펼친 설명을 사용한다. 관련 화면과 요약 검사 69건 및 프런트 빌드가 통과했다. 5173에서 실제 익산한스빌 공고 질문을 테스트 준비 기록에 넣어 Chrome 360px·390px로 열고, 연령 조건의 제목과 펼친 미성년 예외, 가로 넘침 여부를 확인했다.
## 내 준비에서 답변할 때

질문 단계와 답변란에 같은 쉬운 제목을 표시한다. 접힌 상태에서는 공고 상세의 핵심 기준을 보여주고, 펼치면 숫자와 예외를 포함한 설명을 읽을 수 있다. 관련 검사 62건과 프런트 빌드가 통과했다. 5173에서 익산한스빌의 공개 질문을 테스트 준비 기록으로 열어 Chrome 360px와 390px에서 연령 질문 제목, 펼친 예외, 선택지 6개와 가로 넘침 여부를 확인했다.
## 공고 상세에서 이번만 조건 확인

일회성 확인과 내 준비에서 답변할 때 같은 쉬운 질문 제목·핵심 기준·펼친 설명을 사용한다. 5173에서 익산한스빌 공고의 ‘저장하지 않고 이번만 확인’으로 들어가 Chrome 360px·390px에서 미성년 예외를 펼치고, 다음 질문으로 이동했다가 돌아와 선택이 유지되는 것을 확인했다. 관련 검사 60건과 프런트 빌드가 통과했다.
## 일회성 조건 확인 결과

답변 완료 항목과 추가 확인 항목 모두 내 준비 결과와 같은 쉬운 제목과 설명을 사용한다. 익산한스빌 공고에서 일회성 질문 16개에 답해 결과로 이동하고 Chrome 360px·390px에서 연령 조건의 미성년 예외를 펼쳐 확인했다. 관련 검사 60건과 프런트 빌드가 통과했다.
