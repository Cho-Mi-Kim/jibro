# 현재 수집 공고의 개별 발표 누락 점검

## 배경·문제

사용자가 미래 자동 반영뿐 아니라 이미 수집한 미종료 공고도 다시 확인해 누락을 보완하도록 요청했다. 화면의 OPEN/UPCOMING만 보면 기간 미확정·상시모집 공고를 놓칠 수 있어, 저장된 공식 목록 상태와 실제 공식 상세를 함께 점검했다.

## 선택지·결정

종료일이 없다는 이유로 과거 전체 수집 공고를 미종료로 간주하지 않았다. 공식 API 저장 응답의 최신 URL별 상태를 조사하고 확인된 종료 공고는 변경 대상에서 제외했다. 확정 접수 중·예정 21건과 목록상 미종료 후보를 합쳐 84개 상세를 점검했다. 이 후보에는 과거 연도 18건이 포함되므로 84개를 모두 현재 접수 중이라고 주장하지 않는다. 2026년 공고 66건의 PDF86개를 포함해 총113개 PDF를 읽었다. 과거 공고의 다운로드 오류1건은 현재 반영 대상이 아니다.

## 변경·해결

- 전주시 전주평화1·4 영구임대(d5c5d9eb…): PDF11쪽 약3개월 소요 예상, 14쪽 신청일부터3개월 이후 발표 예상·자격검증 일정에 따라 변동·적격자 개별 문자 통보를 확인해 설명 추가.
- 남원노암 원공고(1f4cb367…): PDF6쪽(인쇄11쪽) 적격자 개별 통보 확인. 상세 화면2027.03.31과 첨부의 날짜 미확정 안내 차이를 설명에 표시. 정정공고에 이미 있는 설명과 별개의 원공고 누락이다.
- 일정1개씩만 추가하고 기존 조건·서류·요약·이슈·접수기간·안내 승인 상태는 보존했다. 전주는 기존 제공 상태, 남원 원공고는 기존 검수 중 상태를 유지한다. 전체 준비 안내를 승인한 것이 아니다.
- 수정 직전 공식 상세 상태·정확한 원문 URL 식별·첨부 소속·원문 SHA를 재조회하고, 잠금 하에서 revision·원고·종료 여부·확인 시각을 재검증했다. SourceReviewRepository에 일정 한정 명시적 수정 이력을 기록했다. 사후 개인정보·계정 변경 없음.
- 신규 발견한 `자격검증 결과 적격자에 한하여 개별 문자 통보 (신청일로부터 3개월 이후…)` 문법과 줄바꿈된 변동 안내를 자동 추출에도 추가하고 정책을 source-review-v9 / official-rules-v9로 변경했다. 임의 날짜나 공통10주 기본값은 없다.

## 검증·결과

- 신규 문구 회귀 포함 관련 단위51·PostgreSQL 통합11 테스트 통과. bootJar 성공.
- 두 원문을 실제 자동 추출기에 넣어 각각 개별 결과1개 생성 확인. PDF 원본 이미지로 전주14쪽·남원6쪽, 스캔 광주두암4 13쪽의 고정 발표일을 대조했다. 계약·소명·입주 개별 통보는 결과 발표로 바꾸지 않았다.
- 공개 API에서 새 설명2개 확인. 나머지82개 원고·버전 동일. 기존 개별 안내7건 보존. Content 직렬화에 따른 선택 필드 null/빈 reviewIssues 기본값만 정규화하여 의미 동일 비교.
- 종료27개 행은 collected_at을 제외한 전체 값의 전후 해시 동일, 개인 준비0행 해시 동일. 이번 명시적 수정으로 종료 공고 변경 없음.
- 5173 연결 백엔드를 backend-individual-auto-v9.jar로 교체했다. 기존 프런트 UI 재사용; 실제 기기 UI 검증은 별도 미수행.
- 실행 자료: .tools/qa/current-individual-audit-20261110의 official-check.json, amendments.json, applied.json, replay.json, validation.json, preserve-before/after.txt. 비밀값 없음.

## 기여·한계

AI 보조 구현·원문 대조·로컬 반영. 인간 담당자·검토자 미확인. 남원노암 정확한 발표일은 원문 간 차이가 있어 기관 확인 필요를 유지한다. 이 점검은 개별 발표 설명 누락에 한정하며 전체 공고의 자격·서류 재승인을 뜻하지 않는다. 다열표를 텍스트 근접도로 자동 확정하지 않는다. 원격 커밋·push·배포 없음.

## 발표·포트폴리오 메모

목록의 접수 상태와 결과 발표의 통지 방식을 분리하고, 상시모집처럼 단순 상태 필터에서 빠지는 공고의 누락을 찾아 출처 단위로 수정했다.

## 후속 작업

기관 확인이 필요한 남원 발표일은 후속 공식 자료를 대조한다. 새 문법은 실제 출처와 회귀 테스트를 함께 추가한다.
