# 서류별 제출 대상과 발급 방법 공통 적용

공고 상세·비교의 핵심 서류와 제출서류 전체 목록, 내 준비, 일회성 결과, 이전 기록은 같은 `documentSummary`로 요약하고 `DocumentSummaryFacts`로 표시한다. 비교의 전체 목록과 서류명만 있는 자료에 따로 있던 요약 경로를 통합했다. 공고별 제출 조건, 개인의 확인 상태, 당시 저장 버전은 각 화면에서 전달한다.

AI 보조로 구현하고 전체 프런트 테스트 427건 및 빌드를 검증했다. Chrome 360px·390px에서 5173 익산한스빌 공고 상세와 비교의 국민임대주택 공급신청서에 같은 제출 대상과 발급 방법이 표시됐다.

2026-11-18에는 이전 준비 기록의 서류를 처음에 서류명만 보이도록 접었다. 펼치면 선택한 기록의 제출 대상과 발급 방법을 먼저 보여주고 당시 준비 상태, 메모, 공식 근거를 이어서 표시한다. 같은 이름의 서류라도 기록별 안내가 다르게 표시되는 경우와 발급 정보가 비어 있는 경우를 포함해 관련 테스트 76개가 통과했다.

일회성 조건 확인 결과의 ‘확인할 서류’에도 같은 방식을 적용했다. 공통·조건부·추가 확인 서류의 이름을 선택하면 해당 공고와 답변에 따른 제출 대상과 발급 방법이 보인다. 일회성 확인과 기존 준비 화면 관련 테스트 88개가 통과했다.

다섯 화면의 서류 카드 배치를 `DocumentCard`로 통합했다. 공고 상세의 핵심 서류는 묶음으로 열리고, 개인 준비에서는 저장이 성공하면 편집 카드가 접힌다. 공통 카드 변경 후 전체 프런트 테스트 502개와 빌드·코드 검사·계층 검사를 통과했다. 비교 선택과 준비 삭제 테스트의 제목 기대값도 현행 공고 제목 약칭에 맞췄다. 시연 데이터로 Chrome 360·390·768·1280px에서 공고 상세와 내 준비의 서류를 키보드로 펼치고 다시 접을 수 있는지 확인했다.

공고 상세에서 필요한 서류 확인을 펼치면 서버가 우선순위대로 분류한 나머지 서류 ID를 같은 공고의 서류와 연결해 모두 표시한다. 오산세교2 7단지에서 Chrome 360·390·768px으로 공통 3개·추가 3개에서 공통 7개·추가 28개로 펼쳐지고 다시 접히는 것을 확인했다. 서류 요약 서버 테스트와 전체 프런트 검사·빌드를 통과했다.

공고 비교의 전체 제출서류를 펼치면 해당 공고의 공통·조건부 목록에 나머지 서류가 함께 표시된다. 원문 근거와 발급 방법은 개별 서류에서 확인할 수 있다. 로컬 Chrome 360·390·768px에서 오산세교2(7개·28개)와 공주시(5개·29개)를 함께 열어 각각의 목록 수와 독립적인 접힘을 확인했다. 프런트 테스트 508개와 빌드·코드 검사를 통과했다.

공고 상세와 비교의 접힌 서류 목록에도 공통 서류명을 모두 표시한다. 해당자 서류의 미리보기는 3개이며 펼치면 전체가 보인다. Chrome 360·390·768px에서 오산세교2의 공통 7개, 비교한 공주시의 공통 5개와 펼침·접힘을 확인했고 프런트 전체 검사와 빌드를 통과했다.
