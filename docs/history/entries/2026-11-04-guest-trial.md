# 로그인 없이 신청 준비를 체험하는 로컬 세션

- 기록일: 2026-11-04 (Asia/Seoul)
- 기록 상태: 실행 근거 정리·담당자 검토 전
- 작업 상태: 로컬 적용 및 검증 완료
- 유형: 비회원 체험 / 세션과 기록 분리

## 배경과 결정

5184의 로그인 화면에서 가입 없이 독립된 체험 계정으로 들어가는 동작을 확인했다. 사용자는 5173에서 같은 기능을 원했다. 현재 서비스의 공개 공고, 소유자별 준비 기록과 로그인 복귀 규칙을 유지하고 새로고침 후에도 기록을 이어갈 수 있도록 임시 서버 세션을 채택했다. 제공 기준은 로컬 샘플 프로필이며, 서버가 제공 여부를 알린다.

## 구현과 검증

- 홈·로그인·회원가입에서 체험을 시작한다. 일반 회원의 세션이 있으면 교체하지 않는다. 첫 화면의 예시 공고 링크 또는 사용자가 로그인 전에 선택한 공고로 준비를 시작할 수 있다. 회원가입과 이메일 입력이 필요 없다.
- 체험 세션의 자료는 기존 소유자 확인을 거친다. 체험 계정은 개인 이메일이 없고 외부 알림·메일·관리자 기능을 사용할 수 없다. 마이에서 체험을 종료하면 기록을 삭제한다. 생성 후 24시간이 지나면 인증을 거부하고 정리 작업이 만료 기록을 제거한다.
- 실제 5173 서버에 연결한 독립 Chrome 세션 두 개에서 홈과 로그인 복귀, 조건 답변·서류 완료·일정 기록 후 새로고침, 타인 준비 조회 거부, 종료 후 토큰 거부를 확인했다. 360·390·768px에서 체험 버튼 높이 44px 이상과 가로 넘침 없음을 확인했다.
- 프런트엔드 포맷·린트·타입 검사와 테스트 33개, 일반 빌드가 통과했다. 서버 단위 10개·독립 PostgreSQL 통합 22개와 실행 파일 빌드가 통과했다. 통합 테스트에 재진입·만료·정리·일반 회원 보호를 포함했다.
- Codex가 로컬 구현·검증을 수행했다. 실제 휴대폰, 운영 배포 및 이용자 검토는 이번 범위에 포함하지 않았다.
