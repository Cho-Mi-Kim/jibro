- 기록일: 2026-11-20 (Asia/Seoul)
- 기록 상태: 근거 정리·담당자 검토 전
- 작업 상태: 점검 완료, 개선 구현 미착수
- 유형: 문제 원인 조사·문서
- 담당·검토: AI가 공고별 공식 원문 대조와 답변 흐름 재현을 분담. 기관 확인 및 담당자 승인은 수행하지 않음.
- 기준: `review/local-updates-20261115`, `eb64b60`. 제품 코드·DB·개인 준비 기록·원격 저장소 변경 없음.

## 배경·범위

사용자가 포항블루밸리 점검에 이어 다른 공고도 하나씩 전면 검토하도록 요청했다. 당시 기본 공개 목록 123건에서 기존 사용자 지시에 따라 접수 종료 37건을 제외했다. 남은 86건은 접수 중 11건, 접수 예정 60건, 일정 확인 필요 15건이다. 포항 1건은 앞선 별도 기록을 따르고 이번 보고서는 다른 85건을 다룬다.

85건 중 질문을 제공하는 69건의 질문 862개·서류 2,063개를 공식 원문과 대조했다. 질문이 없는 16건은 현재 공개 상태, 공식 첨부 목록, PDF 접근·판독 가능 여부를 확인했다. 이 16건의 세부 자격·서류 전체를 검수한 것으로 간주하지 않는다.

## 고려한 선택지·결정

공통 요약 문구의 정규식 점검만으로는 신청 유형·자격 예외·선정 순위·서류 연결을 확인할 수 없어, 공고별 원문과 실제 공개 질문을 대조했다. 중복 참조나 잘못된 선택값은 구조 검사로, 서류 과잉·누락은 가상 답변 실행으로 분리해 확인했다. 원문 자체의 충돌, 제품의 연결 오류, 설명 부족을 서로 구분했다. 점검 요청이므로 제품 내용을 임의 수정하지 않고 개별 근거를 기록했다.

## 결과

[개별 공고 보고서](../../reviews/2026-11-20-condition-audit/index.html)와 [구조화 결과](../../reviews/2026-11-20-condition-audit/results.json)에 85건을 한 건씩 기록했다. 분류는 우선 보완 38건, 보완 필요 25건, 새 중대 문제 미발견 6건, 질문 미제공 16건이다. 발견 기록 207개에는 같은 유형의 공고별 사례와 기존 원문 확인 사항이 포함되므로 서로 다른 버그 207개라는 뜻은 아니다.

- 울산다운2 A-6·춘천/철원 행복주택은 준비 서류가 각각 2개뿐이며 공식 원문에 있는 추가 필수·계층별 증빙이 누락됐다. 밀양가곡1·원주명륜2도 공통·조건부 서류가 빠졌다.
- 32개 공고의 34개 질문 묶음에서 차상위 선택 시 상황별 대안 증빙 9개가 각각 준비 항목으로 추가됐다. 모든 증빙이 법적으로 필수라는 뜻이 아니라, 본인 상황에 맞는 증빙을 구분하는 안내·선택 단계가 부족하다.
- 33개 공고에서 2세 미만 자녀가 있는 세대의 30% 범위 우선배정 안내가 질문·핵심 요약에 빠졌다. 공급형별 적용, 제외 주택, 우선배정 내 순위, 탈락 후 잔여 물량 재경쟁을 공고별로 구분했다. 자녀가 없다는 사실을 부적격 사유로 해석하지 않았다.
- 전주평화는 세대 질문에서 예비신혼을 골라도 별도의 가점 질문에서 해당 없음을 고르면 필요한 예비신혼 관련 서류 4개가 제외된다.
- 정읍상동2·3은 최신 첨부 69482893이 연결돼 있으나 질문·서류 근거는 이전 69388609에 남아 있다. 정읍수성1도 최신 69517260과 이전 69477400 사이에 근거·신청서 비치 장소·일정 차이가 있다. 정읍수성1의 일정 변경은 조건 대조 중 발견한 인접 범위 사항으로 구분했다.
- 창원 공고는 질문 분기가 없어 27개 질문을 모두 진행하지만 일부 서류만 단지 선택에 따라 분기한다. 일부 지역순위의 지역명·주거약자용 신청 예외 등도 개별 보고서에 기록했다.
- 장성의 미성년 출생일 오기, 군산의 재계약 주택취득 기준일 혼재, 김제검산1의 기준일·배점 지역명, 전주평화의 현재 소득·자산 금액은 원문 문제와 현재 확인 필요 상태를 구분했다. 이번 조사로 기관 확인이 완료됐다고 간주하지 않았다.

## 검증

- `.tools/qa/all-condition-audit/notices.json`에 당시 공개 자료를 고정했다. 공식 상세 86건을 다시 조회해 첨부 목록을 비교했다. 공개 질문이 있는 70건(포항 포함)의 공고 첨부 목록은 당시 LH 공식 목록과 일치했지만 개별 질문·서류의 근거 파일은 별도 오류가 있었다.
- `structural.cjs`: 포항 포함 질문 877개·서류 2,077개의 중복 ID, 존재하지 않는 연결 질문, 불가능한 선택값 0건. 70개 공고에서 첫 유효 답변·모두 미확인 140회 성공. 이번 85건 보고서에 해당하는 실행은 138회다. 응답 성공과 내용의 정확성은 구분한다.
- `alternatives.cjs`: 위 32개 공고·34개 질문 묶음의 대안 증빙 9개 일괄 추가를 실제 일회성 확인 API로 재현했다.
- `premarital.cjs`: 전주평화의 예비신혼 세대 선택과 가점 해당 없음 조합에서 서류 4개 제외를 재현했다.
- `jangseong-ui.cjs`: Edge 390px에서 실제 12문항을 거쳐 공통 5개+대안 9개, 총 14개 서류가 표시됨을 확인했다. 페이지 실행 오류 없음. 초기 QA 스크립트의 선택지 기본값·버튼 위치 가정 오류를 고친 뒤 완료했으며 제품 오류로 분류하지 않았다.
- `validate-report.py`: 공고 85건의 고유 ID·전체 범위, 질문/서류 참조, 공식 PDF 92개 해시·물리 쪽수 범위 검사 오류 0건.
- `report-ui.cjs`: 최종 HTML의 검색·분류·펼침을 Edge 360/390/1280px에서 확인했다. 가로 넘침 및 페이지 실행 오류 없음. 모바일 보고서 스크린샷을 직접 확인했다.
- 검증 자료는 `.tools/qa/all-condition-audit/`에 있다. 제품 코드가 바뀌지 않아 전체 단위 테스트와 빌드는 재실행하지 않았다. 실제 모바일 기기·로그인 계정 저장·모든 답변 조합은 검사하지 않았다.

## 기여·한계와 후속 작업

AI가 공개 자료 조사·공고별 비교·가상 답변 재현·보고서 작성을 수행했다. 실제 개인 자격 확정, 기관 문의, 자료 제출은 수행하지 않았다. 표본 시나리오와 현재 공식 첨부를 대조한 결과이며 모든 개인 상황 조합이나 모든 외부 후속 공지에 대한 완전성 보증은 아니다.

후속 구현은 필수 서류 누락 → 모순 답변과 서류 과잉/제외 → 자격 예외·선정 순위 → 최신 근거 및 공식 양식 재연결 순으로 진행할 수 있다. 질문 미제공 16건은 별도의 원문 구조화·항목별 검수를 거쳐야 한다. 질문 의미나 연결을 바꿀 때 기존 준비 기록과 새 안내 버전의 관계도 검증해야 한다.

## 발표·포트폴리오 메모

공고별 원문 대조와 실제 답변 결과를 함께 검사해 단순 표현 문제와 준비 서류의 누락·과잉 연결을 구분했다. 이번 작업은 문제 발견과 근거 정리이며 오류 수정 완료나 기관 검수 완료로 표현하지 않는다. 개인 기여 표기는 담당자 확인 후 사용한다.
