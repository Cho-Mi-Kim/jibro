# 접수 중·예정 공고의 방문 접수 시간 재대조

2026-11-17 한국 시각 기준 공개 접수 중 18건·예정 60건 가운데 직전에 고친 정읍수성1을 제외한 77건을 검수했다. 현행 LH 상세의 첨부 목록·정정본 연결과 모집공고 PDF·한글본, 단지·순위·신청 방식별 시간표를 기존 일정과 대조했다. 전체 조회 범위에서 PDF·HWP·HWPX 249개의 파일 지문을 확인했다. 전체 접수의 최초 시작이나 최종 마감을 추가 변경할 근거는 발견하지 않았다.

- 19개 공고에서 방문 접수 회차에 점심 접수 중단을 표시했다. 아산·천안은 12월 2일 11:40~13:00, 해당하는 나머지 공고는 12:00~13:00이다. 주택 열람·계약·서류 제출만을 위한 운영시간은 방문 청약시간과 구분했다. [아산·천안 10쪽](https://apply.lh.or.kr/lhapply/lhFile.do?fileid=69386349#page=10)
- 익산부송1·익산동산과 서귀포동홍3의 기간 하나로 묶인 방문 회차를 각각 5일, 3일로 표시했다. 주민센터를 방문할 때의 일별 시작·마감과 점심을 함께 안내한다. [익산 10쪽](https://apply.lh.or.kr/lhapply/lhFile.do?fileid=69404157#page=10) · [서귀포 10쪽](https://apply.lh.or.kr/lhapply/lhFile.do?fileid=69426786#page=10)
- 인천산곡 A1은 방문 지원을 받으려면 11월 20일까지 전화한다는 안내를 접수 일정에 추가했다. 방문 시각은 LH와 개별 확인하는 항목이다. [인천산곡 8쪽](https://apply.lh.or.kr/lhapply/lhFile.do?fileid=69385666#page=8)
- 삼척원조의 과거 첫날 시작 시각은 공식 문서 안에서 엇갈린다. 최초 접수순번에 관련된 이 항목은 기존 확인 필요 표시를 유지했다.

변경 대상 22개 공고의 상태·버전·원문을 저장 직전 확인해 일정과 검수 근거를 함께 저장했다. 검수 중인 증평송산5는 자동으로 갱신되는 시작·마감 회차와 별도로 공식 방문 접수 중단 시간을 기록했다. 5173의 모바일 브라우저 너비 390px에서 22건 모두 공식 접수 일정의 시작·마감과 회차별 시간 창의 변경된 안내를 확인했다.
