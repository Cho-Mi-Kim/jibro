# 공고 상세 핵심 요약 스크롤

- 배경: 핵심 요약의 근거를 열 때 선택한 카드를 공고 목록처럼 화면 위쪽에 정렬해 달라는 요청.
- 구현: 카드의 펼침 이벤트에 공통 750ms 스크롤을 연결하고 모바일 내부 스크롤 영역과 데스크톱 창을 구분한다. 마지막 카드에 필요한 스크롤 공간을 확보하며 닫거나 화면을 떠날 때 제거한다. 사용자의 스크롤이나 움직임 줄이기 설정을 존중한다.
- 검증: 관련 테스트 15개, ESLint와 프런트엔드 빌드 통과. 데스크톱 브라우저에서 서류 요약을 펼쳐 상단 정렬 확인. 모바일 스크롤 계산은 단위 테스트로 확인했으며 실제 기기 테스트는 하지 않았다.
- 기여·한계: AI 보조 구현, 사용자 검토 전. 후속으로 실제 모바일 기기 확인 가능. 발표·포트폴리오용 효과 수치는 측정하지 않았다.
- 후속 변경: 핵심 요약 카드를 접거나 카드 본문을 클릭해도 같은 위치로 스크롤한다. 근거 링크와 내부 버튼은 독립 동작을 유지한다. 관련 테스트 16개, ESLint 및 빌드 통과.
- 후속: 핵심 요약 스크롤의 750ms 완료를 프레임 단위로 검증했고, 공고 자료와 비교의 펼침·접기에도 같은 정렬을 적용했다. 관련 테스트 18개, ESLint 및 빌드 통과. 데스크톱 브라우저에서 펼침 후 위치 확인.
- 후속: 핵심 요약의 서류 원문 링크에만 적용되는 간격을 조정하고 터치 영역은 유지했다. 상세 내용 테스트 14개 및 데스크톱 브라우저 표시 확인.
- 후속: 조건별 카드, 제출서류·일정 카드 및 검수 중 원문 발췌의 선택·펼침에도 동일한 스크롤을 적용했다. 링크와 독립 버튼은 제외한다. 관련 테스트 27개, ESLint 및 빌드 통과; 데스크톱 브라우저 조건 카드 확인.
- 후속: 조건 카드 본문 클릭은 스크롤만 하고, 우측 펼침 버튼으로만 공식 근거를 열고 닫도록 변경. 관련 테스트 17개와 ESLint·빌드 통과.
- 후속: 내 준비의 조건·서류·일정 카드도 선택 시 준비 탭 스크롤 영역에서 정렬한다. 서류 본문 클릭은 스크롤만 하고 별도 펼침 버튼으로 편집 영역을 열고 닫는다. 공통 스크롤은 공유 모듈로 이동하고 동작 줄이기 설정을 유지했다. 관련 테스트 29개와 서류 흐름 2개, ESLint·빌드 통과. 실제 모바일 기기는 미검증.
