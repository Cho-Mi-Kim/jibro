# 화면 설계 이미지 10개 갱신

- 기록일: 2026-10-31 (Asia/Seoul)
- 기록 상태: 근거 정리·담당자 검토 전
- 작업 상태: 제출 준비
- 유형: 문서 / 디자인 자료
- 담당·검토: 기존 사용자 이미지 변경, Codex 파일 검증·커밋·PR 준비; 상세 디자인 담당·팀 검토자 미확인

## 배경·문제

사용자가 기존 화면 이미지 변경과 gitignore 추가를 각각 별도 브랜치·PR로 제출하도록 요청했다. 이번 변경은 사용자가 작업 폴더에 남긴 화면 설계 PNG 10개다.

## 고려한 선택지

실제 화면 구현과 함께 수정하는 대신 요청한 기존 이미지 변경만 제출한다. 개인 IDE 설정 제외는 별도 PR로 분리한다.

## 결정·이유

최신 develop의 c78d0fa에서 별도 작업 사본과 chore/screen-mockups-20261031 브랜치를 만들었다. 기존 파일명·문서 참조 경로를 유지해 이미지 교체 범위를 분명히 한다.

## 변경·해결 과정

홈, 공고 목록·상세, 조건 확인·결과, 내 준비, 서류 체크리스트, 신청 일정, 가이드, 마이 화면의 기존 PNG를 사용자 변경본으로 교체했다. 이미지를 다시 제작하거나 앱 코드를 수정하지 않았다.

## 검증·결과

- PNG 10개 모두 이미지 디코딩 성공, 크기 887×1774.
- 전체 미리보기에서 각 화면의 구성과 표시를 확인했다. 세부 문구·사용성·공식 정책 정확성 검증으로 확대하지 않는다.
- 원본 작업 폴더와 제출 사본의 SHA-256 일치, 변경 파일 범위 및 diff 공백 검사 확인.
- 문서 이미지 변경이므로 제품 코드 빌드·기능 테스트를 새로 실행하지 않는다.

## 기여·한계

이미지의 세부 수정 의도나 디자인 과정은 제공되지 않아 추정하지 않는다. 실제 앱 동작·구현 완료의 증거가 아닌 화면 설계 자료다. 기존 로컬 검토 기록과 개인 설정 변경은 보존한다.

## 발표·포트폴리오 메모

화면 설계 자료를 기능 구현과 구분하여 버전 관리하고, 사용자 제공 변경을 독립적인 검토 단위로 제출했다.

## 후속 작업

PR에서 화면 설계 의도와 현재 구현의 차이를 검토한다. 병합은 별도 요청 범위다.
