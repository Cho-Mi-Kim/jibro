# 선택한 공고 기준으로 홈 보기

- 기록일: 2026-11-04 (Asia/Seoul)
- 기록 상태: 실행 근거 정리·담당자 검토 전
- 작업 상태: 로컬 구현·검증
- 유형: 홈 / 공개 공고 / 개인 준비

## 배경과 변경

5173의 기존 홈은 개인 준비 건만 전환할 수 있었다. 공고 선택만으로 개인 기록을 생성하지 않도록 공개 공고 ID와 기존 준비 건의 선택을 구분했다. 홈 선택기와 목록·상세의 ‘이 공고로 홈 보기’는 같은 주소를 사용한다. 공개 목록의 최신 20건, 내 준비 건, 현재 선택 및 체험용 예시를 표시하고 다른 공고는 전체 목록에서 찾는다.

- 같은 탭과 사용자에서 선택을 기억하며 공고를 단순 열람할 때는 홈을 바꾸지 않는다. 진행 중 준비가 있는 공고를 명시적으로 선택하면 기존 건의 준비도를 표시한다.
- 공개 요약의 ‘이 공고로 준비 시작’은 로그인이나 비회원 체험을 거친 뒤에도 공고와 버전을 재확인하고 그 공고의 홈으로 돌아간다. 기존 상세의 ‘내 조건 확인하기’는 조건 질문으로 이동한다.
- 모바일 360px에서 루트 글자 200% 확대 시 상단·하단 탐색의 가로 넘침을 확인해 메뉴 배치를 조정했다.

## 검증

- 프런트 CI 및 회귀 테스트에서 비회원 선택으로 기록이 생성되지 않는지, 기존 준비 건 선택이 유지되는지, 시작 후 해당 홈이 표시되는지 확인했다.
- 로컬 Chrome에서 목록·상세·직접 선택, 새로고침과 탭 내 재방문, 마감·조회 실패·기본 홈 복귀, 로그인 없이 체험 시작, 기존 준비 재사용을 확인했다. 360·390·768·1280px 및 360px 200% 확대를 검사했다.
- 구현과 검증은 Codex가 수행했다. 별도 모바일 실기기나 원격 배포는 이번 범위에 포함되지 않았다.
