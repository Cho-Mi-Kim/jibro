# 공고의 LH 기관 표시를 공식 CI로 변경

- 기록일: 2026-11-11 (Asia/Seoul)
- 기록 상태: 근거 정리·담당자 검토 전
- 작업 상태: 해결
- 유형: 개발 / UI 개선
- 담당·검토: 사용자 요청, Codex 구현·검증 보조. 팀원 검토 미실시.
- 관련 커밋: 시작 e288a99 / feature/launch-integrations-20261107. commit/push 없음.

## 배경·문제

공고 탭의 LH 글자를 LH 공식 홈페이지에서 받은 CI로 표시해 달라는 요청이다.

## 선택지·결정

홈페이지 장식 PNG는 그림자가 있고, 헤더 SVG는 회사 한글 이름만 포함했다. 공식 CI 페이지의 워드마크 활용형 AI에서 로고 도형을 추출해 사용했다. 다시 그리거나 임의 색상을 적용하지 않는다. 출처와 변환 범위는 shared/assets/README.md에 기록했다.

## 변경·해결 과정

AgencyMark가 LH의 로고/다른 기관의 원래 글자를 구분한다. NoticeCard와 NoticeDetailOverview가 이를 공유한다. 로컬 SVG 8.38KB를 빌드 자산으로 포함해 외부 홈페이지 연결 없이 표시한다. 글자와 외곽은 벡터이며 원본 PDF 그라데이션은 SVG에 포함된 이미지로 변환했다. 목록 메타데이터의 세로 정렬을 중앙으로 맞췄다. 공고 데이터·API·필터·정렬은 변경하지 않았다.

## 검증·결과

- frontend typecheck, lint, build 통과. 기존 500KB 번들 경고는 유지.
- Chrome CSS 393×852 목록, 360×800 목록·상세: 로고 로딩 성공, 42×28px 표시, 가로 넘침 없음. 상세 console error 없음.
- 카드 펼치기 → 공고 자세히 보기 이동 확인. 실제 휴대폰 미검증.
- QA 캡처: .tools/qa/lh-ci/notices-393.png, detail-360.png (로컬 전용).

## 기여·한계 / 발표 메모

공식 기관 식별 자산을 재사용 가능한 표시 컴포넌트로 연결했다. 권리는 LH에 있으며 UI 사용자의 인지도·만족도 개선은 별도로 측정하지 않았다.

## 후속 작업

전세임대주택 → 전세임대 목록 축약을 추가했다. 인천논현2단지 수집 제목의 국임임대주택은 공식 첨부 PDF(https://apply.lh.or.kr/lhapply/lhFile.do?fileid=69314336) 1쪽 제목의 국민임대주택과 대조해 목록 표시에서 국민임대로 바로잡았다. 오타 교정은 해당 단지 문구에 한정하며 DB 원문·상세는 변경하지 않는다. PDF 제목과 2026.11.05 공고일 확인 완료.

매입임대주택·영구임대주택도 목록 제목에서 매입임대·영구임대로 축약하도록 확장했다. 국민·공공·매입·영구임대 명칭 치환을 한 규칙으로 합치고 기존 정정·자격완화·예비입주자 표시 규칙은 유지한다.

공고 목록의 공공임대주택도 공공임대로 축약한다. 평택·안성 예시의 10년, [리츠], 예비입주자 표시는 보존하며 상세 원문은 변경하지 않는다.

제목 앞 연도와 장황한 표현을 추가 축약했다: 앞의 2026/2026년/2026년도(정정 표기 뒤 포함) 생략, 국민임대주택 → 국민임대, 입주자격완화 → 자격완화. 사용자 요청에 따라 예비입주자 의미를 공식 자료로 확인했다. LH청약플러스 공고 panId=2015122300020616은 공가 발생·퇴거 등에 따라 실제 입주까지 상당기간이 소요될 수 있다고 안내하므로 중요한 구분으로 판단해 보존한다. 앞서 모집 문구와 함께 제거하던 예비입주자도 목록에 다시 남긴다. 원문·검색·접근성 이름은 유지. 테스트 25개 및 typecheck 통과. 이후 이 결정이 아래 과거 축약 기록보다 우선한다.

확인 근거: https://apply.lh.or.kr/lhapply/apply/wt/wrtanc/selectWrtancInfo.do?aisTpCd=26&ccrCnntSysDsCd=03&mi=1026&panId=2015122300020616&uppAisTpCd=13

후속 사용자 결정으로 목록 제목 끝의 날짜도 숨긴다. 괄호/대괄호 안 날짜와 공백 뒤 날짜, 공고/공고일 표기, 점·빗금·하이픈·한글 날짜 형식을 처리한다. 제목 앞 연도와 소득완화 등 의미 있는 괄호는 보존한다. 상세·검색 원문은 그대로다. noticeDisplay 테스트 20개 및 typecheck 통과. 아래 날짜 보존 기록은 이 요청 전 상태다.

추가 제목 단축: 입주자 추가모집(공고) → 추가모집, 자격완화 모집 공고 → 자격완화, 제목 앞 정정공고 표기 → [정정]. 목록 표시 함수만 수정하며 상세 원문은 유지한다. 날짜에 붙는 원래 괄호의 간격도 보존한다. 회귀 사례를 기존 noticeDisplay 테스트에 추가했다.

목록 제목 단축 요청도 반영했다. noticeDisplay.noticeListTitle이 제목 끝의 예비입주자 모집(공고), 입주자 수시/상시모집(공고), 수시/상시모집(공고)을 생략한다. 지역·연도·주택 유형·순위·정정 및 날짜 표시는 유지하고, 모집 결과/취소 안내 및 축약 시 빈 제목은 원문을 보존한다. NoticeCard 표시만 적용하며 상세·검색·접근성 이름에는 원문을 사용한다. noticeDisplay 테스트 9개, typecheck, 변경 파일 ESLint/Prettier 통과.

후속 요청으로 목록 카드의 기관 로고를 왼쪽 42px 열로 분리하고 상태·제목·지역 정보를 오른쪽에 정렬했다. 열 간격은 10px이며 펼친 상세 정보는 카드 전체 너비를 사용한다. 공고 상세 화면은 유지한다. 추가 검증: Prettier/typecheck 통과, 393px 목록과 360px 카드 펼침·가로 넘침 없음 확인. 로고 크기 조정은 AgencyMark 공통 스타일에서 관리한다.
