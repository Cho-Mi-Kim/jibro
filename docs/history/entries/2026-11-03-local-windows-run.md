- 작업 상태: 해결
- 유형: 개발 환경 / 문제 해결
- 담당·검토: Codex가 이 컴퓨터에서 설치와 실행을 확인했다. 별도 검토자는 미확인.
- 기준: `main`의 `cf01da4`

## 배경·결정

요청한 GitHub 저장소를 문서 폴더에 새로 받았다. 기존 작업 사본과 데이터를 보존하고, 준비 기록이 재접속 후에도 유지되도록 실제 API와 DB를 사용했다. Docker 명령을 사용할 수 없어 실행 가이드에서 지원하는 독립 PostgreSQL 17을 선택했다.

## 변경·확인

- 로컬 환경에 Node 24, npm, JDK 17, PostgreSQL 17을 준비했다. Java 빌드 도중 Windows 내부 소켓 연결이 실패해 이 프로젝트의 Java 소켓 임시 디렉터리를 명시했다. 이어서 Gradle `bootJar`가 성공했다.
- 개발용·테스트용 DB를 분리하고 전용 계정으로 연결을 확인했다. 샘플 프로필로 서버를 시작한 뒤 저장소에 포함된 공고 3건과 준비 안내·질문 선택지를 넣었다. 저장소 가져오기 도구의 SQL과 버전 검사를 사용하고, 로컬 클러스터 확인 및 psql 연결 부분만 이 PC용으로 적용했다.
- 홈 HTTP 200, 프론트엔드 경유 `/api/v1/health`의 서버·DB `UP`, 기본 공고 조회 3건을 확인했다. 기본 브라우저에 집으로 창이 열렸고, 재실행 시 같은 서버를 사용했다.
- 컴퓨터 사용 도구가 현재 브라우저 주소를 판별하지 못해 화면 내부 확인을 종료했다. 외부 OAuth·LH 실시간 수집과 전체 테스트 모음은 검증하지 않았다.

## 실행·후속 작업

이 PC에서는 루트의 `Start-Jibro.cmd`로 열고 `Stop-Jibro.cmd`로 종료한다. 실행 도구, 로그와 DB 파일은 Git에서 제외된다. 개인 키가 필요한 외부 연동은 별도의 환경 설정 후 확인한다.
