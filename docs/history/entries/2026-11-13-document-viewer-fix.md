# 서류 카드와 공고문 표시 오류

- 배경: 서류 카드 본문으로 열고 닫으면서 스크롤하고, 다자녀 매입임대 공급신청서 발급처 오류를 수정해 달라는 요청.
- 원인: PDF와 원문 뷰어가 Vite 프로젝트 루트에서 public 파일을 모듈로 불러오면서 개발 서버 변환이 실패했다. 공식 PDF 페이지 API는 정상 응답했다.
- 변경: 뷰어를 정적 공개 자산으로 옮겨 개발과 빌드에서 제공하고, 서류 카드 전체 버튼 클릭 시 열기·닫기와 스크롤을 함께 실행한다.
- 검증: 서류 흐름 테스트 2개 및 서류 카드·근거·스크롤 테스트 7개 통과, 프런트엔드 빌드에서 두 뷰어 파일 생성 확인. 로컬 브라우저에서 공식 공고 17쪽의 다자녀 매입임대주택 공급신청서 표시 확인. 실제 모바일 기기 미검증.
- 기여·한계: AI 보조 구현. 발표용 효과 수치는 측정하지 않았다.
