# 보류 수치 정정과 공식 원문 대조·상황별 질문 복구

- 기록일: 2026-11-23 (Asia/Seoul)
- 기록 상태: 근거 정리·담당자 검토 전
- 작업 상태: 해결 (현재 대상 안내 복구·보완; 독립 PDF 표 관계 자동 판독은 미해결)
- 유형: 개발 / 문제 해결
- 담당·검토: Codex 공식 자료·원고·소비자 검증 분담, 별도 읽기 전용 검토자. 사용자·팀원 검토 미확인
- 관련 이슈·PR·커밋: 미등록. commit/push/운영 배포 없음

## 배경·문제

이전 작업에서 보고한 ‘보류 70건’은 기존 원고를 비운 자동 생성 재생이 실패한 수치였다. 현재 DB의 공개 상태는 PASS 69건, HOLD 1건이었다. 이를 사용자에게 정정하고, 검수한 69개 안내를 새 자동 원고로 덮어쓰지 않고 최신 공식 자료·현재 질문 흐름을 확인했다. 접수 종료 공고는 새 처리에서 제외했다.

## 결정·이유

현재 승인 안내를 기준으로 원문 변경을 검사하고 확인된 질문·서류 연결만 수정한다. 기본 정보와 안내가 함께 보류된 경우에는 기존 출처 검수 게시 경로가 최신 전체 자료와 기본 정보 요건을 검증하여 한 트랜잭션으로 복구한다. 사람의 검수 계정을 만들거나 SQL로 통과 상태를 강제하지 않는다.

## 변경·해결 과정

- 공식 상세 70건과 원래 첨부 236개를 재확인했다. 첨부 URL 추가·삭제 및 승인본과 다른 바이트는 없었다. 당시 공식 종료 공고는 없었다. 포항 11/12 후속 잔여세대 공지의 주공고는 기존 승인본과 동일하고, 별도 잔여세대 자료를 자격 정정본으로 취급하지 않았다.
- 인제서화 국민임대, 대구신서·경산삼주봉황, 삼척·정선, 제천장락1의 제출 대상 자가판단 24문항을 22개 사실 질문으로 교체했다. 중복 현장 신청 질문 2개를 통합하고 47개 서류 ID, 공통 기준·일정·기존 확인 필요 항목을 보존했다. 답변 간 모순으로 필수 서류가 빠지는 경우는 기존 answerDependencies에서 보호한다.
- 북구 공고는 공식 PDF 3~5쪽 자격·순위, 6쪽 일정, 7~8쪽 서류와 관련 예외·양식을 대조해 21질문·17서류·8일정으로 복구했다. 미성년 형제 부양은 사망·실종선고·행방불명을 직접 구분한다. 사망·실종선고 증빙 확인과 행방불명 신고접수증을 분리하고 옛 사유 질문을 삭제했다.
- ApplicationTableReader는 신청자격 열을 접수 회차에 연결하고, ScheduleSourceReader는 신청접수 셀 내부의 정확한 [방문접수] 표시를 읽는다. 열람·발표 열의 날짜를 신청일로 가져오지 않는다. 기존 공통 기간 컴파일 경로를 사용하며 새 병렬 파서는 없다.
- AutomaticPublicationService의 기본 정보 규칙을 LhBasicReview로 이동하고 옛 private 규칙을 삭제했다. SourceReviewPublicationService의 최초 전체 원문 검수에만 기본 HOLD 복구를 허용한다. 현재 및 후보 종료, 공식 식별자·기본 메타·현재 발췌·수동 검수 여부를 검사하고 기본 검수 시각과 안내를 함께 기록한다. 조건만 고치는 경로의 권한은 확장하지 않았다.
- 대구의 58MB 팸플릿은 현재 원격과 승인본의 일치를 확인해 기존 updateFile로 누락된 출처 SHA만 채웠다. FAILED 상태·문맥·읽기 제한을 보존했으며 판독 성공으로 승격하거나 새 추출 job을 만들지 않았다.
- 실제 게시에는 SourceReviewVerifier 및 SourceReviewPublicationService의 기존 apply/refineConditions를 사용했다. 원고는 `data/notices/held-guidance-20261123/`에 있다. 일회성 QA 실행 도구는 `.tools/qa/held-guidance-20261123/`의 고정 캡처에만 적용하며 제품·예약 실행 경로가 아니다.

## 검증·실제 반영

- 일정 단위 61개, 출처 게시 통합 44개, 자동 게시 통합 10개, 화면 통합 18개: 관련 테스트 133개 통과. 타입·변경 테스트 린트·실제 IntelliJ Java 서식 검사·backend bootJar 통과.
- 순위 헤더 제거, 후보 조기 종료 가드 제거, 사실 질문의 역방향 의존 제거가 각각 관련 검사를 실패시키는 것을 확인하고 정확히 복원했다. 북구 필수 서류 범위 변이도 검사에서 검출했다.
- 독립 리뷰의 P1 역방향 답변 모순, P2 미성년 증빙 확인 누락, 추가 후보 조기 종료 가드 지적을 모두 수정했다. `.tools/qa/held-guidance-20261123/independent-review.md`에 처분을 남겼다. Iron Laws·실제 GPT Pro 도구는 제공되지 않아 사용했다고 주장하지 않는다.
- 4건 질문 보완과 북구 1건 복구를 로컬 DB에 실제 적용했다. 각 게시 트랜잭션에서 기존 개인 답변·메모·이전 게시 자료가 바뀌지 않았음을 확인했다.
- 5173 재시작 후 대상 상세 70/70이 AVAILABLE, 보완 원고 5건이 실제 응답과 일치했다. 실제 익명 API의 상황 20건과 no-store 응답을 확인했다. 저장형은 기존 실제 demo API·화면 통합 검사로 확인했으며 사용자 계정에 시험 준비 기록은 만들지 않았다.

## 남은 범위

북구 PDF 6쪽의 신청자격 열은 일정표와 실제 간격이 있는 독립 상자다. 이 관계의 완전 자동 판독은 아직 지원하지 않는다. HWPX 단독 일정 추출 성공이나 이번 공식 원문 직접 검수·게시 성공을 PDF/HWPX 전체 자동 대조 성공으로 보고하지 않는다. 기존 70건의 빈 원고 자동 생성 재생을 모두 통과시킨 작업도 아니다.
