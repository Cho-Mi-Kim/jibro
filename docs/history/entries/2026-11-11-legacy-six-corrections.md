# 구형 공식 정정 이력 6건 연결

## 배경·문제

사용자가 보류9건 중 공식 이력에 원공고가 있는6건을 연결하되, 단순 추가모집·잔여세대는 독립 공고로 유지하도록 요청했다. 구형 LH 원공고 상세가 정정본 대신 자기 ID/일반공고 상태를 유지해 기존 검증에서 거절됐다.

## 고려한 선택지

제목이나 ‘추가모집’ 표현으로 관계를 추정하지 않는다. 공식 이력은 있으므로, 제한된 구형 형식을 지원하고 같은 공식 ID·종류·제목·수정 내용 검증을 재사용했다. 종료 원공고를 전체 자동 수집에서 허용하는 대신 이번에 사용자가 지정한 관계만 내부 명시 명령으로 보완했다.

## 결정·이유

- 구형 예외는 시스템02/분류06/유형08의 일반 원공고 자기참조 형식에 한정한다. 다른 최신본으로 향하는 링크를 무시하지 않는다.
- 공식 이력에 원공고가 실제 포함되고 최신 정정본의 정보가 맞아야 한다. 정정 이력 없는 추가모집·잔여세대·재공고는 별도 공고로 유지한다.
- 일반 자동 연결은 종료 원공고 제외를 유지한다. 이번 지정6건 중5건의 원공고가 종료 상태여서 명시적인 구형 원공고 관계 보완 명령을 사용했다. 최신 정정본 종료 제외는 그대로다. 원공고의 종료 표시·내용·준비 기록은 변경하지 않는다.

## 변경·해결 과정

OfficialCorrectionLink에 기존 최신본 확인 공통 함수, 제한된 구형 원공고 검사, 수정정보 본문 판독을 분리했다. ‘수정정보’ 안에 문자열 ‘정정’이 포함되어 빈 라벨도 이유로 인정되던 문제를 검사에서 발견해 고쳤다. 수정 내용 전체를 보관하고 빈 내용·여러 후보·2000자 초과를 거절한다.

AutomaticCorrectionLinkService의 일반 경로와 저장 검증을 공유하는 `reconcileRequestedLegacyRoot`는 지정 원공고만 처리한다. 스케줄러/API 연결은 없고, 별도 사용자 요청 없이 일반 worker가 종료 공고를 처리하지 않는다.

## 기여·한계

공식 이력을 판독하는 호환 범위를 보완한 작업이며 추가모집을 정정으로 재분류한 작업이 아니다. 일반 수집의 종료 제외 정책은 유지한다. 팀 기여 귀속은 검토 필요.

## 발표·포트폴리오 메모
