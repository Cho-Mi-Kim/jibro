## 후속: 원 위치 고정

## 후속: 목록 클릭 가림 수정
목록의 제목 버튼 ::after가 카드 전체를 덮으면서 상태 원의 클릭을 가로채고 있었다. NoticeCard.module.css에서 badges를 기존 controls와 같은 position:relative/z-index:1 계층에 포함하여 상태 버튼이 카드 열기 영역 위에서 입력을 받도록 수정. 공통 왼쪽 펼침 로직은 유지한다. CSS 포맷 검사 통과. 브라우저 실동작 검증 미실행.
