# 신청 유형·가족관계 답변 모순 확인과 필수 서류 누락 방지

- 기록일: 2026-11-21 (Asia/Seoul)
- 기록 상태: 근거 정리·담당자 검토 전
- 작업 상태: 구현·v6 게시·실제 API/화면·전체 코드 검사 완료
- 유형: 개발 / 문제 해결
- 기준: review/local-updates-20261115, eb64b60
- 담당·검토: AI 구현 및 원문/코드·자동검사 보조. 팀 담당자 검토는 미확인.
- 관련 원격 작업: 커밋·push·병합 없음

## 배경·문제

포항블루밸리의 v5 보완 뒤에도 청년 등 필수 유형을 선택하고 가족관계에서 NONE을 고르면 증명서가 제외되는 단일 조건 제약이 남았다. 사용자는 신청 유형과 가족관계 답변의 모순을 자동 확인해 필수 서류가 빠지지 않게 해 달라고 요청했다.

## 고려한 선택지·결정

화면에서 선택값을 강제로 고치거나 공고 ID별 예외를 추가하지 않았다. DocumentTemplate/Content 전체에 범용 논리식을 도입하는 대신, 검토한 질문에 제한된 answerDependencies를 저장해 기존 질문 스냅샷과 버전 체계를 활용했다. 필수 유형과 실제 상황을 함께 판단하되 입력한 답변은 그대로 보존한다.

## 변경·해결 과정

서버와 프런트에 같은 데이터 계약을 적용했다. 참조 질문의 선택값이 확인되면 연결된 서류는 남기고 모순된 답변은 추가 확인으로 계산한다. 부모 질문을 모르면 서류를 비대상으로 제외하지 않고 UNKNOWN으로 유지한다. 반대로 비필수 유형을 골랐는데 가족 항목에서 청년·한부모 등 필수 유형이라고 답한 경우도 재확인을 요청한다. 공식 검수 항목은 답변 모순과 구분하고 종속 질문·서류에도 전파한다.

저장형·일회성·안내 갱신의 필요 여부 계산을 같은 서버 경로로 묶고, 체험 모드도 같은 계약을 따른다. 상태 배지·추가 확인 개수·진행률·다음 행동·미확인 질문 이동에 전체 답변을 전달한다. 입력 중 모순이 생기면 자동 다음 이동을 멈추지만 사용자가 수동으로 다음을 누를 수 있다. 답변 수정은 첫 미응답/추가 확인 질문으로 돌아간다.

포항 새 원고는 가족관계 질문에 규칙 2개만 추가했다. 문구·선택지·서류·일정·공식 근거와 기존 버전 원고는 보존했다. 새 서버를 빌드해 5173에 반영한 뒤 공식 원문 6개를 새로 대조해 v6/revision7로 게시했다. 공개 상태 AVAILABLE, 개인 준비·이전 기록·과거 공개본 보존, 저장소 원고와 게시 패키지의 SHA 일치를 확인했다.

실제 모바일 화면에서는 긴 질문의 마지막 선택지를 눌렀을 때 경고가 화면 위로 가려지는 문제가 발견됐다. 공통 QuestionCriteria에서 새 모순 메시지가 나타나면 질문 제목으로 0.75초 스크롤하도록 보완했다. 같은 경고 재렌더에는 스크롤을 반복하지 않고 입력 초점을 이동하지 않는다.

## 검증·결과

서버 단위 788개·관련 통합 40개(기존 원문 게시 29개 포함)가 통과했다. 변경 Java 11파일은 프로젝트 IntelliJ 설정으로 포맷한 임시 복사본과 원본의 SHA가 일치했다. 전체 Spotless 실행과는 구분한다. 마지막 공통 스크롤 보완까지 포함한 프런트 전체 CI는 서식·ESLint 0경고·계층/순환 10검사·타입·81파일 626검사·프로덕션 빌드가 모두 통과했다.

5173 실제 익명 API에서 Java/TypeScript 공용 24개 답변 조합을 모두 확인했다. 모순·미응답·미확인·정상 수정의 서류 필요 여부와 경고가 계약과 같고, 입력 답변은 변하지 않았다. 이전 v5 제출은 409로 거절됐다. 검사 도구의 첫 직접 POST는 CSRF 정보 누락으로 403이었으며, 앱과 같은 CSRF 조회·쿠키·토큰 전달을 적용한 후 통과했다. 제품의 보안 설정은 변경하지 않았다.

Edge 브라우저에서 15문항을 실제 선택해 모순 발생 시 자동 진행 정지·답변 유지·결과의 필수 서류 유지·수정 시 모순 질문으로 복귀·정상 답변 후 경고 해소를 확인했다. 360/390/768px에서 가로 넘침이 없고, 360/390px의 125% 글자 확대에서도 경고 텍스트가 잘리지 않았다. 모순 선택 직후 안내가 화면 안에 온전히 보이는 것을 확인했다. 실행 오류 없음. 개인 계정 실저장은 하지 않았으며 저장형/갱신/이력은 통합검사와 화면 테스트로 검증했다.

근거: `.tools/qa/pohang-answer-consistency/`의 `backend-test-counts.json`, `format-check-result.json`, `runtime-activation.json`, `apply-result.json`, `publication-readback.json`, `live-check.json`, `ui-check.json` 및 화면 캡처. 개인 기록·과거 공개본 보존은 실제 게시 트랜잭션 안의 전후 해시 대조 결과다.

## 기여·한계

AI가 구현과 검증을 보조했으며 실제 신청자의 자격을 판정하거나 답변을 바꾸는 기능은 아니다. 규칙이 검수 원고에 설정된 질문에만 적용한다. 현재 포항 가족관계의 두 규칙을 게시했으며 다른 공고에 같은 요건을 추정해 넣지 않았다. 과거 기록은 당시 버전으로 보존하며 새 안내 갱신에서 변경된 질문을 다시 확인한다. 실제 모바일 기기 검증은 미실행이며 브라우저 크기·글자 확대 검증과 구분한다. 기존 큰 번들 크기 경고는 남아 있다.

## 발표·포트폴리오 메모

단일 문항별 답변으로 필수 서류가 누락되던 문제를 질문 간 관계로 표현하고, 자료·결과 표시·진행률·다음 행동을 동일한 계약으로 연결했다. 사용자 만족도나 효과 수치는 측정하지 않았다.

## 후속 작업

현재 요청에 대한 필수 구현은 남아 있지 않다. 다른 공고에 적용할 때는 그 공고 원문에서 확인한 질문 관계를 새 검수 원고에 설정한다. 커밋·push·병합은 하지 않았다.
