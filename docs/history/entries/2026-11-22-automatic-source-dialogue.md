## 추가·교체·삭제

- `PdfPageLayout`을 기존 `PdfLayoutTextStripper`에 연결했다. 실제 좌표로 두 인쇄면, 닫힌 셀·중첩 표·행 기준선을 보존한다. 단순 y/x 정렬로 서로 다른 인쇄면의 문장이 섞이던 경로를 교체했다. OCR 판정에서는 구조 표식을 실제 본문 문자량으로 세지 않는다.
- `DocumentContextReader`로 PDF·HWPX·ZIP 내부 문서를 읽는다. HWPX 전용 reader를 삭제하고 모든 호출자를 바꿨다. HWPX 전용 일정 표 구현도 기존 `ApplicationTableReader`에 통합했다.
- `GuidanceTableProjection`은 항목 대조와 공개 설명에서 같은 셀 관계를 사용한다. 내부 구조 표식을 공개하지 않고, 확정하지 못한 머리말을 임의로 부여하지 않는다. 완전한 중첩 표의 부모·자식 관계와 모든 숫자·예외를 유지한다.
- 원문 설명의20개 제한을 공개 `Content.MAX_QUESTIONS` 계약으로 통합했다. 원문 설명은 신청자 입력에서 계속 제외한다. 명확한 모든 신청자 서류는 공통 필수로 연결하며 불필요한 제출 여부 질문을 제거한다.
- 실제 성년 예외 문단을 읽고, 등본·실종선고·외국인 부모의 대리 신청은 각 원문에 적힌 경우에만 요구한다. 문서에 없는 동거 요건은 추가하지 않는다. 정책은 `source-review-v16`이다.
- 실제 PDF 링크의 물리 페이지와 인쇄 쪽수를 구분한다. 출처 포함 여부를 검사할 때 같은 파일의 위치 fragment는 같은 자원으로 대조하며, 실패 자료 자체를 성공으로 바꾸지는 않는다. 공식 PDF를 HTML 상세 본문으로 오독하던 생산자도 고쳤다.
- 확정 일시에 설명을 함께 저장한 태백장성 일정의 검증 거부를 수정했다. 날짜 값은 변경하지 않았다. 부산 조기 마감 근거의 LH 공지 URL은 같은 공식 경로에서 선택 board query의 생략을 허용하되 ID·호스트·본문·첨부 검증은 유지했다.

이는 입력 의미를 바꾸는 기능 보완과 추출 구조 리팩토링을 포함한다. 이전 개인 답변을 새 질문에 자동 이관하지 않는다. 바뀐 원고는 기존 버전 갱신·보관 절차를 따른다.
