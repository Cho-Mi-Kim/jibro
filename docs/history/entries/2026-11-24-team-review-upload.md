- 기록일: 2026-11-24 (Asia/Seoul)
- 기록 상태: 근거 정리·팀 검토 전
- 작업 상태: 로컬 검사·별도 브랜치 push·초안 PR #31 생성 완료. 당시 남긴 develop 충돌은 후속 사용자 요청으로 [충돌 정리 작업](2026-11-24-pr31-conflict-resolution.md)에서 해결했다.

- 담당·검토: Codex가 변경 범위 확인·검사·업로드 준비. 인간 검토자 미확인.
- 기준: `eb64b60`의 로컬 작업을 `review/local-updates-20261124`로 분리. 이전 PR #26은 이미 병합됨.

## 배경·문제

사용자가 최근 제작한 발표 시각화를 제외하고 현재 집으로 코드를 GitHub에 push하도록 요청했다. 이전 작업 브랜치에는 원격 커밋 6개가 추가돼 있어 기존 브랜치를 덮어쓰지 않는 공유 경로가 필요했다.

## 고려한 선택지·결정

이전 브랜치 강제 갱신 대신 현재 로컬 기준에서 새 검토 브랜치를 만들었다. 사용자 요청은 코드 공유이며, develop/main 병합·배포·원격 변경을 로컬 코드에 통합하는 작업은 수행하지 않는다. PR은 develop 대상으로 만들되 최신 develop과의 통합 검토는 별도다.

발표 시각화 HTML·미리보기 및 시안은 저장소 밖의 Codex 시각화 폴더에 보존하며 이번 업로드에 포함하지 않는다. 기존 제품의 공고 요약·조건 표시·PDF 뷰어와 공식 자료 검수 기록은 서비스 코드에 필요한 내용이므로 포함한다. 과거 커밋에 있던 자료를 소급 삭제하는 작업은 아니다.

## 변경·해결 과정

- 기존 누적 변경을 공유: 조건·서류·일정 표시 통합, 답변별 질문 분기·맞춤 준비, 공식 문서 판독·정정 및 후속 자료 대조, 근거 연결, 안내 갱신, 신청 후 기록, 계정·메일·방문자 보호, 운영 배포·보안 보완 및 관련 검증 자료.
- `.gitignore`에 Python 캐시 제외 규칙 추가. 이미 추적되던 캐시 3개는 Git 추적만 제거하고 로컬 파일은 보존했다.
- 실제 `.env`·서버 runtime·키 파일·빌드 결과는 공유하지 않는다. 업로드 후보 텍스트를 로컬 설정의 비밀값 및 주요 인증키 패턴과 대조했고 발견된 비밀값은 없다.
- 업무 기능을 새로 구현하거나 기존 변경 내용을 이번에 처음 작성한 것으로 보고하지 않는다. 상세 구현·검증 경계는 각 작업 기록을 따른다.

## 검증·결과

- `npm run ci`: 서식, lint, 계층, 검수 카탈로그, 공개 페이지, 타입, 109파일 887검사, 운영 빌드 통과.
- `gradlew.bat build integrationTest`: 성공. 단위·통합 검사 입력이 변하지 않아 Gradle의 최신 결과를 재사용했으며 이번 실행에서 전체 검사를 재실행한 것은 아니다.
- 운영 도구 검사: 35개 중 31개 통과, 환경 조건 검사 4개 미실행.
- 작업 기록 검사: 7개 통과. `npm run build:pages`도 성공.
- Git 공백 검사: 기존 추적 변경은 통과. 신규 파일을 포함한 stage 검사에는 파일 끝 빈 줄 경고 11건이 있으며, 이미 검증·운영된 migration을 포함한 기존 바이트는 업로드 작업에서 임의로 고치지 않았다.
- 실제 외부 로그인·메일 발송·AWS 배포를 이번 업로드 검증으로 재실행하지 않았다. Java formatter 및 Iron Laws 전체 감사도 업로드 작업에서 반복하지 않았으며 기존 기록과 구분한다.

## 기여·한계·후속

Git 커밋 작성자만으로 누적 기능 전체의 개인 기여를 판단하지 않는다. 공개 브랜치와 PR은 팀 검토용이며 자동 병합을 설정하지 않는다. 최신 develop의 변경과 호환·충돌 여부 및 GitHub CI는 PR에서 확인한다.

발표·포트폴리오 메모: 실제 검사한 서비스 변경과 발표 산출물·로컬 자격·캐시를 구분해 팀이 검토할 수 있도록 공유한다.
