## 배경·선택과 결정

사용자가 화면·접근성 설정의 미리보기 카드와 일반 저장 안내를 제거하고 라이트·다크 모드를 추가하도록 요청했다. 기존 밝은 화면을 기본값으로 유지하고, 요청한 두 모드만 명시적으로 선택한다. 시스템 자동 선택은 추가하지 않았다.

## 구현과 책임

`features/accessibility`의 기존 브라우저 설정에 `theme` 필드를 추가했다. 기존 v1 저장값은 그대로 읽으며 theme 누락·잘못된 값은 light로 처리한다. 모드를 바꿔도 글자 크기·대비 강화·동작 줄이기 설정을 보존한다. 정상 저장 문구는 제거하고 저장 실패 안내만 실패할 때 제공한다. 선택 즉시 적용하며 재방문·탭 간 변경·초기화를 지원한다.

`shared/styles/theme.css`에 어두운 배경·표면·글자·선·상태 색상을 모았다. 공통 및 기능별 고정 색상을 의미에 맞는 테마 변수로 연결하되 라이트 값은 fallback으로 보존했다. 밝아지는 브랜드 글자색과 흰 글자가 놓이는 버튼 채움색을 분리했다. 다크+대비 강화도 별도 팔레트로 처리한다. Google·카카오 고유색, 검정 체크박스, 이미지·일러스트 색상은 보존했다. 앱 업무 규칙·API·계정 데이터는 바꾸지 않았다.

## 기여·한계·후속

Codex가 설정/테스트·기능 색상·공통 색상 작업을 분담하고 통합 검증했다. 인간 검토자는 미확인이다. 실제 모바일 기기·보조공학 사용자 검증이나 모든 로그인 후 상태의 시각 검증을 완료했다고 주장하지 않는다. 필요한 후속은 실제 기기의 글자 확대와 준비 서류·일정의 데이터별 화면 점검이다. 사용자의 개인 데이터나 외부 서비스 설정은 사용하지 않았다.

후속 요청으로 접근성 설정 상단의 ‘선택하면 바로 적용됩니다. 이 브라우저에서 사용하는 설정이에요.’ 문단을 삭제했다. 문단 제거로 해당 행의 여백도 제거되며 설정 동작·저장 실패 안내는 유지한다. 대상 Prettier 통과.

구분선이 글자 크기 legend와 겹친 원인은 fieldset border-top의 기본 legend 배치였다. 두 번째 group의 위 테두리를 제거하고 첫 번째 group의 아래 테두리·16px 안쪽 여백으로 옮겼다. 대상 Prettier 통과.
