# 남은 구형 정정 3건의 공식 첨부 대조

- 기록일: 2026-11-11 (Asia/Seoul)
- 기록 상태: 근거 정리·담당자 검토 전
- 작업 상태: 연결 가능한 1건 해결, 원공고 미확인 2건 유지
- 유형: 개발 / 문제 해결 / 의사결정
- 담당·검토: AI 조사·구현·실행 검증; 팀 검토 미확인
- 관련 이슈·PR·커밋: 미등록; feature/launch-integrations-20261107 e288a99의 기존 변경 보존

## 배경·문제

선행 6건 연결 후 남은 파주운정 A23(2015.04), 충주안림 1단지(2014.12), 대구혁신 B-3(2012.11)의 원공고·첨부를 재확인했다. 세 공식 페이지의 수정정보는 남아 있지만 이력 팝업은 정정본 한 행뿐이고 원공고 링크는 비어 있다.

## 고려한 선택지

- 제목 유사성 또는 '최초 공고를 준용' 문구로 연결: 별도 회차의 추가/잔여 모집을 합칠 위험이 있어 제외.
- 공식 이력만 허용: 안전하지만 대구의 같은 회차 전체 공고문 두 형식이 일치하는 근거를 활용할 수 없음.
- 이번에 검토한 정확한 한 쌍만 첨부 지문과 공식 메타데이터로 재검증: 채택. 일반 자동 수집 조건을 완화하지 않음.

## 결정·이유

대구 정정 PAN 520과 일반 PAN 522는 모두 2012.11.26 모집이며 서로 다른 파일 ID의 9쪽 PDF와 HWP가 각각 바이트 단위로 동일하다. PDF 1쪽의 235세대와 5쪽의 계약서류 발급 기준일 2012.11.26이 공식 수정정보의 수정 후 값과 일치한다. 원공고 첨부에도 수정 후 내용이 반영된 동일 모집으로 판단하여 명시 검토 연결했다. SHA 동일성만으로 새 공고를 자동 연결하지 않는다.

파주 첨부는 2015.04.21 회차 및 5.11 추첨 참관 추가를 확인했으나 같은 회차의 별도 원공고 ID를 확인하지 못했다. 문서의 2012.08.31 최초 모집은 별도 회차다. 충주 첨부는 2014.12.01 회차와 접수 장소·요일 수정을 확인했으나 같은 회차 원공고를 찾지 못했다. 문서에서 준용하는 2014.07.17 최초 모집과 이번 잔여세대 추가모집은 별도 유지한다. 공식 목록 과거 기간 검색은 결과 없음이어서 원공고 부재의 확정 증거로 취급하지 않는다.

## 변경·해결 과정

`ReviewedLegacyCorrection`은 명시 검토한 두 URL·공고일·제목·정정 종류/내용·공고문 PDF/HWP 파일 ID/SHA를 검증한다. `AutomaticCorrectionLinkService`의 기존 잠금·현재성·종료 제외·관계 저장 경로를 재사용한다. `NoticeCorrectionRepository.Evidence.attachmentReview`에 검토 내용과 지문을 남기며 기존 evidence 읽기는 호환된다. 원공고가 종료된 대구 한 쌍의 관계만 사용자 지정 보완 범위로 처리했고, 종료공고 전체 수집/내용 검수는 실행하지 않았다.

## 검증·결과

- 실제 적용: 관계 884→885, 대구 연결 1건. 관련 42개 공고 content/revision/source fingerprint/source closed 보존. 추가된 한 건 외 기존 관계 전체 보존. 감사: `docs/reviews/2026-11-11-remaining-three-corrections.json`.
- 테스트: `test --tests '*Correction*'` 40건, DB 통합 25건 통과 및 bootJar 성공. 파일 변경/잘못된 형식/공통 서식/공고일·종류·사유 변경 거절, 기본 자동 경로 보류, 명시 연결·재실행·기존 내용 보존 확인.
- 초기 검증에서 테스트 도우미 이름 충돌과 첨부 메타데이터 검사 순서 문제를 찾아 수정했다. 모든 첨부 메타데이터 확인 후 파일을 읽도록 정리했다. IntelliJ 지정 서식 적용.
- 상세 PDF 1·5쪽 시각 대조, HWP 본문 확인. 파주 PDF는 전체 문서가 아닌 3쪽 발췌라 전체 HWP를 함께 읽었다. 파주·충주 대용량 팸플릿은 전송 크기 제한으로 내려받지 않았고 정정 관계 판단에는 사용하지 않았다.
- 재시작 후 5173 경유 health/database UP. 기본 목록 82건에서 최신본 표시·구본 제외·미확인 2건 유지, 명시 CLOSED 검색에서도 대구 구본 제외/다른 모집 유지, 구본 상세 HTTP 200 확인. 백엔드 PID 93972, 로컬 실행만 확인했으며 원격 배포/push 없음.

## 기여·한계

AI 보조 조사·구현·검증이며 팀 검토는 미확인. 공식 이력 복구나 기관 확인을 수행한 것은 아니다. 파주·충주의 원공고 별도 ID를 확보하기 전까지 미연결 상태를 유지한다. 별도 모집을 정정으로 오인하여 숨기지 않는다.

## 발표·포트폴리오 메모

원공고 링크가 소실된 사례에서 전체 공식 문서 대조와 검토된 지문 재검증을 결합해 한 쌍만 복구했다. 확인 불가능한 두 건은 억지 병합하지 않았다.

## 후속 작업

- 파주 2015.04.21/충주 2014.12.01의 같은 회차 원공고 URL·식별자 확보 시 재검토.
- 별도 추가모집·잔여세대는 현재처럼 독립 유지.
