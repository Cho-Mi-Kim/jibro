# 거창 신원 다자녀 공고 서류 발급 안내

- 배경: 온라인 발급 링크가 없는 서류의 공식 발급처를 확인해 연결해 달라는 요청.
- 확인: 정부24 주민등록표 등·초본(13100000015), 수급자(14600000280), 차상위계층 확인(13520000098), 한부모가족(10601000001), 인감증명서(13100000025), 본인서명사실확인서(13110000047) 서비스 설명과 대법원 전자가족관계등록시스템 안내를 확인했다.
- 결정: 현재 거창 신원 공고의 일치하는 서류 10개에 발급·안내 링크를 제공한다. 해당 여부 미확인 서류에도 선택적 안내로 노출한다. 본인서명사실확인서는 방문 발급을 표시하고 인감증명서는 본인 온라인 발급·제출 가능 여부 확인을 안내한다. 의료기관·금융기관·당사자 등에 따라 달라지는 12개에는 임의 링크를 넣지 않았다.
- 검증: 7개 공식 주소 HTTP 200, 발급 안내와 링크 범위 테스트 14개, 기존 서류 흐름 테스트 2개, ESLint·빌드 통과. 실제 로그인·발급은 진행하지 않았다. 사용자 브라우저 연결이 중단되어 현재 계정 화면의 시각적 확인은 하지 못했다.
- 기여·한계: AI 보조 구현이며 다른 공고에는 이 공고 전용 링크를 적용하지 않는다. 발표용 수치는 측정하지 않았다.
