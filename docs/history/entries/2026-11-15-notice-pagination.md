# 공고 목록 하단에 현재·전체 페이지 표시

사용자는 하단에 표시된 현재 페이지 번호 1을 전체 페이지 수로 이해했다. 기존 20건 단위 조회와 URL 페이지 이동을 활용해 하단에 현재 페이지와 전체 페이지를 함께 표시하고 화살표 옆에 이전·다음 문구를 추가했다. 페이지 정보는 조회가 끝난 후 실제 응답으로 표시한다.

5173의 기본 목록은 54건이다. Chrome 360px 화면에서 다음·다음·이전 버튼을 눌러 1/3, 2/3, 3/3, 2/3 표시와 카드 20·20·14·20개를 확인했다. 첫 페이지의 이전 버튼과 마지막 페이지의 다음 버튼 비활성도 확인했다. AI 보조 구현이며 검증 범위는 로컬 브라우저다.
