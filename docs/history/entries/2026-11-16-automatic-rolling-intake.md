# 수집 공고의 상시 마감과 날짜 미확정 접수 시각

- 기록일: 2026-11-16 (Asia/Seoul)

공식 공고문을 대조해 수동으로 보완한 상시 마감과 접수 시각을 신규 수집 경로에서도 생성하도록 했다. 공고 제목의 ‘상시’만으로는 기한이 정해진 모집과 구별할 수 있어야 한다. 신청 기간 항목, 접수 안내 문장, 접수 열이 확인된 표를 읽고 같은 모집의 확정 마감일과 충돌하는지 검사한다. 접수일이 다른 경우 회차와 접수 방식별로 시작·마감 시각을 각각 대조한다. 서로 다른 시각이 적힌 항목은 공개하지 않는다. 확정 날짜가 없는 시각은 일정 알림의 기준으로 쓰지 않는다.

예약 검수와 명시적인 변경 전·후 정정 비교가 같은 판독기를 사용한다. 기존 회차 식별 방식과 목록·상세의 상시 마감 표시를 재사용했다. 새 결과는 공고 상태와 원문 버전을 확인한 뒤 저장한다. 접수 종료와 취소·조기 마감 공고는 처리 대상에서 제외한다.
