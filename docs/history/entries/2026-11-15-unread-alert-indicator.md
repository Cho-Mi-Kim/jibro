# 상단 알림 아이콘의 읽지 않은 알림 표시

회원의 알림함에 읽지 않은 항목이 있으면 종 아이콘 오른쪽 위에 빨간 점을 표시하고 접근 가능한 링크 이름에도 상태를 포함한다. 알림함을 열거나 기기 알림을 수신한 시각으로 읽음 여부를 추정하지 않는다. 서버가 반환하는 항목별 읽음 상태를 사용한다.

Shell이 로그인한 계정의 알림함을 분 단위로 갱신해 헤더와 ForegroundAlerts에서 공유한다. AlertsPage에서 개별 또는 전체 읽음 처리가 성공하면 같은 계정의 알림함 조회를 갱신한다. 비회원은 알림함을 요청하지 않는다.

5173에서 테스트 알림 응답을 사용해 Chrome 360px·1024px 화면에서 두 건 중 하나를 읽으면 점이 남고 모두 읽으면 사라지는 것을 확인했다. 비회원 화면의 점과 알림함 요청이 없음을 확인했다. App 및 알림 설정 테스트 45건 통과. AI 보조 구현이며 운영 계정이나 실제 기기 알림 전송은 검증 대상에 포함하지 않았다.

알림함에서 알림 종류·날짜·공고 제목을 하나의 공고 상세 링크로 묶었다. 링크를 열면 해당 알림 키만 기존 읽음 API에 전달하고, 성공 시 같은 회원의 알림함과 헤더 표시를 갱신한다. 이미 읽은 알림은 추가 저장 없이 다시 열 수 있다. Chrome 390px·1024px에서 테스트 알림 두 건을 실제 공고 상세로 열어 부분 읽음, 마지막 빨간 점 해제, 뒤로 가기와 재열기를 확인했다. 알림 관련 앱 테스트 6건 및 프론트엔드 빌드가 통과했다.

알림함은 안 읽은 알림을 먼저 표시하고 각 그룹에서 발생 시각이 최신인 항목부터 보여준다. 일정 알림에는 서울 기준 사전 알림 시작일을, 공고 버전 변경에는 해당 버전의 최초 공개 시각을, 취소·조기 마감·복원에는 해당 변경의 확인 시각을 사용한다. 과거 공개 시각은 같은 판본에 남은 검수 기록으로 복원하고 시각을 확인할 수 없는 알림은 각 그룹 끝에 둔다. 읽음 처리 시 발생 시각은 유지된다. Chrome 360·390·1024px에서 네 건의 테스트 응답으로 두 그룹의 순서와 모두 읽은 뒤의 순서를 확인했다.

각 알림의 공고 제목 아래에 발생 시각을 한국 시간으로 표시한다. 기록이 없는 항목은 ‘알림 시각 미상’으로 표시한다. 5173 Chrome의 360·390·768px 화면에서 날짜 경계의 한국 시각, 마감일과의 구분, 과거 시각 미상과 읽음 전후 표시를 테스트 응답으로 확인했다.

알림 시각을 경과 시간에 맞춰 1분 미만은 방금, 1시간 미만은 분, 24시간 미만은 시간으로 표시하고 이후에는 한국 날짜만 표시한다. 로컬 브라우저 360·768px에서 0·10·120·1439·1440분 경과와 한국 자정 경계를 확인했다.

알림 목록의 경과 시간·날짜는 항목 오른쪽 위에 작게 배치하고 아래 공고 제목은 전체 너비를 사용한다. 5173 Chrome에서 테스트 알림 두 건으로 360·390·768px 및 글자 150% 확대 시 내용과 시각이 겹치지 않음을 확인했다.

안 읽은 알림의 빨간 점을 첫 줄 왼쪽에 배치했다. Chrome 360·390·768px에서 글자 크기 100%와 150%로 점·본문·시각의 위치와 모두 읽음 뒤 점이 사라지는 동작을 테스트 응답으로 확인했다.

알림 목록의 공고 제목은 공고 탭의 noticeListTitle을 재사용한다. Chrome 360·768px에서 연도·수시모집 생략, 정정·추가모집 보존, 축약 제목을 눌렀을 때 원래 공고 경로로 이동하는 동작을 테스트 응답으로 확인했다.

관심 공고 목록에도 공고 탭과 같은 noticeListTitle을 적용했다. 카드 제목의 접근성 이름은 원문을 유지한다. 5173 브라우저에서 테스트 관심 공고의 축약 제목 및 상세 경로를 360·390·768px로 확인했다.

완료 여정 보관함의 현재 준비 공고, 펼친 선택 목록, 보관 기록 제목도 공고 탭의 noticeListTitle을 사용한다. 선택 시 준비 ID를 사용하며 키보드 검색은 축약·원문 제목을 모두 지원한다. Chrome 360·390·768px에서 테스트 응답으로 세 위치의 표시를 확인했다.

내 준비의 이전 준비 기록 제목도 공고 목록의 noticeListTitle을 적용했다. 원문은 제목의 접근성 이름과 도움말로 유지한다. 5173 브라우저에서 테스트 기록의 축약 제목을 360·390·768px로 확인했다.
