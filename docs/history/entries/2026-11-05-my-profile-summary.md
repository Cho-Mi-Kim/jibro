# 마이 프로필과 준비 건수

마이 화면의 방문자 이름과 아이콘 중심이 달랐고 건수 라벨과 아이콘 위치가 화면 폭에 따라 바뀌었다. 사용자 요청에 따라 [Figma UI 디자인 원칙](https://www.figma.com/ko-kr/resource-library/ui-design-principles/)의 정렬·근접성·계층을 적용했다.

프로필은 화면 배경 위에 두고 48px 방문자 아이콘과 이름을 가운데 정렬했다. 흰 카드 안에 준비와 보관 링크를 같은 너비로 배치했다. 라벨 14px, 숫자 24px, 단위 14px로 두 건수의 읽는 순서를 통일했다. 각 열 전체가 링크이며 키보드 초점과 누름 상태를 표시한다.

`MyPage`가 조회 결과를 `MyProfileSummary`에 전달하고 전용 CSS가 프로필과 건수 표현을 담당한다. 실제 5173 서버에서 모듈 응답을 확인했다. 격리된 시연 브라우저에서 360·393·768·1024·1280px 정렬과 가로 넘침을 확인했다. 두 열의 터치 높이는 88px이고 준비 목록과 보관함 이동을 확인했다. 관련 앱 테스트 2개와 lint·빌드가 통과했다. 모바일 캡처는 `.tools/feature-qa/my-profile-summary-393.png`에 있다.
사용자 피드백에 따라 건수 카드의 1px 테두리를 진하게 조정했다. 393px 시연 화면에서 확인한 색으로 계산한 테두리와 캔버스의 명도 대비는 약 1.25:1에서 3.09:1로 높아졌다. 360px에서도 같은 색과 가로 넘침 없음을 확인했다.

## 관심 공고 목록 정리 (2026-11-06)

사용자가 관심 공고의 설명 문구 삭제와 UI 정리를 요청했다. 기존 한 박스 안의 밑줄 제목·저장됨 버튼·공고 찾기 배치 대신, 공고마다 16px 안쪽 여백을 둔 카드로 나누고 제목 18px/기관·지역 14px의 계층을 적용했다. 북마크는 오른쪽의 44px 아이콘 버튼으로 두며 기존 저장 상태·해제 동작과 접근성 이름을 유지했다. 공고 찾기는 목록 아래 독립된 전체 너비 테두리 링크로 배치했다. 공유 컨트롤의 기본 스타일은 유지하고 관심 공고 전용 클래스에만 적용했다.

빌드가 통과했다. 실제 로그인 세션이 없는 QA 브라우저에서는 보호된 페이지가 로그인으로 이동하는 것을 확인했으며, 별도의 임시 화면에 실제 SavedPage와 가상 조회 캐시를 사용해 360·393px에서 긴 제목과 44px 북마크, 가로 넘침 없음을 확인했다. 계정의 저장 데이터는 변경하지 않았고 실제 저장/해제 API는 이번에 재검증하지 않았다. 임시 화면은 검증 후 삭제했다.

## 완료 여정 보관함 UI (2026-11-06)

사용자가 보관함 화면도 같은 방식으로 개선하도록 요청했다. 기존 양식의 공유 기본 여백 대신 `ArchivePage.module.css`에서 16px 카드 여백과 영역 간격, 8px 라벨·입력 간격을 관리한다. 현재 공고 선택과 선택 메모, 보관 시 기록이 유지된다는 안내, 전체 너비 보관 버튼을 차례로 배치했다. 보관 기록은 실제 건수를 표시하고 빈 상태와 기록별 제목·메모·복원/연결 행동의 계층을 정리했다. 화면 하단의 내 준비 링크도 전체 너비 테두리로 맞췄다.

보관·복원·메모 연결 API와 선택 상태, 500자 제한, pending/error/success 처리는 유지했다. 빌드 통과 후 실제 컴포넌트와 가상 조회 캐시를 사용한 임시 브라우저 화면에서 393px 빈 상태와 360px 글자 확대(기본 20px)·기록 있는 상태를 확인했다. 가로 넘침 없이 긴 제목·메모·행동 버튼이 줄바꿈되며 버튼 높이는 48px였다. 초기 QA에서 공통 label의 14px margin이 겹치는 것을 발견하여 전용 스타일에서 0으로 보정했다. 실제 기기나 보관 API를 재검증한 것은 아니며 사용자 기록을 변경하지 않았다. 임시 검증 화면은 삭제했다.

사용자가 기본 select의 열린 목록 개선을 요청하여 `ArchivePreparationSelect`를 분리했다. 보관함의 현재 공고 선택만 교체하고 기존 target 상태와 저장 경로를 유지한다. 목록은 입력 폭에 맞는 흰 표면·얇은 테두리·약한 그림자로 표시하며 긴 제목 전체를 줄바꿈하고 현재 선택에는 체크를 표시한다. 44px 이상 항목, 목록 스크롤, 바깥 클릭/Tab 닫기, Escape 초점 복귀, 방향키·Home/End·Enter 선택을 제공한다. 전용 테스트 4개가 통과했고 격리 브라우저의 393·360px에서 긴 제목, 선택 반영, 선택 유지, 키보드 열기·닫기와 가로 넘침 없음을 확인했다. 실제 API 데이터는 변경하지 않았고 검증용 파일은 삭제했다.
