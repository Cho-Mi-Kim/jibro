## 배경과 결정

사용자가 제공한 Miro 보드에는 2026-10-07에 정리한 여섯 도표가 있다. 사용자는 충돌하는 부분에 GitHub 기준을 유지하도록 선택했다. 구현에는 현재 저장소의 화면설계서, 인증·공고·개인 준비 API 계약, 질문별 선택지와 준비 대상 서류 계약을 적용했다. [Miro 사용자 워크플로우](https://miro.com/app/board/uXjVHpbFOYE=/)

## 도표별 반영

| 도표 | 로컬 서비스의 처리 |
| --- | --- |
| 01 화면 지도 | 다섯 메뉴를 유지한다. 홈과 내 준비가 같은 현재 건을 사용하고, 홈의 전체 여정에서 선택한 공고의 조건·서류·신청·후속 일정으로 이동한다. |
| 02 공고 탐색과 준비 시작 | 카드 펼침은 공개 정보만 읽고 해당 위치로 이동한다. 공개 일정을 미리 볼 수 있고, 빈 결과에서 필터 초기화 또는 LH 공식 공고 목록으로 이동한다. 준비 시작을 명시적으로 누르면 로그인·가입 후 계정 목록과 최신 공고를 다시 읽는다. 저장 성공 후에만 현재 건과 질문 화면으로 전환한다. 직접 시작 주소만 방문할 때는 별도 확인이 필요하다. |
| 03 가입·조건 편집 | 가입에서 비밀번호 확인을 제공한다. 선택한 공고는 이메일 가입·로그인 사이에 유지한다. 목적지 없는 가입은 마이로 이어진다. 이름·비밀번호 검증과 질문별 답변은 GitHub 계약을 따른다. |
| 04 조건·서류·일정 | 기존 서버 응답을 기준으로 답변·해당 서류·신청 기록을 갱신한다. 일정에서 다른 준비 건을 선택할 수 있다. 여정에서 공식 신청과 공식 일정을 각각 열 수 있다. 공고 원문을 여는 행동과 신청 여부 저장은 별도로 유지한다. |
| 05 가이드·마이 | 주제 선택 후 전체 주제로 복귀할 수 있다. FAQ와 공식 출처는 기존 API를 사용한다. 비회원 마이에서 로그인과 가입 모두 가능하다. 로그아웃 후 개인 경로는 재인증이 필요하다. |
| 06 예외·저장 경계 | 목록·개별 건 조회 실패, 시작 저장 실패는 성공 상태로 표시하지 않는다. 인증 갱신이 만료되면 개인 캐시를 비우고 로그인 후 원래 경로에서 데이터를 다시 읽는다. 공고 ID와 버전을 재확인한다. |

현재 건은 이 브라우저에서 계정별로 기억하는 준비 건 ID다. 답변·서류·일정·진행률은 서버에 저장한다. 명시적 선택이 없거나 저장된 ID가 목록에 없으면 진행 중 건을 우선한다. 임의 외부 URL의 분석·저장, 계정 공통 소득·자산 프로필, 읽음 체크로 조건 확인, 서류 임의 제외, 관심 공고·알림 실저장, 정보 변경·탈퇴·메일 재설정·기기 가져오기는 구현하지 않았다. 공고 API에는 독립적인 취소 상태가 없어 취소를 별도로 감지한다고 주장하지 않는다. 시작은 서버의 `canStart`와 실제 안내 버전으로 제한한다.

## 검증과 한계

- 프론트엔드 포맷·린트·타입 검사, 테스트 31개, 일반 빌드와 Pages 시연 빌드가 통과했다. 현재 백엔드의 실행 JAR 빌드도 확인했다.
- 별도 PostgreSQL DB와 Spring 서버를 사용해 Chrome에서 가상 계정의 가입, 비밀번호 확인 불일치, 로그인 후 대기 공고 자동 시작, 조건 답변·서류 완료·신청 기록 저장을 검증했다. 두 준비 건 전환, 새로고침 후 선택 복원, 다른 공고 열람 시 선택 유지, 일정 대상 변경, 로그아웃 뒤 보호 경로 차단도 확인했다.
- 목록 요청 503과 세션 갱신 401은 브라우저에서 의도적으로 재현했다. 읽기 실패 시 준비 생성 요청은 없었고 재시도 성공 후에만 전환했다. 만료 후 재로그인으로 같은 건의 결과 화면을 복원했다. 저장 실패 시 원래 건 유지와 재시도는 회귀 테스트로 확인했다.
- 홈·여정·공고 펼침·일정에서 360, 390, 768, 1280px 및 360px·글자 200%를 검사했다. 20개 조합에서 문서 가로 넘침, 브라우저 페이지 오류가 없었다. 캡처와 검사 요약은 Git 제외 경로 `.tools/workflow-qa/`에 있다. 테스트 전용 서버와 DB를 정리하고 실제 5173 사이트와 DB의 정상 응답을 확인했다.
- 실제 기기, 외부 소셜 계정과 LH 실시간 수집은 이번 변경 검증에 포함하지 않았다. 운영기관 신청·자격 판단 기능에 대한 결과가 아니다.
