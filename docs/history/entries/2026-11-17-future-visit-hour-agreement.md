# 방문 접수 시간의 공식 자료 대조

접수 중·예정 공고에 방문 회차가 있으면 시작·마감 시각이 이미 입력되어 있어도 원공고, 연결된 최신 정정본과 접수처 후속 공지를 다시 확인한다. 접수처의 본문과 판독된 공식 첨부에서 일별 운영시간과 점심시간을 추출한다. 여러 날의 첫날 시작과 마지막 날 마감만 적힌 자료에서는 중간 날짜의 운영시간을 추정하지 않는다.

같은 모집·회차·접수 방식의 날짜별 운영시간을 비교해 공통 구간과 차이가 나는 구간을 나누고, 차이가 있는 구간에 원문 근거를 연결한다. 전체 일정과 회차별 시간은 같은 일정 데이터를 사용한다. 공식 자료를 발행 직전에 다시 확인하며, 종료된 공고는 자동 처리에서 제외한다.

원주명륜2의 LH 원문과 원주시청 게시문을 대조해 11월 25~27일 공통 시간이 10:00~12:00, 13:00~17:00이고 확인이 필요한 구간은 09:00~10:00, 17:00~18:00임을 확인했다. 검수 결과를 360px·390px 브라우저에서 전체 일정과 회차별 시간에 각각 표시해 검증했다.
