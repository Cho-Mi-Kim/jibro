# 공식 근거 링크 공통 표시

공고 상세·비교, 내 준비, 이전 준비 기록, 일회성 조건 확인 결과의 공식 근거는 EvidenceLink와 전용 CSS 모듈에서 링크 문구·외부 이동 아이콘·확인일자·간격을 관리한다. 화면별 className과 확인일자 줄바꿈 옵션을 제거하고 확인일자는 항상 링크 아래 표시한다. 첨부 자료와 검수 중 확인된 원문 링크도 같은 표시를 사용한다.

표시용 label을 지정해도 연결 위치는 원래 evidence.label로 계산한다. 비교하는 각각의 공고 및 이전 기록의 URL·쪽수·해시·확인일자를 유지한다. 경로가 없거나 허용되지 않은 URL이면 링크 대신 원문 경로 확인 필요를 표시한다.

AI 보조로 구현했다. 담당자·검토자는 확인되지 않았다. 전체 프런트 테스트 72개 파일·505개, TypeScript, ESLint, 계층·순환·선택자 계약, 빌드와 전체 서식 검사가 통과했다. 서식 검사에서 발견한 기존 파일의 형식 차이도 정리했다. 빌드의 기존 번들 크기 안내는 남아 있다.

Chrome에서 공통 컴포넌트를 실제 앱 스타일과 함께 렌더링하여 360·390·768px의 긴 링크 줄바꿈, 확인일자 아래 배치, 가로 넘침 없음을 확인했다. 실제 기기 확인이나 외부 원문 서버 접속 검증은 수행하지 않았다. 첫 두 브라우저 검증 스크립트는 임시 모듈 로딩 방식 때문에 실패했고, Vite의 모듈 변환을 적용한 임시 진입점으로 수정해 검증을 완료했다.
