# 화면·접근성 설정

사용자 요청(2026-11-06)으로 후순위 접근성 옵션을 구현한다. 같은 요청에서 다국어 지원은 제외했다. 한국어 UI와 공고 원문은 유지한다.

## 적용 범위

- 마이 → 화면·접근성 설정(`/accessibility`). 로그인하지 않은 사용자도 이용한다.
- 화면 모드는 라이트 모드/다크 모드 중 선택한다. 초기값과 초기화 값은 라이트 모드이며 기기의 색상 모드를 자동 선택하지 않는다. 모드 변경은 글자 크기·대비 강화·움직임 줄이기 선택을 보존한다.
- 글자 크기 기본/크게/아주 크게는 브라우저 기본 글자 크기의 100%/112.5%/125%다. 브라우저 확대 기능을 제한하지 않는다.
- 기본 설정은 기존 디자인을 유지한다. 확대 설정에서는 좁은 모바일 필터, 준비 요약과 지표의 배치를 바꾸어 읽을 공간을 확보한다.
- 대비 강화는 본문·보조 글자·브랜드·상태 색상 및 구분선 토큰을 진하게 한다. 색상만으로 상태를 전달하지 않으며 기존 상태 문구를 유지한다.
- 화면 움직임 줄이기는 펼침 애니메이션과 자동 스크롤을 줄인다. 이 옵션을 꺼도 기기의 `prefers-reduced-motion` 설정은 따른다.
- 사용자 요청(2026-11-07)으로 설정 미리보기 카드와 정상 저장 안내 문구를 제거했다. 저장 실패 시 현재 화면에만 적용된다는 안내는 유지한다.

## 저장과 책임

- 개인 계정 정보와 분리한 브라우저별 표시 설정이다. `localStorage`의 `jibro.accessibility.v1`에 표시 설정만 저장한다. 답변·계정·공고 내용은 포함하지 않는다.
- 선택 즉시 적용하고 다음 방문에도 유지한다. 다른 탭의 변경·삭제도 반영한다.
- 기존 v1 저장값에 `theme`가 없거나 유효하지 않으면 `light`로 읽고, 기존의 유효한 글자 크기·대비·움직임 설정은 유지한다. Provider는 루트 `data-theme`를 갱신하며 색상 적용은 테마 스타일이 담당한다.
- 잘못된 저장 형식은 기본값으로 읽는다. 저장 불가 환경에서도 현재 화면에는 적용하며, 영구 저장되었다고 표시하지 않는다.
- `features/accessibility`가 설정 검증·저장·전역 적용·화면을 소유한다. `GuidePage`와 `DocumentEditor`의 스크롤은 공통 동작 줄이기 판단을 이용한다.

## 검증 기준

- 저장/재방문/초기화/키보드 라디오 선택/다른 탭 변경/저장 오류/OS 동작 줄이기를 컴포넌트 테스트한다.
- 360px, 393px, 768px에서 설정과 주요 화면의 줄바꿈·고정 탐색 영역을 확인한다. 브라우저 화면 검사와 실제 모바일 기기·보조공학 사용자 검증은 구분한다.
- 글자 200% 확대 시 내용 손실 방지는 [W3C Resize Text](https://www.w3.org/WAI/WCAG21/Understanding/resize-text)를 참고한다. 이 기능 추가만으로 전체 서비스의 WCAG 준수 인증을 주장하지 않는다.
