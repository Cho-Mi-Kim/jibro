# 공식 조기 마감·취소 상태

기준: `docs/planning/backlog-decisions-20261106.md` 15번. 자동 수집 중 원문 누락·접속 실패·첨부 오류는 조기 마감이나 취소의 근거가 아니다.

## 상태와 변경 권한

- `Notice.status`는 기존 시작일/마감일에서 계산한 `OPEN/UPCOMING/CLOSED/UNKNOWN`을 유지한다.
- 별도 `Notice.lifecycle.state`는 `NORMAL/EARLY_CLOSED/CANCELLED`이다. 기본값은 `NORMAL`이다. 공개·비공개 및 준비 안내 검수 상태와 독립적이다.
- 관리자 전용 `PATCH /api/v1/admin/reviews/{id}/lifecycle`은 현재 `revision`, 변경할 `state`, 확인 내용 `reason`, 공식 근거 `evidence(label,url,checkedAt)`, 명시적 `officialConfirmed=true`를 받는다. HTTPS 주소·확인일·내용이 필수이며 미래 확인일은 허용하지 않는다. 서버는 운영기관 문서 내용의 진위를 자동 판정하지 않는다. 관리자가 해당 공고에 대한 공식 안내를 직접 대조한다.
- 동일한 공고 행 잠금 아래 현재 revision을 대조한다. 충돌은 409이며 최신 내용을 다시 확인해야 한다. 변경할 때 notice revision과 별도 lifecycle revision을 각각 올리고 감사 이력을 기록한다. 정상 복원에도 같은 공식 확인 절차를 적용한다.
- 질문·서류의 `version`, basic/guide 검수 결과와 확인 시각은 바꾸지 않는다. 변경 이후 수집·원고 수정에 대한 기존 재검수 규칙도 유지된다. 관리 UI는 저장하지 않은 원고·검수 변경이 있을 때 상태 변경을 막는다.

## 사용자 화면과 개인 기록

- 목록 배지·필터·상세·홈·내 준비에서는 공식 조기 마감/취소 표시가 날짜 계산 상태보다 우선한다. 정상 상태 필터는 별도 중단 상태를 제외한다.
- 중단 상태에서 `canStart=false`이며 새 준비 시작과 ‘이번만 확인’을 차단한다. 이미 생성한 준비 건의 답변·서류·일정 기록·준비도·revision·안내 버전은 그대로 보존한다. 기존 준비 건을 열거나 개인 기록을 수정하는 기능은 기존 소유권·검수 계약을 따른다.
- 준비 조회 응답은 현재 공식 상태 경고와 확인할 다음 행동을 덧붙인다. 상태 변경만으로 개인 JSON 스냅샷을 다시 저장하지 않는다.
- 기존 날짜는 삭제하지 않고 ‘기존 공고 일정’이라는 안내와 함께 남긴다. 중단된 접수에는 남은 D-day나 새 신청 행동을 표시하지 않는다. 타임라인에도 중단 상태를 표시한다.
- 공개 수정 이력은 해당 notice revision의 lifecycle 근거를 함께 기록한다. 과거 공개본은 소급 변경하지 않는다. 관리 감사 이력은 담당자 ID를 보관하되 계정 삭제 시 담당자 참조만 익명화한다.

## 기한 안내와 캘린더

- `EARLY_CLOSED`는 신청/접수 시작·마감과 공식 신청 여부·완료 확인 알림을 제외한다. 결과 발표·서류 마감은 기존 신청자에게 필요할 수 있어 유지한다. 제목에 신청/마감이라는 말이 함께 있어도 서류·결과 발표·공고 게시 분류를 먼저 적용한다.
- `CANCELLED`는 모든 기한 알림을 제외한다. 조기 마감·취소·정상 복원 소식은 별도 lifecycle revision 키로 사이트 알림에 남긴다. 읽음 및 이메일·푸시 중복 방지 키는 기존 계약을 따른다. 기존 안내 version 변경 소식과 분리한다.
- 이메일·푸시 발송 작업은 실행 시점에 재구성한 알림 목록을 사용한다. 이미 발송된 외부 메시지는 회수하지 않는다.
- 다음 일정과 새 캘린더 내보내기에도 같은 제외 기준을 적용한다. 이미 내려받은 `.ics`는 변경할 수 없으므로 가져온 일정은 사용자가 정리해야 한다는 안내를 표시한다.

## 검증 범위

- `NoticeLifecycleIntegrationTest`: 실제 PostgreSQL V18 적용, 관리자/일반 사용자/익명 권한과 CSRF, 공식 확인 필수, stale revision, 공개 유지, 새 시작 차단, 개인 스냅샷 보존, 상태 필터, 공개 수정 이력, 기한 알림 중지·복원.
- `noticeLifecycle.test.tsx`: 목록/상세 표시 우선순위, 기존 준비 접근, 중단 기한 제거, 캘린더, 타임라인.
- 실제 운영기관의 조기 마감 공고 판독과 외부 발송은 관리자·운영 환경 확인 대상이다.
