## 전세임대 질문·서류 계약

공통 필수 4개는 본인 등본, 상세 가족관계증명서, 개인정보 동의서, 해당 1순위 증명서다. 아래 5개 항목은 답변에 따라 달라진다. 항목 하나가 여러 서류를 포함하는 경우 제목에 ‘묶음’을 표시한다.

| 질문 조건 | 표시되는 서류 항목 |
| --- | --- |
| 19~39세 밖의 대학생 유형 | 재학/입학/복학 상태에 맞는 증빙 묶음 |
| 19~39세 밖의 취업준비생 유형 | 졸업·중퇴 등 학력 증빙, 건강보험자격득실확인서 |
| 30세 이상 + 부모 명의 1순위 증명서 + 해당 부모와 등본 분리 | 본인·부·모 초본 묶음 |
| Q&A 5번의 제한된 형제자매 명의 예외 | 해당 형제자매 가족관계증명서 |

본인 명의 증명서일 때 부모 관련 서류·서명 면제를 반영했다. 부모 또는 형제자매 명의일 때 동의 참여자는 해당 명의자와 본인으로 안내한다. 형제자매 예외는 본인·부모 명의 발급 불가 및 동일 등본 조건이 있으며 일반적인 형제자매 수급 사실로 확대하지 않는다.

질문 답변은 자기 확인 기록이다. YES는 연결 서류를 조건부 필요로, NO는 해당 없음으로, UNKNOWN/미응답은 추가 확인으로 표시한다. 완료된 서류의 조건이 바뀌면 RECHECK로 전환한다. 모든 NO를 자격 탈락으로 계산하거나 YES 수를 합격 확률로 쓰지 않는다. 서로 다른 신청 유형의 모순 응답을 자동 판정하는 기능은 없으며, 실제 신청 유형 선택은 원문 확인이 필요하다.

전세임대 안내는 신청 준비 범위다. LH가 추가 자료를 요구할 수 있으며 개별 가족관계 예외, 실제 임대차 계약, 권리분석을 자동 판정하지 않는다. 주민번호 공개 등 공식 발급 기준은 원문대로 설명하되 집으로에는 원본·주민번호를 수집하지 않는다.

## 적용·추적 방법

`data/notices/guidance-review-20261101.json`에 내용·판단·근거 URL·확인일·다운로드 원문 SHA-256을 보존한다. PDF/HWP 원문 자체는 Git에 넣지 않는다. 복학확약각서는 공식 첨부 링크를 확인했으며 SHA-256 수집 대상에는 포함하지 않았다.

`node scripts/apply-guidance-review.mjs`는 검증만 한다. `--apply`는 지정된 로컬 Docker DB만 변경한다. 초기 자료와 버전·리비전·상태가 일치할 때만 세 공고를 한 트랜잭션으로 갱신한다. 동일 결과 재실행은 건너뛰고, 다른 편집이 있으면 전체 중단한다. 적용 전 공개 공고 행과 결과를 `.tools/notice-imports`에 남긴다.

이번 로컬 일괄 적용은 사용자 관리자 계정을 대신 사용하지 않는다. `review_audit`에 사람 검수자로 위장한 행을 만들지 않으며, 버전 관리된 이 문서·JSON·notice.reason·로컬 백업으로 Codex 검토와 적용을 추적한다. 팀 운영 검수는 실제 관리자 계정으로 별도 재확인해 관리자 감사 기록을 남겨야 한다. 기존 사용자의 준비 스냅샷·답변은 수정하지 않는다.
