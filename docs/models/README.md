# 코드 개념 지도

- 열기: `http://127.0.0.1:5173/jibro-code-model.html`
- 파일: `frontend/public/jibro-code-model.html` — 외부 의존성이 없는 단일 HTML, 파일 자체로도 열 수 있음.
- 재생성: 저장소 루트에서 `python docs/models/build_code_model.py`.

현재 작업 트리를 정적으로 확인해 수동 모델링한 여섯 관점(논리 UML, 축약 ER, 답변 저장 시퀀스, 상태·결정 규칙, 구성요소, 일정·탐색 경계)이다. 모든 타입이나 테이블을 나열한 자동 역공학 결과가 아니다. 각 상자와 근거 목록에서 검토한 코드 위치를 확인할 수 있다. 갱신 시 Python 파일의 모델 설명·관계·근거·확인일을 코드와 대조한 뒤 재생성한다. HEAD는 현재 저장소에서 읽으며, 주요 선언의 근거 줄번호는 실제 심볼에서 찾는다.

보관함과 안내 갱신 이력, 공고 기준 version과 개인 준비 revision, 논리적 Answer와 물리 저장을 구분한다. 준비도는 자격·선정 확률이 아니다. 외부 서비스 동작이나 실데이터는 이 문서에 포함하지 않는다.

2026-11-06 최초 작성 검증: SVG 다섯 개 XML 파싱, 인용 파일 존재, 브라우저 다섯 관점 전환·노드 설명·확대, 1440px과 393px 표시, 실행 오류 없음. SVG 저장·전체 인쇄 기능은 제공하지만 실제 저장 파일 및 인쇄 결과는 별도로 검증하지 않았다.

2026-11-06 업데이트본: 리팩토링 후 책임을 그림 자체에 반영했다. 저장 시퀀스의 `PreparationService → PreparationRules → Assessment → Service → DB`를 별도 생명선으로 그렸고 구성요소에서도 저장과 순수 정책, 정적 시연과 실제 서버 경계를 분리했다. 여섯 번째 관점에는 현재 공개 일정과 동일 기준의 개인 완료 표시, 명시적 조건 URL, 개요 신청 기록 팝업, 준비 ID별 메모 초안·제출 명령을 그렸다. ER의 이력 유일키도 실제 `preparation_id, notice_version`으로 수정했다. 보관·복원에서 revision을 증가시킨다고 일반화하지 않는다.

생성 검증: SVG 6개 XML 파싱, 33개 개념의 모든 근거 파일·줄번호 범위 확인, 주요 심볼의 유일 위치 확인, 외부 스크립트/스타일 의존성 없음 확인. 앱의 실제 저장 검증과 이 모델의 정적 확인은 별개다. 이번 업데이트의 브라우저 검증 결과는 작업 이력에 기록한다.

업데이트본 브라우저 검증: 1440px에서 여섯 관점 전환·상자 글자 넘침 없음·설명 패널·120% 확대/맞춤 확인. 393×852에서 문서 가로 넘침 없이 다이어그램 내부만 스크롤됨을 확인했다. SVG 저장 버튼으로 내려받은 시퀀스 파일의 XML과 현재 모델 일치를 확인했다. 브라우저 오류 로그는 없었다. 전체 인쇄/PDF 출력은 별도 실행하지 않았다.
