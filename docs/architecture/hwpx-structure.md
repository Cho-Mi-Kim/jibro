# HWPX 원문 구조 보존

`DocumentTextParser`는 HWPX 구역을 `HwpxStructuredText`로 읽는다. 기존 `Part(location, text)`·파서 작업자 통신·DB 구조는 유지한다. PDF는 기존의 위치 정렬 텍스트 추출을 사용하며, HWPX 표 구조가 생겼다는 이유로 PDF와의 내용 일치를 확정하지 않는다.

## 구조 표시 형식

각 표시자는 독립된 줄이다. 표 ID는 구역 안에서 시작 태그 순으로 부여하며, 행·열은 HWPX `cellAddr`의 0 기준 값을 1 기준으로 변환한다. 셀 순서를 임의로 다시 정렬하지 않는다.

```text
⟦HWPX:TABLE id=1 rows=2 cols=3⟧
⟦HWPX:CELL table=1 row=1 col=1 rowspan=1 colspan=3⟧
가구원 수별 기준
⟦HWPX:/CELL⟧
…
⟦HWPX:/TABLE⟧
```

- `rows`·`cols`는 표의 선언된 크기다. `rowspan`·`colspan`은 해당 셀의 원문 병합 범위다. 값이 없으면 `unknown`으로 남기며 주변 값으로 채우지 않는다.
- 빈 셀도 시작·종료 표시자를 남긴다. 내부 문단의 줄바꿈은 보존한다. 중첩 표는 부모 셀 안에 별도 ID의 표로 기록된다.
- 각주·미주는 `FOOTNOTE`·`ENDNOTE`, 머리말·꼬리말은 `HEADER`·`FOOTER`와 대응하는 `/…` 표시자로 감싼다. 내용은 삭제하지 않는다. 이 표시자는 규칙이 아닌 문서 구조다.
- `HwpxStructuredText.withoutStructure(text)`는 이 파서가 만든 표시자 줄만 제거하는 이전 텍스트 비교용 보조 함수다. 조건 해석과 표 비교에서는 구조 표시를 유지해야 한다. 일반 PDF나 임의 본문의 의미를 정규화하는 함수로 사용하지 않는다.

## 제한과 보류

구조 표시를 포함한 결과도 기존 1,000,000자·최대 200개 구역/쪽·압축 해제 24MiB·ZIP 항목 300개 제한 안에 있어야 한다. XML 깊이 128, 표 중첩 16, 표 2,048개, 셀 10,000개, 개별 표 점유 좌표 40,000개를 넘기면 실패로 남긴다. 표 범위를 벗어나거나 겹치는 셀 좌표는 자동으로 고치지 않는다.

XML 외부 엔티티·DTD는 허용하지 않는다. 문서 본문이 구조 표시자를 가장할 수 없도록 예약 구분 문자 `⟦`·`⟧`를 포함한 HWPX는 실패로 남겨 원문 확인 대상으로 보낸다. 기존의 프로세스 메모리·실행시간 제한은 그대로 적용한다.

이 구조는 행·열·병합 범위를 가진 입력을 제공한다. 자격 판단, PDF/HWPX 동등성 판정, 조건·서류 생성 및 공개 승인 자체를 수행하지 않는다.

## 로컬 해석에서 사용하는 방식

`HwpxContextReader`는 HWPX로 추출된 구역의 표시자만 읽는다. `LocalRuleInterpreter`의 원문 인용에는 표시자 줄이 들어가지 않으며, 인용과 수치의 시작·끝 위치는 구조를 포함한 원래 `Part.text`의 위치를 그대로 사용한다. 표·행·열·병합·중첩·각주 정보는 조항의 `heading`에 보관한다. 일반 PDF 본문에 같은 모양의 글자가 있더라도 HWPX 표시자로 처리하지 않는다.

셀의 조항에는 같은 셀, 같은 행, 열이 겹치는 첫행 셀, 중첩 표를 둘러싼 부모 셀의 조항을 관련 문맥으로 연결한다. 첫행을 실제 열 제목이라고 확정하거나 셀들을 합쳐 새로운 인용문을 만들지는 않는다. 여러 행에 걸친 공유 셀은 각 행에서 참조하며, 공유 셀이 다른 모든 행을 다시 연결하는 구조는 피한다.

좌표가 미상이거나 필요한 관련 조항이 64개를 초과하면 `HWPX_TABLE_CONTEXT_INCOMPLETE`로 남긴다. 구조 표시가 닫히지 않는 등 손상이 있으면 `HWPX_STRUCTURE_INCOMPLETE`로 남긴다. 이 미완료 문맥은 작은 API 요청으로 임의 축약하지 않는다. 기존 API 요청 크기·횟수 제한과 원문 충돌 시 호출 보류는 유지된다.

로컬 해석 정책은 `local-rules-v2-hwpx-context`로 구분하여 이전의 구조 없는 조항 캐시와 혼용하지 않는다.

## 검증 범위

- `HwpxStructuredTextTest`: 빈 셀·병합 범위·열 값 재배치·중첩 표·각주·머리말·꼬리말·미상 좌표·잘못된 좌표·DTD·출력/깊이 제한.
- `DocumentTextParserTest`: HWPX·압축 첨부 경로와 기존 PDF/HWP 처리.
- `LocalRuleInterpreterHwpxTest`: 표시자 제외·정확한 원문 위치·행/열 문맥·병합 셀·부모 셀·각주 연결, 미상/손상/과대 문맥의 보류, PDF의 일반 텍스트 보존.
- 실제 익산한스빌 2026.11.04 공고의 HWPX 두 구역은 별도 128MiB 실행에서 추출했고, 구조 표시와 공백을 제외한 모든 원문 글자의 순서가 이전 추출과 같음을 비교했다. 이 비교는 글자 보존 확인이며 규칙의 정확성이나 PDF와의 의미 일치를 뜻하지 않는다.
