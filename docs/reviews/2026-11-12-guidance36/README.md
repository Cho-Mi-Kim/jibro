## 읽기·검증 개선

- OCR: PDF 총 쪽수 대신 실제 광학 판독 이미지 수를 기준으로 예산 적용. 45쪽 일반 텍스트 + 1쪽 스캔 회귀 검사, 실제 스캔 41장 제한 유지.
- 명시적 원문 검수: 대용량 ZIP/PDF 지문 확인의 스트리밍 상한을 150MiB로 조정. 일반 수집 20MiB 제한 유지. 120MiB 허용·151MiB 거절 회귀 검사.
- 5개 대용량 팸플릿/ZIP 및 전주팔복 혼합 PDF의 발췌를 복구. 도면·과거 팸플릿의 내용을 현재 신청 조건으로 사용하지 않음.
- 게시 때마다 공식 상세·첨부 재조회, SHA-256·공고 revision·발췌 지문을 검증하고 기존 게시 서비스를 사용. 각 결과는 DB 원문검수 이력에 기록.
