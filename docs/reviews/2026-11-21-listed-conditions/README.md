# 현재 목록의 제공 공고 조건 검토 — 2026-11-21

현재 기본 목록122건 가운데 준비 안내가 제공되는106건을 개별 대조했다. 공고별 결과는 [results.json](results.json)에 있고, 의미가 바뀌는 질문·서류 원고는 `data/notices/condition-review-20261121/`, 공통 표시 원고는 `frontend/src/features/housing/reviewedConditions/batch-*.json`에 있다. 공고별 `notice-*.json`과 `index.json`은 생성 파일이며 원본 묶음을 수정한 뒤 `npm run build:reviewed-conditions`로 갱신한다.

최종 공개 질문1,474개, 서류2,615개다.71건은 새 안내 버전을 게시했고 나머지는 표시만 개선하거나 기존 네 개의 개별 검토 안내를 보존했다. 이미 저장된 준비·답변·메모·과거 공개본은 덮어쓰지 않았다. 현재19공고의28개 확인 필요 항목을 임의로 확정하지 않았다.

질문 제목과 접힌 핵심 기준을 쉽게 줄이고, 펼치면 기준·예외·수치표·정확한 원문 근거를 보여준다. 신청 유형별 필수 서류와 답변 모순도 공통 평가 흐름으로 연결한다. 원문이나 질문이 달라져 검토 원고와 일치하지 않으면 해당 공고의 기존 안전한 표시로 돌아간다.

표시 생성기는 같은 검토 폴더의 질문 원고에서 답변 계약도 가져온다. 예전 예/아니요 질문이 새 유형 선택 질문으로 바뀐 경우처럼 입력의 의미가 달라졌다면, 과거 기록에는 새로운 질문 설명을 대입하지 않는다.

원문 대조는 AI 보조 검토이며 기관의 자격 판정이나 사람 관리자 승인과 다르다. 준비 안내와 실제 신청은 구분하며, 기존 기록의 상태는 기존 안내 갱신 흐름으로 유지한다. 이번 범위 밖 공고와 미래 공고의 세부 숫자 기준에 임의로 일반화하지 않는다.

검증 결과와 문제 해결 과정은 [작업 기록](../../history/entries/2026-11-21-listed-condition-improvement.md)을 따른다. 실기기 검사는 수행하지 않았으며 화면 크기 검사는 Edge 브라우저에서 수행했다.
