# 남은 12개 항목 재대조 결과

2026-11-10(한국시간), 접수 종료를 제외한 7개 공고의 12개 쟁점을 다시 검토했다. 공식 상세의 상태는 모두 공고중이었고, 현재 연결된 첨부 23개의 원본 해시는 이전 검토본과 같았다. 동일 공고의 정정 이력, LH 후속 공지, 적용 법령·공식 안내서를 추가 대조했다.

**1개 해소, 4개 확인 범위 축소, 7개 유지. 남은 확인 필요 항목은 총 11개다.** 4개 공고의 안내를 실제 로컬 DB에 반영했고 공개 API로 확인했다. 접수 종료 공고는 이번 검토·발췌·반영 대상에 포함하지 않았다.

## 실제 반영한 내용

- 태백궁전의 전환이율 충돌을 해소했다. LH 본사 2025.11.24 공지는 **2026.1.1 이후 신규 납부분부터 증액 6%, 감액 3.5%**를 안내한다. 모집공고 4쪽의 2026.1.17 기준 표와 일치한다. 기존 납부분에 소급하거나 향후 이율을 고정한다는 뜻이 아니다. [공식 본사 공지](https://apply.lh.or.kr/lhapply/apply/noti/an/view.do?bbsSn=9102431119&ccrCnntSysDsCd=02&slBbsKdCd=03&mi=1079) · [공식 첨부 1쪽](https://apply.lh.or.kr/lhapply/lhFile.do?fileid=64452247)
- 삼척도계·정선신동, 태백장성, 동해유성·태백철암장미, 태백궁전의 대리신청 안내를 분리했다. 본문에서 확인된 인감증명/본인서명 방식과 신분증은 준비할 수 있고, 실제 위임장 적용·작성에 관한 충돌만 확인 필요로 남는다.
- 네 공고에 문서 후보가 각각 2개 추가되었다. 신청자에게 모든 후보 서류를 요구하는 것이 아니라 기존 답변에 따른 해당 서류만 표시한다.
- 기존 질문과 선택지·문서 ID를 보존했다. 전환이율이 달라진 `tg-contract` 질문만 내용이 변경되며, 안내 버전 갱신 시 기존 답변을 다시 확인하게 된다. 개인 준비 기록을 직접 수정하거나 삭제하지 않았다. 버전 갱신 시 기존 서비스 정책에 따라 새 서류는 미확인, 준비완료 상태는 재확인으로 바뀔 수 있다.

## 전주 일반 기준 조사와 적용 한계

LH 본사 2026 안내서에서는 영구임대의 일반 기본값 총자산 2억 4,500만원·자동차 4,542만원을 확인했다. 하지만 이것만으로 해당 상시모집의 적용 시점과 출산 등 가산 금액을 확정하지 않았다. 가산은 기초 통계값·반올림/절사 규칙이 있어 공개된 기본값에 비율을 단순 곱하지 않았다. 이 값은 조사 근거로 보존하며 현재 공고의 개인별 충족 판단에 대입하지 않았다. [LH 공식 안내서](https://www.lh.or.kr/boardDownload.es?bid=0033&list_no=731834&seq=1)

## 검증과 보존

- 적용 전 DB 백업 생성 및 복원 목록 확인.
- 고정된 미종료 대상만 처리. 현재 공고 상태, 기존 게시본·revision, 전체 원문 문맥, 첨부 구성과 SHA를 재검증.
- 기존 `SourceReviewVerifier`와 `SourceReviewPublicationService.amend`를 통과한 4건만 반영. 모든 반영 결과 `amended=true`.
- 태백궁전 새 본사 공지는 게시물 본문·첨부 연결의 지문과 PDF 원바이트를 다시 조회해 검사. 전환이율은 별도 독립 대조 통과.
- 동해 정정 안내의 새 버전에 맞춰 기존 원본→정정본 연결을 재검증. 남원 관계도 API에서 계속 유효함을 확인.
- 공개 안내 10/10 이용 가능. 질문 141개·서류 후보 286개·일정 21개·확인 필요 11개. 수정하지 않은 대상 3개 게시본은 이전과 완전히 동일.
- 독립 콘텐츠 검사 62개 통과. 기존 준비 테이블의 행 수·해시 동일, 프런트 5173 HTTP 200.
- 이번 작업은 검토 데이터·문서 변경이다. 제품 코드·수집 설정 변경, 전체 자동 검수 실행, 재배포·push는 하지 않았다. 새 전체 단위/통합 테스트 및 실제 모바일 기기 검증은 실행하지 않았다.

원고 4개는 `packages/`, 실제 적용 결과는 [apply-results.json](apply-results.json), 공개 응답 검증은 [runtime-validation.json](runtime-validation.json)에 보존한다. 쟁점별 공식 근거와 기관에 확인할 정확한 질문은 `research/`의 proxy·renewal·standards·timing 기록에 있다. 이전 검토 파일은 덮어쓰지 않았다.
