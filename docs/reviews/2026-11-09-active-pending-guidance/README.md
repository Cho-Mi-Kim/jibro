## 처리 원칙과 검증

- 최신 상세 및 모든 첨부 62개 출처 참조를 재조회해 원본 SHA/전체 문맥을 대조했다. 출처 수는 공고별 참조의 합이며 중복 첨부를 포함한다.
- 접수종료 15,895건과 미확정 과거 18건은 이번 명시적 검수에서 처리하지 않았다. 날짜가 없는 것을 종료 또는 접수중으로 추정하지 않았다.
- 군산·전주는 모집 완료 등 종료 조건만 확인되므로 임의의 마감일을 만들지 않았다. 태백장성은 상세/첨부의 날짜 충돌 때문에 마감일을 비웠다. 이 3건은 앱에서 기간 미확인으로 보이지만 준비 안내를 이용할 수 있다.
- 남원 공식 당첨자 발표 예정일 2027.03.31은 개별통보·변경 가능 조건과 함께 제공한다. 서류 대상자 발표와 구분했다.
- 예비신혼·한부모·신생아 등 겹치는 조건, 가점 증빙, 외국인 서류 생략, 금융서류 면제, 장기카드대출 증빙 분기를 원문과 재대조했다.
- 한글 파일명 ZIP 4개 출처의 자동 판독을 복구했다. 이미지 도면 5개는 시각 대조와 원본 해시 검사를 수행해 REVIEWED로 남겼다.
- backend 단위559 + DB통합306 = 865개 검사 통과, bootJar 성공. 재시동 후 5173/8080 HTTP200, 10건 공개 내용·준비 시작·출처·미확정 범위, 정정 연결 2건을 실제 API로 확인했다.
- 기존 개인 준비 snapshot을 변경하지 않았다. 새 검토는 AI_ASSISTED_SOURCE_REVIEW 감사로 남겼으며 사람의 관리자 승인이나 최종 신청 자격 판정을 만들지 않았다.
- 이번 코드 변경은 읽기와 동일성 검사 보완이다. 미래 모든 공고를 자동 승인한다는 의미가 아니며 전체 예약 수집 정책을 변경하지 않았다.

원문 전체 파일·렌더 이미지·비밀 설정은 이 폴더에 포함하지 않는다. 원문 검토 패키지와 해시·검증 집계만 보존한다.
