# 스캔 원문 대조와 확인된 준비 안내 제공

검토일: 2026-11-08. 아래 공고별 기록은 원고 작성 당시의 읽기 범위와 판단을 보존한다. 원고 작성자가 DB에 반영하지 않았다는 각 절의 설명과 달리, 후속 통합 검증에서 17건 모두 명시적 원문 검토 서비스로 로컬에 반영했다. 최종 상태는 함께 보관한 runtime JSON과 packages JSON을 기준으로 한다. 외부 배포·push는 하지 않았다.

## 최종 적용 절차

기존 32개 승인 공고와 개인 준비 기록을 비교 기준으로 보존했다. 초기 6건 반영 후 11건은 공식 상세 문맥 차이로 차단되었다. 동일한 최신 HTML을 이전 파서에 통과시키면 11건 모두 기존 저장 문맥과 일치했고, 현재 파서가 접수처정보를 추가로 읽는 차이임을 확인했다. 추가 주소·운영시간·접수 방식도 검토하고 모든 첨부 바이트를 다시 내려받아 SHA가 같은 경우에만 기존 OCR/native 읽기 결과를 새 스냅샷에 연결했다. 원문 비교 검사를 완화하지 않았다. 공주 접수처 운영시간과 실제 신청기간 같은 서로 다른 범위를 합치지 않았다.

공주·화성의 신분증 안내는 일반 증명서 발급일과 구분하도록 정정했다. 이미 반영된 화성은 이전 공개 원고 지문을 확인하는 amend 경로로 수정했고, 모든 패키지를 현재 revision·extraction·공식 HTML/첨부 SHA에 다시 결합했다. 미확정 신청 시작/마감은 PARTIAL의 일정 issue에 연결하고 확정 일정·알림·캘린더에 임의의 날짜를 생성하지 않는다.

# OCR 공식 원문 대조 — 담당 A (2026-11-08)

## 작업 범위와 판정의 의미

- 담당 5건의 공식 상세 본문, native HWP 전체, 첨부 양식/공급목록을 읽고 스캔 PDF의 주요 표를 실제 이미지로 대조했다. 저장된 최신 extraction의 URL·SHA·revision을 원고에 연결했다.
- `PASS`는 작성된 준비 안내의 출처 검토 결과이지 신청자 자격·당첨 확정이 아니다. 질문은 자기확인 및 `UNKNOWN`을 유지한다. 과거 공고에 2026년 기준을 넣지 않았다.
- OCR만으로 누락 숫자를 메우거나 표의 행을 이어 붙이지 않았다. PDF 전체를 전수 시각 검수했다고 주장하지 않는다. 실제 시각 대조 범위는 아래와 같다. 나머지 부분은 전체 native HWP 텍스트를 검토했다.
- DB 변경, 재수집, 실발행은 하지 않았다. 발행 담당자가 현재 지문·첨부 SHA·revision을 다시 검증해야 한다.
- 작성기: `build-a.py`; 결과: `packages/{noticeId}.json`. 편집 중인 다른 담당자의 원고를 수정하지 않았다.

## 조건부 서류와 기술 검증

- 공통서류/계층별/해당자/입주·계약 전 서류를 설명과 `conditionQuestionId/conditionAnswerValues`로 분리했다. 질문에 `UNKNOWN`을 보존한다.
- 다중 사유(분리배우자+외국인, 주소변경 등)는 복수선택으로 묶어 하나의 조건이 다른 조건을 막지 않게 했다. 같은 가족관계증명서를 계층별·추가사유로 이중 생성하지 않도록 화성 목록을 합쳤다.
- 모든 질문·문서 ID 중복, 조건 옵션 참조, SHA64, sourceURL coverage, 증거 페이지 및 문자열 길이는 작성기/사전검증으로 확인한다. 제품 `SourceReviewVerifier`, `validateContent`, `ReviewedApplicationPeriod` 검증은 root의 공통 preflight 결과를 기준으로 한다.
- 이 파일과 JSON은 최종 동결 전달 이후에 변경하지 않는다. 원문의 새로운 충돌이나 현재 지문 변화 발견 시 새 검토가 필요하다.

# OCR 원문 대조 원고 B — 2026-11-08

담당 5건. DB·운영 코드·원본 문서는 변경하지 않았다. 작성물은 `build-b.py`와 `packages/{noticeId}.json`이다. 실행 중 원문을 다시 조회하거나 게시하는 기능은 없다. 루트 담당자의 공식 원문 재조회·전출처 SHA 검증 후 명시적 원문 검토 경로로 적용하는 원고다.

## 읽은 자료와 대조 방법

# 과거 공고 5건: 원문 대조와 준비 안내 원고 검토

검토일: 2026-11-08. 담당: Codex 보조 원문 검토 C. 이 문서는 실제 DB 게시 결과가 아니라 명시적 원문 검토 패키지의 검토 근거다. 최종 게시자는 최신 원문과 SHA, revision, extractionId 및 Java 검증 결과를 다시 확인한다.
