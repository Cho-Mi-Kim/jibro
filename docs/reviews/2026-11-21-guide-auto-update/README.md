## 운영

`GUIDE_REFRESH_ENABLED`는 예약 출처 확인, `GUIDE_REFRESH_AI_ENABLED`는 변경 내용 검수를 제어한다. 후자는 미설정 시 기존 `GEMINI_REVIEW_ENABLED`를 따른다. 기존 서버 키와 전체 서비스의 최대 10회/일·최소60초 간격 제한을 공유한다. 할당량을 우회하거나 자동 과금 설정을 바꾸지 않는다.

서버가 꺼져 있으면 다음 시작 후 미실행분을 확인한다. 서버 없는 demo는 배포 원고와 당시 확인일을 표시한다. 연결이 끊긴 출처의 대체 주소는 임의 생성하지 않는다. 공식 사이트의 유효한 동일 기관 이동은 추적하고, 해결되지 않는 읽기 실패는 상태로 남긴다.

`verification.json`은 이 작업의 상태·검사·실행 요약이다. 상세 로컬 로그·원문 캐시는 `.tools/qa/guide-auto-update`, `guide-auto-sources`, `guide-auto-review`에 있으며 저장소에 원문 전문이나 비밀값을 추가하지 않는다. 소스 계약은 `docs/architecture/backend-contracts.md`와 `frontend-contracts.md`를 따른다.
