단일 원고는 `data/guides/guide-catalog.json`이다. 서버는 빌드 시 같은 파일을 패키징하고, 체험 모드는 이 파일을 직접 가져온다. 각 항목에 적용 범위·확인일·하나 이상의 공식 출처를 포함한다. 출처의 표현을 그대로 옮기기보다 핵심 절차를 짧은 문단·목록으로 정리했다.

## 검토 방식

- LH청약플러스, LH, 정부24, 대법원, 보건복지부, 복지로, SH 서울주거상담, 주택관리공단의 공식 자료를 확인했다.
- 지원제도·용어와 발급·절차·문의처를 나눠 조사한 뒤 교차 검토했다. 일반 가이드에 남은 과거 연도 표와 개별 공급유형의 숫자를 전체 공고의 기준으로 복제하지 않았다.
- 정정·예비입주·완화 안내의 개별 공고 링크에는 ‘사례’라고 표시하고 다른 모집에 동일 적용하지 않도록 범위를 명시했다.
- LH 일반 상담과 주거급여 전용 상담을 구분했다. 수정·삭제 가능 안내는 확인한 LH 건설임대 인터넷 청약 범위로 한정했다.
- 등·초본은 공고가 요구한 종류를 준비하도록 안내한다. 온라인 대리 발급과 방문 대리 발급, 증명서 발급과 청약 대리를 구분했다.
- 본문을 읽을 수 없던 마이홈 PC 경로와 직접 접근에 제약이 있던 SH 청약 경로는 내용을 확인한 공식 대체 자료로 연결했다.

항목별 검토 근거는 `sources-concepts.json`, `sources-practical.json`을 따른다. 이 자료는 AI 보조 조사 기록이며 기관이나 사람 관리자의 승인을 뜻하지 않는다. 인증 후 실제 증명서 발급·청약 접수·전화 상담은 수행하지 않았다.

## 갱신

제도·발급 경로·연락처를 바꾸면 원고와 출처 확인일을 함께 갱신하고, 서버·체험 모드의 검색과 페이지 응답, 링크 연결과 작은 화면을 검증한다. 일반 FAQ는 공고 자격의 판정 입력으로 사용하지 않으며 공고 원문·개인 준비·과거 답변을 수정하지 않는다. 이 작업은 새로운 예약 수집을 설정하지 않는다.


## 실행 검증 결과

최종36개 API 항목이 원고와 일치하며,37개 공식 출처를 실제 브라우저에서 확인했다. Edge360/390/768px 및360px 글자125%에서 모든 항목을 열고 접는144개 화면 사례와 검색·주제 재선택·페이지 이동을 통과했다. 실제 휴대폰, 로그인 후 민원 발급·청약은 검증하지 않았다. 코드 검사와 실행 근거 요약은 `verification.json`, 출처 접근 확인은 `final-link-qa-summary.json`을 따른다.5173에 반영됐다.
