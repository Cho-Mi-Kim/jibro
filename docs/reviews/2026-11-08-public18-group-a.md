- 현재18 snapshot의9건 모두 공식 상세 HTML을 새로 열어 접수처/안내사항까지 확인했다. main HWPX·PDF18파일도 다시 다운로드하여 기존 SHA256과 일치함을 확인했다(fresh-downloads.json).
- PDF의 신청자격·선정·증빙·일정 원문을 읽고 같은 HWPX의 대상 문장·표 셀을 대조했다. clause-comparison.json은 단어와 숫자의 순서를 유지한 실제 문장 조각의 위치 색인이다. 숫자 목록의 일치나 자동 일치율만으로 형식 간 동등을 판정하지 않았다.
- 주요 일정표의 PDF 렌더(8개)를 직접 확인하여 순위/접수방식별 열,시간,장소를 분리했다. 인천 남동구 PDF는 한 물리쪽에 문서2쪽이 배치되어 있어 물리쪽/문서쪽을 함께 적었다.
- 공고 본문의 개별 주택판정 예외·공적소득/자산 산정 소명은 질문으로 추가확인 경로를 남겼다. 편집 검토 PASS는 신청자 자격·점수·당첨에 대한 확정이 아니다.
- 자료의 적용 범위가 특정 단계에 한정되면 최초신청/가점/서류/갱신을 분리했다. 단지 팸플릿과 서식의 빈칸·서명일을 새로운 신청조건이나 접수일로 만들지 않았다.
