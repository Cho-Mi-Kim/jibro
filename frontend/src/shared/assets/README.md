# 기관 CI 출처

## LH (`lh-ci.svg`)

- 공식 안내: https://www.lh.or.kr/menu.es?mid=a10702040100
- 공식 원본: https://www.lh.or.kr/boardDownload.es?bid=ATT&list_no=571701&seq=4
- 내려받은 파일: `2022_BS_01-2.ai` (워드마크 활용형), 확인일 2026-11-11.
- AI의 PDF 호환 페이지에서 활용형 워드마크만 SVG로 추출했다. 설명·치수·기본형 비교 도형은 포함하지 않는다.
- 공식 도형과 색상을 유지한다. 글자·외곽선은 벡터이며, PDF의 그라데이션은 SVG 안에 포함된 이미지로 변환했다. 외부 이미지 요청은 없다.
- `AgencyMark`에서 비율을 유지해 약 42 × 28px로 표시한다. 다른 기관에는 적용하지 않는다.
- CI의 권리는 한국토지주택공사에 있으며, 공고의 제공 기관을 식별하기 위해 사용한다.
